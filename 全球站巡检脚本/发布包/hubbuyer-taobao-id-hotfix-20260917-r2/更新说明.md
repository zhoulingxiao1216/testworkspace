# 淘宝详情 ID 校验热修复 r2

适用：已安装 hubbuyer-patrol-20260917-r1，出现“淘宝详情商品ID与加购商品不一致”的巡检项目。

## 替换范围

仅将 payload 内两个文件按相对路径覆盖到 hubbuyer 根目录：

- checker/api/add_cart.py
- tests/test_add_cart_taobao.py

不替换整个项目，不改线上配置、账号或运行数据，不涉及 Global 后台。

## 修改内容

原校验仅读取 offerId，缺少该字段时也报商品不一致。新校验兼容 product_index_item_id、offerId、offer_id，忽略未提供的字段并去除字符串两端空白。所有已提供的商品 ID 必须与请求一致；字段冲突或全部缺失仍会失败。失败日志显示请求与返回的商品 ID，便于定位具体环境。

本机 main 环境原始问题未复现，不能据此断定截图一定由字段缺失造成。更新后本机淘宝和1688加购通过；全量25项单元测试通过，本文件中的淘宝专项测试为9项通过。

## 操作

暂停正在运行的巡检，备份上述两个旧文件，按原路径覆盖。使用线上原虚拟环境执行：

```text
python -m unittest discover -s tests -p "test_add_cart_taobao.py"
```

需实测时运行 `python -u checker/api/add_cart.py`，该命令会实际加购1688和淘宝商品。若仍失败，保留新日志中的 requested、returned 字段及该环境 ENV_TYPE 继续排查，不应移除商品身份校验。

回滚：暂停巡检后恢复上述两个文件的发布前备份。此操作不撤销已经产生的购物车记录。
