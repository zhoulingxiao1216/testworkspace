## 变更内容

| 文件 | 变更 |
| --- | --- |
| checker/api/add_cart.py | 淘宝加购前读取最新商品详情和索引；保持配置中的商品、SKU、数量，不存在的 SKU 明确失败；输出接口业务错误。 |
| checker/api/purchase_order_ops.py | 按明细调用 updateGenuineQty；仅 HTTP 200、业务码 40000 且消息为正品附加项同步失败时，等待 1.2 秒后重试一次；重试成功必须回查数量；保留首次失败 WARN；数量计算扣除不良和待定；加强幂等失败排除及旧发货上下文清理。 |
| checker/api/backend_admin_checkpoint.py | 仓配失败时跳过发货，避免使用上一轮发货上下文。 |
| checker/api/purchase_order_shipping.py | 验证发货数量为正，并检查发货上下文订单号与本轮订单一致。 |
| tests/test_add_cart_taobao.py | 验证索引更新、SKU不替换、商品匹配及业务错误保留。 |
| tests/test_purchase_order_ops_genuine.py | 验证有限重试、数量复核、持续失败、不重放成功明细及待定数量扣减。 |

仓配与发货保护包含当前工作区已有的相关变更；发布的是经过本轮整链路验证的文件版本。未纳入登录账号修改、购物车ID映射、付款订单记录、发货上下文及提交订单记录等本地运行数据。

## 包结构

- payload/：6 个待部署文件，内部路径相对于线上 hubbuyer 根目录。
- config_steps.merge.json：需合并到 config/data/purchase_order_ops.json 的步骤配置，不可当作完整配置替换。
- 发布说明.md、上线步骤.md：变更及发布回滚指引。
- manifest.json：包内文件路径、大小及 SHA-256 校验值。
- ZIP 同目录的 .sha256 文件：整个压缩包校验值。

## 已知限制

- 后台同秒更新问题仍存在，本次仅提供巡检侧有限恢复措施。
- 重试只针对明确业务失败；网络异常不自动重试，避免无法判断首次写入结果时重复操作。
- 重试仍失败或数量复核不通过时，巡检保持失败并停止后续仓配步骤。
- 本包不是完整项目，依赖线上已有同代巡检目录、配置规范化函数和发货上下文模块。禁止解压后作为独立新项目运行。
