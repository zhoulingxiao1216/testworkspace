# 黑白名单及采购账号PRD

## 1. 项目背景与目标

### 1.1 项目背景

当前全球站存在以下问题：
- 缺乏IP管理功能，相关人员可以在任何地方登录后台，安全性不可控
- 采购账号是写死的，没有配置页面，人员变动时需要开发介入调整

### 1.2 优化目标

- 增强系统安全性，通过IP黑白名单控制登录权限
- 提供采购账号配置页面，支持灵活调整账号信息
- 实现1688和淘宝采购账号的授权管理
- 确保系统操作的安全性和灵活性
- 支持订单一键采购功能，提高采购效率
- 完善采购账号异常提醒机制，确保采购流程顺畅

## 2. 业务流程

### 2.1 IP黑白名单流程

1. 用户尝试登录系统
2. 系统检查用户IP：
   - 如果在黑名单：拒绝登录
   - 如果在白名单：允许登录
   - 如果不在黑白名单：允许登录但展示拦截提示页面
3. 管理员可以在后台管理黑白名单

### 2.2 采购账号授权流程

#### 2.2.1 1688采购账号管理流程

1. 管理员添加1688主账号信息
2. 点击"刷新子账号"获取子账号列表
3. 绑定平台账号
4. 配置完成后，系统可使用该账号进行一键采购操作

#### 2.2.2 淘宝采购账号授权流程

1. 管理员添加淘宝账号信息
2. 点击"授权"按钮，跳转到淘宝授权页面
3. 用户在淘宝页面完成授权
4. 系统获取授权信息，完成绑定
5. 配置完成后，系统可使用该账号进行一键采购操作

### 2.2.3 订单维度一键采购流程

1. 用户查看代购订单详情页面
2. 系统检查订单状态：
   - 如果订单状态为"进行中"：显示1688一件采购和淘宝一件采购按钮
   - 如果订单状态为其他状态：按钮置灰（不可点击）
3. 用户点击"1688一件采购"或"淘宝一件采购"按钮
4. 系统检查对应平台的采购账号配置：
   - 如果已配置启用状态的采购账号：自动调用采购接口进行采购
   - 如果未配置采购账号：提示"该账号没有绑定采购账号，无法进行一键采购！"
5. 采购成功后，更新采购信息

### 2.3 一键采购流程

1. 用户提交订单，选择一键采购选项
2. 系统检查是否配置了对应的采购账号：
   - 如果已配置：自动选择可用的采购账号进行操作
   - 如果未配置：弹出异常提醒，引导用户前往采购账号配置页面
3. 系统使用采购账号完成采购操作
4. 采购成功后，更新订单状态

## 4. 权限控制

| 角色 | 权限 |
|------|------|
| 管理员 | 可管理黑白名单、采购账号授权 |
| 授信账号 | 不受IP限制，可在任何地方登录 |

## 5. 页面详细设计

### 5.1 黑白名单页面

#### 5.1.1 核心业务逻辑介绍

黑白名单页面是管理员用来管理系统IP访问权限的核心页面，通过设置白名单和黑名单，实现对系统登录IP的控制，确保只有授权IP范围内的用户可以正常访问系统。

**功能概述：**
- 全局白名单：只有白名单IP范围内的用户可以登录系统
- 全局黑名单：黑名单IP的用户无法登录系统
- 拦截提醒：不在黑白名单的IP登录后，展示拦截提示页面，无法访问其他页面
- 有效日期管理："有效日期至"字段非必填，默认2099年12月30日
- 状态管理：禁用后变成普通IP，失去黑白名单功能

| 类型筛选 | 选择白名单或黑名单进行筛选 | 下拉选择，默认为全部 |
| 状态筛选 | 选择启用或禁用状态进行筛选 | 下拉选择，默认为全部 |
| 搜索按钮 | 点击执行搜索操作 | 无特殊异常处理 |
| 添加按钮 | 点击打开添加黑白名单弹窗 | 无特殊异常处理 |
| 批量删除按钮 | 点击删除选中的记录 | 至少选择一条记录，否则提示"请选择要删除的记录" |

##### (2) 底部列表展示字段区

| 字段/控件名称 | 功能展现描述 | 业务规则与异常边界处理 |

- 点击"添加"按钮：原生弹窗展示添加黑白名单表单
- 点击"编辑"按钮：原生弹窗展示编辑黑白名单表单
- 点击"状态"按钮：直接切换状态，无需弹窗
- 点击"批量删除"按钮：弹出确认对话框，确认后删除选中记录
- 搜索操作：页面局部刷新，显示搜索结果

#### 5.1.4 关联的隐藏后端模块及解决方案

- IP地址格式验证：后端需要验证IP地址格式是否正确
- 重复IP检查：后端需要检查是否已存在相同IP的记录
- 日期有效性检查：后端需要检查有效日期是否合理
- IP匹配逻辑：后端需要实现IP匹配算法，支持精确匹配和范围匹配
- 批量操作处理：后端需要支持批量删除操作
- 黑名单拦截：IP在黑名单中时拒绝登录，提示"您的IP已被列入黑名单"
- 白名单验证：IP不在黑白名单中时允许登录但展示拦截提示页面

### 5.3 1688采购账号管理页面

#### 5.3.1 核心业务逻辑介绍

1688采购账号管理页面是用来管理1688采购账号的核心页面，管理员可以添加1688主账号，刷新子账号，并进行账号管理，确保系统可以使用这些账号进行一键采购操作。

**功能概述：**
- 添加主账号：输入账号名称、账号ID、token等信息
- 刷新子账号：通过1688接口获取主账号下的子账号信息
- 绑定账号：绑定对应的平台账号，可进行一键采购
- 多应用支持：一个1688应用可绑定5个主账号，支持多个应用
- 启禁用管理：一个B2B后台账号可绑定多个1688账号，但同一时间只能有一个账号为启用状态

**启禁用规则：**
- 一个B2B后台账号可以绑定多个1688/淘宝采购账号
- 同一B2B后台账号下的所有1688和淘宝采购账号，只能有一个是启用状态
- 当某个采购账号改为启用时，该B2B后台账号下的其他采购账号自动变为禁用状态

- 启禁用互斥逻辑：当某个采购账号启用时，自动禁用同B2B后台账号下的其他采购账号

- 异常提醒：如果未配置采购账号，系统会弹出异常提醒，引导用户前往采购账号配置页面
- 一键采购流程：订单提交时，系统自动选择可用的采购账号进行操作，确保采购流程顺畅

### 5.5 淘宝采购账号授权页面

#### 5.5.1 核心业务逻辑介绍

淘宝采购账号授权页面是用来管理淘宝采购账号的核心页面，管理员可以添加淘宝账号，进行授权绑定，确保系统可以使用这些账号进行一键采购操作。

**功能概述：**
- 添加账号信息：输入账号名称、账号ID、卖家账号、手机号等
- 授权绑定：点击授权按钮，通过淘宝授权链接进行授权
- 授权到期提醒：授权即将到期时，账号标题上显示数字气泡提醒
- 异常提醒：授权到期后，系统弹出异常提醒，引导重新授权
- 一键采购：授权后可进行一键采购下单
- 启禁用管理：一个B2B后台账号可绑定多个淘宝账号，但同一时间只能有一个账号为启用状态

**启禁用规则：**
- 每个1688/淘宝采购账号都必须绑定到一个B2B后台账号
- 一个B2B后台账号可以绑定多个1688/淘宝采购账号
- 同一B2B后台账号下的所有1688和淘宝采购账号，只能有一个是启用状态
- 当某个采购账号改为启用时，该B2B后台账号下的其他采购账号自动变为禁用状态

## 6. 故障处理流程

### 6.1 常见故障场景

| 故障类型 | 故障描述 | 可能原因 |
|---------|---------|----------|
| IP黑白名单失效 | 用户无法登录系统或被错误拦截 | IP地址格式错误、黑白名单配置错误、系统IP检查逻辑异常 |
| 1688接口调用失败 | 无法获取子账号列表 | token过期、网络连接问题、1688接口变更 |
| 淘宝授权失败 | 授权流程无法完成 | 授权链接失效、网络连接问题、淘宝接口变更 |
| 采购账号无法使用 | 一键采购功能失败 | 账号未授权、token过期、绑定关系异常 |
| 采购账号未配置 | 一键采购时弹出异常提醒 | 未添加采购账号、账号配置不完整、账号状态为禁用 |
| 授权到期 | 账号标题显示数字气泡提醒或弹出异常提醒 | 授权时间到期、系统未及时更新授权信息 |
| 系统性能问题 | 页面加载缓慢、操作卡顿 | 数据库压力大、服务器资源不足、代码效率低 |
| 启禁用互斥异常 | 启用一个采购账号后其他账号未自动禁用 | 后端启禁用互斥逻辑执行失败、数据库事务异常 |
