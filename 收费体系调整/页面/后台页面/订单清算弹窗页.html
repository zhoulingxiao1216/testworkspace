费用名称 计算公式 说明
商品金额 下单数量 × 单价 客户下单时的数量和单价，系统自动计算。
变化金额 下单数量或修改数量 × 变化单价 当变动单价不为 0 时，按变化单价计算客户价。
实际支出 填写 采购时实际支出的金额。
预估国内运费 报价单预估国内运费 用于清算对比；实际国内运费以清算填写金额为准。
国内运费 填写 采购时商家收取的国内运费。
到付运费 填写 采购时国内运费为到付时的金额。
退换货运费 填写 产生退换货时支出的国内运费。
不良退款金额 不良商品数量 × 单价 退换货时对应的不良商品金额。
店铺其他费用 填写 该店铺产生的其他费用，如辅料、样品等。
订单其他费用 填写 该订单产生的其他费用，如托盘、叉车等。
店铺返现 填写 店铺给的返现金额；二次确认后才计入采购差额。
正品金额 正品数 × 单价或变化单价 质检后更新为正品的商品金额，系统自动计算。
没货退款金额 填写 已采购但商家没货时，商家退款的金额。
没货退款商品金额 没货商品数量 × 单价或变化单价 已采购但商家没货的商品数量对应金额。
没货退款差额 没货退款金额 - 没货退款商品金额（注：为负数时，差额为 0） 没货退款金额和没货退款商品金额可能不同。
店铺总退款 没货退款金额 + 不良退款金额 店铺总退款包含没货退款和不良商品退款。
客户价 正品金额 + 国内运费 + 退换货运费 + 到付金额 + 店铺其他费用 - 没货退款差额 客户需要支付的商品相关价格。
采购差额 正品金额 + 国内运费 + 不良退款金额 + 店铺返现 + 没货退款金额 - 实际支出 采购差额组成：1688商家商品价格优惠，店铺返现，国内物流让利，没货退还差额等部分；对应的是前台的“人工降价”。
报价单支付金额 商品金额 + 预估国内运费 + 预估检品费用 + 预估附加项费用 + 预估手续费 新增报价单支付口径，用于和实际结算金额对比。
实际结算金额 客户价 + 附加项费用 + 质检费用 + 订单其他费用 + 手续费 清算后的实际金额。
订单差额 实际结算金额 - 报价单支付金额 - 采购差额 服务费扣减项替换为采购差额，用于对比新旧公式口径。
总差价率 总差价 / 正品金额
汇率收益 正品金额 × 汇率增值比例/数值 汇率增值比例/数值在汇率配置中进行配置获得。
业绩差额 采购差额
订单收入利益 业绩差额 + 附加项费用 + 质检费用 + 汇率收益 + 手续费
国际物流客户价 国际物流客户运费 + 其他费用
国际物流成本价 国际物流成本运费 + 其他费用
物流收入利益 国际物流客户价 - 国际物流成本价
总收入利益 订单收入利益 + 物流收入利益 + 发货附加项客户费用 - 赔偿金 赔偿金在列表中手动添加，系统无法自动计算。
商品总价 正品金额 + 国内运费 + 店铺总退款
总差价 商品总价 - 实际支出
