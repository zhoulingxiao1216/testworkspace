## 一、报告摘要

本次在 main 环境对 B2B 核心接口链路进行两轮压测：**10 分钟基准压测** + **30 分钟稳定性压测**，用户模型均为 47 真实账号 + 53 虚拟访客 = **100 并发用户**。

**相对 2026-06-15 的唯一环境变量**：压测发起侧切换为**日本网络节点**（模拟日本用户访问路径）；压测脚本、账号池、并发模型与 06-15 保持一致，链路已包含**完整报价流程**（附加项 Step1/Step2 + `quote/create`）。

| 轮次 | 总请求 | 失败 | 失败率 | RPS | 平均响应 | P95 | 结论 |
|:--|--:|--:|--:|--:|--:|--:|:--|
| 10min | 37,362 | 0 | 0% | 62.2 | 941ms | 2700ms | **测试通过** |
| 30min | 145,058 | 29 | 0.020% | 80.6 | 640ms | 1500ms | **附条件通过** |

**综合发布结论：附条件通过。**

- 10min **零失败**，完整报价链路在日本节点下可稳定跑通。
- 30min 失败率 **0.020%**，较 06-15 同期（0.131%）显著下降；RPS 与响应时间全程无衰减迹象。
- 预热登录 **46 次 / 0 失败**（延续 06-15 已剔除 `performance_test_003` 策略）。
- **本轮共 3 类接口出现失败**（仅 30min；10min 为零）：

| 优先级 | 压测统计名 | API 路径 | 30min 失败 | 错误码（推断） |
|:--|:--|:--|--:|:--|
| 🟡 P2 | 商品加购_1688 | `POST /api_b2b/cart/add1688` | 1 / 6,085（0.016%） | 业务码异常（极少） |
| 🟡 P2 | 关键词浏览_taobao | `POST /api_tb/product/keyword` | 12 / 17,514（0.069%） | code=40000 |
| 🟡 P2 | 虚拟用户关键词查询_taobao | `POST /api_tb/product/keyword` | 16 / 25,524（0.063%） | code=40000 |

- **完整报价链路 7 类接口均为 0 失败**（附加项列表/保存/费用合计、Step1/Step2 明细与费用合计、提交报价单）。
- 相对 06-15：**1688 加购失败从 P1 级（~1.89%）降至可忽略**；代价是平均/P95 响应时间因日本节点 RTT 升高（见第七节对比）。

## 六、与 2026-06-15 对比（同场景 100 并发）

| 指标 | 06-15 10min | **06-16 10min** | 06-15 30min | **06-16 30min** |
|:--|:--|:--|:--|:--|
| 压测节点 | 国内 | **日本** | 国内 | **日本** |
| 报价链路 | 简化（直接 quote/create） | **完整 Step1/Step2** | 简化 | **完整** |
| 总请求 | 58,088 | 37,362 | 173,085 | 145,058 |
| 失败率 | 0.127% | **0%** | 0.131% | **0.020%** |
| 平均响应 | 417ms | **941ms (+524ms)** | 439ms | **640ms (+201ms)** |
| P95 | 1200ms | **2700ms (+1500ms)** | 1300ms | **1500ms (+200ms)** |
| RPS | 96.6 | 62.2 | 100.5 | 80.6 |
| 加购_1688 失败率 | 1.69% | **0%** | 1.89% | **0.016%** |
| 提交报价单 | 766 / 0 失败 | **384 / 0** | 2,265 / 0 | **1,545 / 0** |

**解读**：

1. **延迟升高**：日本节点下 RTT 增加，平均/P95 响应时间整体抬升，符合跨境访问预期。
2. **失败率大幅下降**：1688 加购从 06-15 的 P1 级问题降至近零；完整报价链路全部通过。
3. **吞吐下降**：完整链路单次任务 API 调用数约为简化链路的 3–4 倍，叠加网络延迟，RPS 低于 06-15 属正常现象。
4. **提交报价单次数**：06-16 的 384（10min）/ 1,545（30min）表示成功走完完整下单链路的次数，**不是**失败/总数格式。
