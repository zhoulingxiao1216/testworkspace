*(注：由于导出的字段顺序与现在的管理后台列表排版严丝合缝，这是典型的“导出贴合页面所见”优化。开发并没有写错，纯粹是旧版测试模板和 PRD 没有随着 UI 的改版而同步刷新。)*

**发现问题**：

   * 前两份核对通过的单据是因为其导出结构完美贴合了新版 UI，但这份单据并非如此。
   * 后台 UI 的字段实际上是高度聚合的（如 `物流信息` 包含了单号和物流方式，显示了 `状态`、`业务员` 和 `下单时间`）。

   * 原模板中的 `客户ID/名称` 被改为了 `客户信息`（且数据格式拼接成了“会员类型-客户ID”）。

   * 私自为 `重量` 和 `运费` 添加了 `(KG)` 和 `(CNY)` 后缀。
3. **数据状态判定修正**：
   * 在早前的未完全发货测试中，导出的 `发货时间` 字段均为空白，一度怀疑是取数 Bug。
