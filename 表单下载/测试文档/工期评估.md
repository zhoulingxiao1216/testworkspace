## 四、重点说明

### 4.1 重度前置环境要求

| 环境项 | 要求 | 阻塞影响 |
|--------|------|----------|
| 管理员账号 (admin) | 1 个，管理端全权限 | 阻塞 NP/IV/WB/PM/SH/OD 全部管理端用例 |
| 普通用户账号 | 2 个（用户 A + 用户 B），有实际订单 | 阻塞 MV/PV 归属判断、FD 用户端下载 |
| 发货单数据 | 至少 1 单含 2+ 不同订单的商品 | 阻塞 §5 合并逻辑验证 |
| 7182 客户订单 | 至少 1 单关联樱花站客户 | 阻塞 §6 ID 映射验证 |
| 进口商地址场景 | 4 种（相同/null/空字符串/正常） | 阻塞 §8 流通王 CONSIGNEE |
| 箱子二维码 | 至少 2 个有效箱子 | 阻塞 MV 扫码核对全流程 |
| 28 个 Excel 模板文件 | PM 提供的原始模板 | 阻塞 §10 模板交叉验证 |
| 字段获取.json | PRD 目录下已存在 | 阻塞 FD-016/SH-005/OD-004/OD-005 |

### 4.2 跨平台物理隔离要求

| 场景 | 设备要求 |
|------|----------|
| 移动端核对 (MV) | 手机浏览器（或 Chrome DevTools 375px 模拟） |
| PC 端核对 (PV) | PC 浏览器 |
| 跨端同步 (TC-MV-029) | 手机 + PC 同时登录同一账号 |
| 多语言 (FD-022/023) | 日本籍用户 + 非日本籍用户两个账号 |

### 4.3 风险预警

| 风险项 | 风险等级 | 缓解策略 |
|--------|----------|----------|
| 7182 客户数据不可用 | 高 | 提前确认樱花站→全球站的数据迁移状态 |
| 英文品名接口（樱花站）不稳定 | 中 | PM-002 预留降级验证场景 |
| 28 个 Excel 模板变更频繁 | 中 | E0 阶段锁定模板基线版本 |
| 移动端 H5 扫码依赖真机 | 低 | 可使用 Chrome DevTools 模拟，但真机验证更可靠 |
