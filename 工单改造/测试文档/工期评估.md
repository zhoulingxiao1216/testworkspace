# 工单改造测试工期评估

## 评估结论

建议测试周期：**5.5 人日**。  
若缺少后台权限、客户确认回传环境、可控历史工单数据，则至少需要增加 **1.0-1.5 人日** 数据构造与联调等待。

## 模块工期

| 模块 | 覆盖内容 | 用例量级 | 预计工期 |
| --- | --- | ---: | ---: |
| 需求审计与数据准备 | PRD、功能清单、流程图、角色/订单/商品/模板数据 | - | 0.6 人日 |
| 订单详情入口与创建工单 | 商品行入口、角标、创建弹窗、附件、历史工单 | 8-12 | 1.0 人日 |
| 工单详情与状态流转 | 非业务处理、业务对客、客户回复、同步、完结、关闭、转交 | 12-16 | 1.5 人日 |
| 我的待办 / 全部工单 | Tab、筛选、跳转、权限范围 | 6-8 | 0.8 人日 |
| 工单模板 | 新增、编辑、停用、删除、多语言、历史快照 | 5-7 | 0.6 人日 |
| 客户确认回传 | 客户选择、原文、翻译、多轮沟通 | 4-6 | 0.5 人日 |
| 权限、安全、并发专项 | 角色越权、数据权限、状态版本、日志与附件安全 | 6-8 | 0.8 人日 |
| 回归与报告 | 缺陷复测、执行报告、上线风险整理 | - | 0.7 人日 |

## 前置依赖

- 可登录的质检、采购、业务、普通员工、全量工单权限账号。
- 至少 3 个代购订单，覆盖无工单、有未完结、多工单、全完结、同规格不同商品ID。
- 客户确认页或回调接口可用。
- 后端日志或审计记录可查询。
- 可模拟图片上传失败和状态版本冲突。
