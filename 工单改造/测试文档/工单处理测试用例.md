# 工单处理测试用例

> Agent1 生成。用例前缀：`WO` 表示 WorkOrder。执行时需结合真实账号、订单商品、后台权限和客户确认回传环境。

## 1. 订单详情入口

### TC-WO-ENTRY-001 【SmokeTest】无工单商品显示创建工单

| 字段 | 内容 |
|:--|:--|
| 测试点 | 订单商品行工单入口初始态 |
| 优先级 | P0 |
| 前置条件 | 代购订单中存在无工单商品行，当前用户有创建权限 |
| 步骤 | 1. 打开代购订单详情页<br>2. 定位无工单商品行<br>3. 查看工单入口 |
| 预期 | 显示“创建工单”；状态为“暂无工单”；不显示未完结数量角标。 |

### TC-WO-ENTRY-002 【SmokeTest】有未完结工单显示工单处理和角标

| 字段 | 内容 |
|:--|:--|
| 测试点 | 商品行未完结工单聚合 |
| 优先级 | P0 |
| 前置条件 | 商品行存在 2 条未完结工单 |
| 步骤 | 1. 打开订单详情<br>2. 查看该商品行工单入口 |
| 预期 | 显示“工单处理”；按钮内红色角标为 2；下方展示最新未完结工单状态。 |

### TC-WO-ENTRY-003 【回归】工单完结后角标剔除

| 字段 | 内容 |
|:--|:--|
| 测试点 | 未完结数量计算 |
| 优先级 | P1 |
| 前置条件 | 商品行存在 1 条未完结、1 条已完结工单 |
| 步骤 | 1. 发起人确认完结未完结工单<br>2. 回到订单商品行刷新<br>3. 查看角标 |
| 预期 | 未完结数量减少；全部完结后不再显示红色数量角标。 |

### TC-WO-ENTRY-004 【Security】无权限用户入口置灰且接口拒绝

| 字段 | 内容 |
|:--|:--|
| 测试点 | 工单入口权限 |
| 优先级 | P0 |
| 前置条件 | 使用无该订单处理权限账号 |
| 步骤 | 1. 打开订单详情<br>2. 尝试创建或处理工单<br>3. 直接调用创建/处理接口 |
| 预期 | 前端置灰或提示无权限；后端返回无权限；不产生工单或记录。 |
