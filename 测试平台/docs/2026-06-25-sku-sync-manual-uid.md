# SKU 批量同步 — 手动填写客户 UID

- 日期：2026-06-25
- 修改文件：`pages/4_sku_bulk_sync.py`
- 修改类型：修改
- 描述：侧边栏增加「手动填写客户 UID」，无需预先写入 sku_accounts.json

## 变更摘要

### 变更点 1：客户选择方式
- 变更原因：每次新增测试客户都要改 sku_accounts.json，不便
- 变更方式：下拉首项为「手动填写客户 UID」，选中后显示输入框；预设账号仍可从列表选择

### 变更点 2：accounts 可为空
- 变更原因：仅用手动 UID 时不应强制配置 json
- 变更方式：移除 accounts 为空时的 st.stop()，改为 UID 未填或非法时提示并阻止后续操作
