# 7182词搜接口测试用例

> 用例前缀来自 `superpowers.md` 模块缩写配置表。执行账号、Token、Secret 仅使用安全凭据引用，不在本文档记录明文。

## 1. 统一认证 AUTH

### 1.1 Token 获取

#### TC-AUTH-001 【Critical·Security】正确凭据获取 Bearer Token [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 正确 `client_key/client_secret` 获取 Token |
| **优先级** | Critical |
| **前置条件** | 测试环境存在启用状态的 7182 客户 `SKR7182`，测试人员通过安全账号引用获取正确 Secret |
| **操作步骤** | 1. 调用 `POST /open_api/v1/auth/token`<br>2. 请求体传入 `client_key=SKR7182` 和正确 `client_secret`<br>3. 查看响应和认证日志 |
| **预期结果** | 1. 返回 200<br>2. 返回 `access_token`、`token_type=Bearer`、`expires_in`<br>3. 日志记录 client、IP、结果，不记录 Secret 明文 |

#### TC-AUTH-002 【异常】缺少 client_key 或 client_secret 返回日文错误

| 字段 | 内容 |
|:--|:--|
| **测试点** | Token 获取接口必填参数校验 |
| **优先级** | High |
| **前置条件** | Token 获取接口可访问 |
| **操作步骤** | 1. 调用 Token 接口仅传 `client_key`<br>2. 调用 Token 接口仅传 `client_secret`<br>3. 调用 Token 接口两个字段均为空 |
| **预期结果** | 1. 均返回 400<br>2. message 为日文必填提示<br>3. 不生成 Token，失败日志不记录 Secret 明文 |

#### TC-AUTH-003 【Critical·Security】错误凭据不生成 Token [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 错误 `client_secret` 鉴权拦截 |
| **优先级** | Critical |
| **前置条件** | 存在启用客户 `SKR7182` |
| **操作步骤** | 1. 调用 Token 接口传入 `client_key=SKR7182` 和错误 Secret<br>2. 查看响应<br>3. 查询调用日志记录 |
| **预期结果** | 1. 返回 401<br>2. message 为 `認証情報が無効です` 或等价日文认证错误<br>3. 不返回 access_token，日志记录失败分类但不记录错误 Secret 明文 |

#### TC-AUTH-004 【Critical·Security】禁用客户无法获取 Token [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 客户禁用状态对 Token 获取生效 |
| **优先级** | Critical |
| **前置条件** | 准备禁用状态的 7182 客户或由后台禁用测试客户 |
| **操作步骤** | 1. 使用禁用客户凭据调用 Token 接口<br>2. 查看响应和后台日志 |
| **预期结果** | 1. 返回 403<br>2. message 为 `APIアクセスが無効になっています`<br>3. 不生成 Token，写入禁用访问日志 |

### 1.2 Bearer Token 使用

#### TC-AUTH-005 【Critical·Security】业务接口缺少 Token 被拦截 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 搜索、详情、状态查询必须携带 Bearer Token |
| **优先级** | Critical |
| **前置条件** | 搜索、详情、状态查询接口均可访问 |
| **操作步骤** | 1. 不带 Authorization 调用 `/product/search`<br>2. 不带 Authorization 调用 `/product/detail`<br>3. 不带 Authorization 调用 `/product/status_v2` |
| **预期结果** | 1. 三类业务接口均返回 401<br>2. message 为日文 Token 必填提示<br>3. 不调用 1688，不查询商品状态业务数据 |

#### TC-AUTH-006 【Critical·Security】无效或过期 Token 被拦截 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | Token 无效、签名错误、过期的拦截 |
| **优先级** | Critical |
| **前置条件** | 准备无效 Token、过期 Token、篡改签名 Token |
| **操作步骤** | 1. 分别携带三类 Token 调用 `/product/search`<br>2. 分别携带三类 Token 调用 `/product/status_v2`<br>3. 查看错误响应和日志 |
| **预期结果** | 1. 均返回 401<br>2. 无效 Token 提示 `認証トークンが無効です`，过期 Token 提示 `認証トークンが期限切れです`<br>3. 日志只记录 Token 摘要，不记录原值 |

#### TC-AUTH-007 【Critical·Security】Token 不允许通过 query 传递 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | Token 放置位置安全限制 |
| **优先级** | Critical |
| **前置条件** | 准备有效 Bearer Token |
| **操作步骤** | 1. 将 Token 拼到 `/product/search?access_token=...` 调用<br>2. 不传 Authorization 头<br>3. 查询调用日志中的路径和参数摘要 |
| **预期结果** | 1. 接口按未认证返回 401<br>2. 不因为 query Token 通过认证<br>3. 日志不展示 query 中 Token 明文 |
