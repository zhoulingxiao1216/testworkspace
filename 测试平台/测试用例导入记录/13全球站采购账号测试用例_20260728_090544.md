# 13全球站采购账号 测试用例

> 设计依据：`superpowers.md`、`测试点大纲.md`、`需求文档.docx`、页面原型和导出样例。  
> 覆盖范围：1688/淘宝采购账号绑定、代购订单一键下单、采购主体管理、采购额度预警、采购金额统计、权限与审计。  
> 用例总数：54 条，其中 Critical 29 条、High 24 条、Medium 1 条。

## 1. 1688 采购账号绑定 PA-AL

### 1.1 公司名称与绑定状态

#### TC-PA-AL-001 【正向】1688列表展示并筛选公司名称
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 1688 列表页账号名称后展示公司名称并支持公司名称筛选。 |
| **优先级** | High |
| **前置条件** | 1. Admin-Global-Full 登录后台。<br>2. 1688 已存在哲顺、协润、协樱三个主体账号。 |
| **操作步骤** | 1. 进入 1688 采购账号授权列表。<br>2. 查看账号名称与公司名称展示。<br>3. 使用公司名称下拉分别筛选协润、哲顺、协樱。 |
| **预期结果** | 1. 每条账号记录在账号名称后展示所属公司名称。<br>2. 公司名称筛选项包含启用主体。<br>3. 筛选后列表仅展示对应公司主体账号，清空筛选后恢复全量。 |

#### TC-PA-AL-002 【重点·异常】1688新增账号公司名称必填且来源于启用主体
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 新增/编辑 1688 采购账号时公司名称必填且来源于启用采购主体。 |
| **优先级** | Critical |
| **前置条件** | 1. 存在启用主体协润、哲顺、协樱。<br>2. 协樱主体可在采购主体管理中切换启用/禁用。 |
| **操作步骤** | 1. 打开 1688 新增账号弹窗。<br>2. 不选择公司名称尝试保存。<br>3. 选择协润后填写其他必填字段保存。<br>4. 禁用协樱主体后再次打开新增账号弹窗。 |
| **预期结果** | 1. 公司名称为空时保存被阻断并提示必填。<br>2. 选择启用主体后保存成功，列表展示对应公司名称。<br>3. 协樱禁用后不再出现在新增账号公司名称下拉中。 |

#### TC-PA-AL-003 【重点·正向】1688主账号支持绑定并参与一键采购
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 1688 主账号支持绑定账号进行一键采购。 |
| **优先级** | Critical |
| **前置条件** | 1. 1688-zheshun 主账号已授权。<br>2. 主账号状态为启用并绑定到当前后台账号。<br>3. 存在可一键下单的代购订单。 |
| **操作步骤** | 1. 在 1688 账号列表确认主账号处于启用并绑定状态。<br>2. 进入代购订单详情点击 1688 一键下单。<br>3. 查看订单预览采购账号选项。 |
| **预期结果** | 1. 主账号可保存绑定关系。<br>2. 订单预览中展示该主账号。<br>3. 选择该主账号后可进入后续采购确认流程。 |

#### TC-PA-AL-004 【重点·正向】多个1688绑定账号同时启用均可使用
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 多个 1688 绑定账号同时启用后均可用于一键采购。 |
| **优先级** | Critical |
| **前置条件** | 1. 当前后台账号绑定 1688-zheshun、1688-xierun、1688-xieying。<br>2. 三个绑定账号状态均为启用。 |
| **操作步骤** | 1. 保存三个启用状态。<br>2. 进入代购订单详情点击 1688 一键下单。<br>3. 分别选择三个账号进行预览校验。 |
| **预期结果** | 1. 保存时不触发旧的单点启用互斥逻辑。<br>2. 订单预览中三个账号均可见且可选择。<br>3. 启用其中一个账号不会自动禁用另外两个账号。 |

#### TC-PA-AL-005 【正向】删除全部1688绑定账号后允许保存
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 删除所有 1688 绑定账号也可以保存，无需提醒至少保存一条。 |
| **优先级** | High |
| **前置条件** | 1. 某 1688 采购账号已绑定至少 1 个后台账号。<br>2. 操作账号具备编辑权限。 |
| **操作步骤** | 1. 打开该 1688 采购账号编辑弹窗。<br>2. 删除所有绑定账号。<br>3. 点击保存。<br>4. 进入订单详情点击 1688 一键下单。 |
| **预期结果** | 1. 保存成功，不出现“至少保留一条”类旧提示。<br>2. 该采购账号绑定账号数量为 0。<br>3. 订单预览中不再展示该采购账号。 |

#### TC-PA-AL-006 【正向】取消绑定1688账号后订单预览不展示
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 取消绑定 1688 账号后，订单预览不再展示该账号。 |
| **优先级** | High |

| **操作步骤** | 1. 在 1688 账号管理中取消当前后台账号与 1688-xierun 的绑定。<br>2. 保存后刷新订单详情。<br>3. 点击 1688 一键下单。 |
| **预期结果** | 1. 取消绑定保存成功。<br>2. 订单预览账号列表不再出现 1688-xierun。<br>3. 其他仍绑定且启用的账号不受影响。 |

#### TC-PA-AL-007 【异常】1688禁用或授权异常账号不可用于一键采购
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | Token 失效、接口异常、账号禁用时不进入订单预览可选账号。 |
| **优先级** | Critical |
| **前置条件** | 1. 准备 1688-token-expired、1688-disabled 两个账号。<br>2. 两个账号均曾绑定当前后台账号。 |
| **操作步骤** | 1. 将 1688-token-expired Mock 为 Token 失效。<br>2. 将 1688-disabled 设置为禁用。<br>3. 点击 1688 一键下单。 |
| **预期结果** | 1. Token 失效账号不展示或展示为不可选并给出授权异常提示。<br>2. 禁用账号不进入可选账号列表。<br>3. 若无其他可用账号，页面提示没有绑定可用 1688 采购账号。 |
