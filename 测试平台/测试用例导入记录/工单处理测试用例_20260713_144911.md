# 工单改造测试用例

> Agent1 重跑版本：2026-07-13  
> 用例来源：`测试点大纲.md`、`审计待确认问题单.md`、PRD / 功能清单 / 流程图 / 页面原型 / Vue 脚本复核结果。  
> 优先级枚举：`Critical`、`High`、`Medium`、`Low`。  
> 执行说明：涉及接口鉴权、状态版本、客户回调、历史工单权限、附件失败等场景，必须结合真实后端或接口模拟；仅验证静态原型不算通过。

## 1. 需求审计与原型一致性

#### TC-WO-AUD-001 【重点·异常】目标语言缺失规则冲突审计

| 字段 | 内容 |
|:--|:--|
| **测试点** | PRD 与原型脚本冲突识别：目标语言缺失 |
| **优先级** | Critical |
| **前置条件** | 存在客户语言为日语的订单；存在缺少日语内容但有中文内容的启用模板；可查看 PRD 和模板原型 |
| **操作步骤** | 1. 在工单模板页打开该模板并查看日语页签预览<br>2. 在订单详情中创建使用该模板的工单<br>3. 以订单业务身份准备发送客户确认<br>4. 检查发送内容和系统提示 |
| **预期结果** | 1. 审计记录应标明 PRD 要求目标语言缺失时提示补充，不得静默发送空内容<br>2. 若系统自动回退中文发送，应标记为需求冲突或缺陷<br>3. 未经产品确认前，该场景不得判定为通过 |
| **备注** | 关联 `审计待确认问题单.md` BQ-005、DIFF-001。 |

#### TC-WO-AUD-002 【重点·异常】客户空选择规则冲突审计

| 字段 | 内容 |
|:--|:--|
| **测试点** | 客户选择结果为空不得进入客户已回复 |
| **优先级** | Critical |
| **前置条件** | 工单已发送客户确认；可通过接口或回调模拟客户 choice 为空；原型 UI 默认选择“可以接受” |
| **操作步骤** | 1. 在 UI 中查看客户选择结果默认值<br>2. 通过接口提交空 choice 和有效客户原文<br>3. 查看工单状态、客户沟通记录和业务待办 |
| **预期结果** | 1. UI 默认值不能替代后端空值校验<br>2. 空 choice 回调应被拒绝或保持待客户确认<br>3. 不得生成客户已回复状态、客户沟通记录或同步客户信息待办 |
| **备注** | 关联 `审计待确认问题单.md` HQ-002、DIFF-002。 |

#### TC-WO-AUD-003 【重点·异常】完结权限前后端差异审计

| 字段 | 内容 |
|:--|:--|
| **测试点** | 发起人确认完结权限与原型脚本差异 |
| **优先级** | Critical |
| **前置条件** | 准备三类账号：工单发起人、当前处理人但非发起人、同名或同部门但非发起人；工单处于客户已确认 |
| **操作步骤** | 1. 分别用三类账号打开工单详情<br>2. 检查确认完结按钮显隐<br>3. 分别直接调用完结接口 |
| **预期结果** | 1. 只有真实工单发起人可看到并成功执行确认完结<br>2. 当前处理人但非发起人、同名或同部门但非发起人均应被前端隐藏并被后端拒绝<br>3. 若前端因同名或当前处理人误放行，应记录缺陷 |
| **备注** | 关联 `审计待确认问题单.md` HQ-003、DIFF-003。 |

#### TC-WO-AUD-004 【重点】Blocking 问题执行门禁

| 字段 | 内容 |
|:--|:--|
| **测试点** | 需求未确认时的执行门禁 |
| **优先级** | Critical |
| **前置条件** | `审计待确认问题单.md` 中 BQ-001 至 BQ-005 仍有未确认项 |
| **操作步骤** | 1. 执行涉及状态版本、关闭/完结边界、全部工单权限、历史规格 Key、目标语言缺失的用例<br>2. 检查执行记录和最终结论 |
| **预期结果** | 1. 未确认规则相关用例应允许进入“执行阻塞”或“待确认”状态<br>2. 不得将阻塞场景计入通过<br>3. 最终报告不得在 Blocking 未关闭时写“测试通过” |

## 2. 订单详情商品行入口

#### TC-WO-ENTRY-001 【正向】无工单商品行显示创建入口

| 字段 | 内容 |
|:--|:--|
| **测试点** | 无工单商品行入口状态 |
| **优先级** | High |
| **前置条件** | 存在当前用户有订单商品查看和工单创建权限的代购订单；订单中至少 1 个商品行无任何工单 |
| **操作步骤** | 1. 打开代购订单详情页<br>2. 定位无工单商品行<br>3. 查看工单入口、状态摘要和数量角标 |
| **预期结果** | 1. 商品行显示“创建工单”入口<br>2. 不展示未完结数量角标<br>3. 状态摘要显示暂无工单或不展示工单状态<br>4. 点击入口打开创建工单弹窗并带入当前商品快照 |

#### TC-WO-ENTRY-002 【正向】有未完结工单显示处理入口和角标

| 字段 | 内容 |
|:--|:--|
| **测试点** | 有未完结工单商品行入口状态和数量聚合 |
| **优先级** | High |
| **前置条件** | 商品行存在 2 条未完结工单，状态分别为待处理和待客户确认；当前用户有查看权限 |
| **操作步骤** | 1. 打开订单详情页<br>2. 定位该商品行<br>3. 查看工单入口、红色数量角标和状态摘要 |
| **预期结果** | 1. 商品行显示“工单处理”入口<br>2. 红色数量角标为 2，仅统计未完结工单<br>3. 状态摘要展示最新未完结工单状态<br>4. 点击入口打开工单详情并默认定位最新未完结工单 |

#### TC-WO-ENTRY-003 【回归】多工单商品按最新未完结状态摘要

| 字段 | 内容 |
|:--|:--|
| **测试点** | 多工单商品行状态摘要规则 |
| **优先级** | High |
| **前置条件** | 商品行存在 1 条已完结历史工单、1 条较早待处理工单、1 条最新客户已回复工单 |
| **操作步骤** | 1. 打开订单详情页<br>2. 查看该商品行工单状态摘要<br>3. 打开工单详情查看左侧工单列表顺序 |
| **预期结果** | 1. 商品行摘要展示最新未完结工单“客户已回复”<br>2. 未完结数量不包含已完结工单<br>3. 工单详情左侧仍保留已完结工单用于查看 |

#### TC-WO-ENTRY-004 【回归】全部完结后角标剔除且历史可查看

| 字段 | 内容 |
|:--|:--|
| **测试点** | 全部完结商品行入口状态 |
| **优先级** | Medium |
| **前置条件** | 商品行所有工单均为已完结；当前用户有查看历史权限 |
| **操作步骤** | 1. 打开订单详情页<br>2. 查看该商品行工单入口和角标<br>3. 点击工单入口查看历史工单 |
| **预期结果** | 1. 不显示红色未完结数量角标<br>2. 状态摘要显示暂无未完结工单或仅保留入口<br>3. 已完结工单仍可在详情列表中查看，所有编辑动作隐藏 |

#### TC-WO-ENTRY-005 【重点】展示序号与内部唯一ID分离

| 字段 | 内容 |
|:--|:--|
| **测试点** | 工单编号展示序号不是接口主键 |
| **优先级** | Critical |
| **前置条件** | 两个不同商品行均存在展示编号为 001 的工单；可抓取或查看接口请求 |
| **操作步骤** | 1. 分别打开两个商品行的 001 工单<br>2. 查看详情请求、转交请求或提交意见请求中的工单标识<br>3. 尝试仅用展示序号调用处理接口 |
| **预期结果** | 1. 页面可展示相同序号 001，但内部请求使用不同唯一ID<br>2. 仅用展示序号不得定位或处理工单<br>3. 不得出现跨商品误处理、串单或覆盖记录 |

#### TC-WO-ENTRY-006 【重点】商品删除拆分合并后保留工单快照

| 字段 | 内容 |
|:--|:--|
| **测试点** | 商品行绑定和商品快照追溯 |
| **优先级** | Critical |
| **前置条件** | 准备已创建工单的商品行，并在测试环境模拟商品删除、拆分或合并；保留原工单数据 |
| **操作步骤** | 1. 打开订单详情和工单详情<br>2. 查看工单商品图、商品名称、商品ID、规格、客户、国家、提出人、创建时间<br>3. 查看历史记录中的商品快照 |
| **预期结果** | 1. 工单仍可通过订单或历史入口追溯<br>2. 商品快照显示创建时数据，不因商品删除、拆分、合并丢失<br>3. 字段缺失时展示“--”或占位图，不阻断查看 |

#### TC-WO-ENTRY-007 【回归】内部备注与辅助图标不参与工单状态

| 字段 | 内容 |
|:--|:--|
| **测试点** | 内部备注、特殊物品、黑名单、吐槽与工单状态隔离 |
| **优先级** | Medium |
| **前置条件** | 商品行存在内部备注、特殊物品、黑名单、吐槽图标；该商品无工单或只有已完结工单 |
| **操作步骤** | 1. 打开订单详情页<br>2. 查看内部备注入口和三个辅助图标<br>3. 检查工单入口、状态摘要和数量角标 |
| **预期结果** | 1. 内部备注不会自动生成工单记录<br>2. 特殊物品、黑名单、吐槽只作为辅助标识或快捷入口<br>3. 三类图标不参与工单数量和最新状态计算 |

#### TC-WO-ENTRY-008 【Critical·Security】无权限用户入口置灰且接口拒绝

| 字段 | 内容 |
|:--|:--|
| **测试点** | 工单入口权限后端兜底 |
| **优先级** | Critical |
| **前置条件** | 使用无该订单查看或工单处理权限的员工账号；准备可抓取接口请求的环境 |
| **操作步骤** | 1. 用无权限账号打开订单详情<br>2. 尝试查看、创建或处理工单<br>3. 直接调用创建、详情、处理接口 |
| **预期结果** | 1. 前端入口隐藏、置灰或提示无权限<br>2. 后端接口返回无权限<br>3. 不产生工单、处理记录、客户沟通记录或日志副作用 |

## 3. 创建工单弹窗

#### TC-WO-CREATE-001 【正向】填写必填项创建工单成功

| 字段 | 内容 |
|:--|:--|
| **测试点** | 创建工单主流程 |
| **优先级** | High |
| **前置条件** | 当前用户有创建工单权限；商品行无未完结工单；处理人列表存在采购处理人 |
| **操作步骤** | 1. 点击商品行“创建工单”<br>2. 选择一个处理人<br>3. 填写问题内容<br>4. 点击提交并进入处理人待办 |
| **预期结果** | 1. 工单创建成功，初始状态为待处理<br>2. 当前处理人为所选处理人，发起人为当前登录人<br>3. 所选处理人的我的待办出现该工单<br>4. 订单商品行入口刷新为“工单处理”并展示未完结角标 |

#### TC-WO-CREATE-002 【异常】处理人和问题内容必填

| 字段 | 内容 |
|:--|:--|
| **测试点** | 创建表单必填校验 |
| **优先级** | High |
| **前置条件** | 打开创建工单弹窗 |
| **操作步骤** | 1. 不选处理人提交<br>2. 选择处理人但不填问题内容提交<br>3. 问题内容仅输入空格或换行提交 |
| **预期结果** | 1. 三种情况均阻止提交<br>2. 页面提示处理人或问题内容必填<br>3. 已填写字段和已上传附件不丢失<br>4. 后端不得生成空工单 |

#### TC-WO-CREATE-003 【重点】处理人单选且质控角色过滤

| 字段 | 内容 |
|:--|:--|
| **测试点** | 单处理人闭环与质控角色过滤 |
| **优先级** | Critical |
| **前置条件** | 人员数据包含质控初检、组长、主管以及其他质控角色；创建工单弹窗已打开 |
| **操作步骤** | 1. 打开处理人下拉<br>2. 查看可选人员和部门显示<br>3. 尝试通过前端或接口提交多个处理人<br>4. 尝试提交被过滤的质控角色 |
| **预期结果** | 1. 下拉仅允许单选处理人<br>2. 质控部门只展示初检、组长、主管<br>3. 接口拒绝多个当前处理人或被过滤人员<br>4. 创建后工单只有一个当前处理人 |

#### TC-WO-CREATE-004 【重点】选择模板只回填中文且允许手动编辑

| 字段 | 内容 |
|:--|:--|
| **测试点** | 创建阶段模板语言规则 |
| **优先级** | Critical |
| **前置条件** | 存在包含中文、英文、日文内容的启用模板；订单客户语言为日语或英语 |
| **操作步骤** | 1. 创建工单选择该模板<br>2. 查看问题内容<br>3. 手动编辑问题内容并切换其他字段<br>4. 提交工单后查看工单内容记录 |
| **预期结果** | 1. 创建阶段只回填中文模板内容，不因订单国家或处理人角色回填外语<br>2. 用户手动编辑内容后不得被无故覆盖<br>3. 历史记录保存创建时实际问题内容快照 |

#### TC-WO-CREATE-005 【异常】问题内容纯文本保留换行并处理脚本输入

| 字段 | 内容 |
|:--|:--|
| **测试点** | 问题内容输入和展示安全 |
| **优先级** | High |
| **前置条件** | 打开创建工单弹窗 |
| **操作步骤** | 1. 输入多行问题内容并提交<br>2. 输入包含 HTML 标签或脚本片段的问题内容并提交<br>3. 在详情、历史记录、待办摘要中查看展示 |
| **预期结果** | 1. 多行内容在展示处保留换行可读性<br>2. 富文本或脚本片段按纯文本处理，不执行脚本<br>3. 待办摘要不撑破布局，详情可查看完整内容 |

#### TC-WO-CREATE-006 【正向】实物图和链接图分组上传展示

#### TC-WO-CREATE-007 【异常】点击拖拽粘贴上传失败不丢表单

#### TC-WO-CREATE-008 【重点】同规格不同商品ID历史工单可召回

| 字段 | 内容 |
|:--|:--|
| **测试点** | 历史工单规格匹配 |
| **优先级** | Critical |
| **前置条件** | 当前商品 A 与历史商品 B 商品ID不同，但商品名称、颜色、尺码、属性标准化后相同；历史商品 B 有工单 |
| **操作步骤** | 1. 打开商品 A 创建工单弹窗<br>2. 查看历史工单模块<br>3. 按客户ID、订单编号、问题类型分别筛选 |
| **预期结果** | 1. 历史工单模块召回商品 B 的同规格工单<br>2. 筛选只在同规格结果内收窄<br>3. 创建弹窗历史工单展示订单编号、客户编号、工单模板、创建时间和摘要，不展示状态<br>4. 结果按创建时间倒序 |

#### TC-WO-CREATE-009 【Critical·Security】历史工单不召回近似规格和无权限订单

| 字段 | 内容 |
|:--|:--|
| **测试点** | 历史工单规格误召回和权限过滤 |
| **优先级** | Critical |
| **前置条件** | 准备近似名称但颜色或尺码不同的历史工单；准备无权限订单的同规格历史工单；当前账号无该订单权限 |
| **操作步骤** | 1. 打开当前商品创建工单弹窗<br>2. 查看历史工单结果<br>3. 直接调用历史工单检索接口查询同规格条件 |
| **预期结果** | 1. 近似规格但标准化 Key 不一致的数据不得召回<br>2. 无权限订单历史工单不得在 UI 或接口返回中出现<br>3. 接口不得暴露无权限订单编号、客户编号、摘要或模板信息 |

#### TC-WO-CREATE-010 【交互】历史工单查看新开 Tab 不覆盖创建弹窗

| 字段 | 内容 |
|:--|:--|
| **测试点** | 历史工单跳转方式 |

| **优先级** | Critical |
| **前置条件** | 工单已发送客户确认；同一确认ID可重复调用回调接口 |
| **操作步骤** | 1. 使用同一确认ID提交客户回复<br>2. 使用同一确认ID再次提交相同回复<br>3. 使用同一确认ID再次提交不同回复<br>4. 查看状态和客户沟通记录 |
| **预期结果** | 1. 首次有效回调进入客户已回复<br>2. 重复相同回调不得重复生成客户沟通记录或业务待办<br>3. 重复不同回调应被拒绝或按产品确认规则保留审计<br>4. 不得覆盖已同步或已完结结果 |

#### TC-WO-CUST-007 【异常】错误确认ID过期ID和已完结回调拦截

| 字段 | 内容 |
|:--|:--|
| **测试点** | 客户回调异常拦截 |
| **优先级** | Critical |
| **前置条件** | 准备错误确认ID、过期确认ID或产品确认的失效场景；准备已完结工单的旧确认ID |
| **操作步骤** | 1. 使用错误确认ID提交回复<br>2. 使用过期确认ID提交回复<br>3. 对已完结工单提交旧确认ID回调 |
| **预期结果** | 1. 错误确认ID被拒绝且不暴露有效工单信息<br>2. 过期确认ID按规则拒绝<br>3. 已完结工单不得被客户回调重新打开或覆盖历史记录<br>4. 异常回调进入安全或接口日志 |
| **备注** | 有效期规则受 HQ-010 影响。 |

#### TC-WO-CUST-008 【回归】多轮客户沟通历史倒序且不重复

| 字段 | 内容 |
|:--|:--|
| **测试点** | 多轮客户沟通记录展示 |
| **优先级** | High |
| **前置条件** | 工单已有两轮业务发送和两轮客户回复 |
| **操作步骤** | 1. 打开工单详情客户沟通分类<br>2. 打开全部分类<br>3. 查看每轮发送、回复和图片 |
| **预期结果** | 1. 客户沟通按时间倒序展示<br>2. 每轮业务发送和客户回复均保留独立内容、图片和选择结果<br>3. 同一沟通记录不重复展示<br>4. 全部分类中客户沟通与内部处理混排仍可区分 |

## 9. 接口安全与数据一致性专项

#### TC-WO-SEC-001 【Critical·Security】后端不信任前端隐藏状态

| 字段 | 内容 |
|:--|:--|
| **测试点** | 接口后端鉴权和状态校验 |
| **优先级** | Critical |
| **前置条件** | 可直接调用创建、提交意见、转交、发送客户、确认同步、完结接口 |
| **操作步骤** | 1. 篡改前端隐藏状态或按钮限制<br>2. 在错误角色、错误状态下分别调用关键接口<br>3. 查看工单数据和历史记录 |
| **预期结果** | 1. 后端根据登录人、角色、当前处理人、发起人、工单状态进行校验<br>2. 错误角色或错误状态请求被拒绝<br>3. 不产生任何业务副作用或脏历史记录 |

#### TC-WO-SEC-002 【Critical·Security】历史工单和全部工单不可被枚举

| 字段 | 内容 |
|:--|:--|
| **测试点** | 数据权限防枚举 |
| **优先级** | Critical |
| **前置条件** | 当前账号无部分订单权限；已知无权限订单号、客户ID、商品规格 |
| **操作步骤** | 1. 在全部工单使用无权限订单号和客户ID搜索<br>2. 在历史工单接口使用同规格条件查询<br>3. 尝试通过分页、排序或模糊搜索枚举 |
| **预期结果** | 1. 无权限数据不返回、不计数、不展示摘要<br>2. 搜索无权限关键字不暴露订单号、客户号、工单编号或状态<br>3. 历史工单和全部工单权限口径一致 |

#### TC-WO-SEC-003 【Critical·Security】已完结工单编辑接口拒绝

| 字段 | 内容 |
|:--|:--|
| **测试点** | 已完结状态不可变更 |
| **优先级** | Critical |
| **前置条件** | 工单状态为已完结；可直接调用编辑类接口 |
| **操作步骤** | 1. 调用提交意见接口<br>2. 调用转交接口<br>3. 调用发送客户接口<br>4. 调用确认同步或附件删除接口 |
| **预期结果** | 1. 所有编辑类接口均拒绝已完结工单<br>2. 工单状态保持已完结<br>3. 历史记录和附件不被修改<br>4. 非法请求进入审计或安全日志 |

#### TC-WO-SEC-004 【异常】附件边界和重复去重

| 字段 | 内容 |
|:--|:--|
| **测试点** | 附件格式、大小、数量和重复上传 |
| **优先级** | High |
| **前置条件** | 后端已提供附件格式、大小、数量和去重规则；准备合法、超限、重复和损坏文件 |
| **操作步骤** | 1. 上传合法 JPG、PNG、WebP<br>2. 上传超限大小或不允许格式<br>3. 重复粘贴同一张图片<br>4. 超过数量上限继续上传 |
| **预期结果** | 1. 合法文件按实物图或链接图分组成功<br>2. 非法文件被拒绝并提示原因<br>3. 重复文件按规则去重或提示重复<br>4. 超过上限被拦截且已有附件不丢失 |
| **备注** | 附件规则未确认时，本用例标记执行阻塞。 |
