# B2B 用户端 UI 优化测试用例

> Agent1 设计版本：2026-07-21  
> 用例来源：`测试点大纲.md`、`superpowers.md`、`用户端UI优化PRD.html`、客户端 UI 设计/交互规范及 29 个 reference-pages 示例。  
> 优先级枚举：`Critical`、`High`、`Medium`、`Low`。  
> 执行说明：资金、支付、发货、删除、账号安全等高风险操作优先在测试环境或沙箱执行；未确认真实提交权限前，可执行至确认弹窗并记录 `Skip-待环境确认`。
