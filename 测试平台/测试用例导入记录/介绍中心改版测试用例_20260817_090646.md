## 三、详细测试用例

### 公共壳层与全局规则 [IC-GEN]

#### TC-IC-GEN-001 【重点·正向】公共壳层跨页一致

| 字段 | 内容 |
|:--|:--|
| **测试点** | 公共 Logo、七语言、登录态、采购入口和页脚复制跨页一致 |
| **优先级** | High |
| **前置条件** | 公开官网 REQ-001～012 页面均可访问，准备未登录和已登录账号 |
| **操作步骤** | 1. 分别打开首页、服务费用、FAQ、Blog、通知和条款页面<br>2. 检查 Logo、语言入口、登录/头像、立即采购、页脚布局<br>3. 执行页脚复制并观察 Toast |
| **预期结果** | 1. 各页面公共壳层样式和行为一致<br>2. 未登录展示登录入口，已登录展示头像，立即采购进入 B2B 首页<br>3. 复制成功 Toast 为“复制成功”且失败可恢复 |
| **需求映射** | REQ-001～012,REQ-043 |
| **Smoke** | 是 |

| **预期结果** | 1. 未登录打开现有登录弹窗并保留返回上下文<br>2. 登录后只显示头像，立即采购进入 B2B 系统首页<br>3. 会话失效时回到登录态，不进入空白或占位页 |
