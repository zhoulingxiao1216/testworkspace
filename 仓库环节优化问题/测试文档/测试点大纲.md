# 仓库环节优化问题 - 测试点大纲

## 1. PDA 正品录入 (PDA-PR)
### 1.1 扫描异常提示
- 扫描捆绑商品条码时的语音播报及文本提示语验证
### 1.2 详情页信息扩充
- 正品录入详情中展示的贴纸信息验证
- 正品录入详情中展示的 FBA 信息完整性验证

## 2. PDA 配货模块 (PDA-AL)
### 2.1 新订单触达提醒
- 新配货单下发至 PDA 时的实时语音播报触发
- 待配货标签右上角气泡消息数动态增加与准确性
- 未读配货单号列表红色高亮展示
- 点击进入详情后未读状态解除，单号颜色恢复正常
### 2.2 并发锁定与状态流转
- 【重点】首个用户点击配货按钮：触发单据责任人绑定，状态变更为“配货中”
- 【重点】多人并发点击配货请求的数据竞争拦截验证
### 2.3 数据视图隔离
- 【重点】"配货中"单据在绑定操作人 PDA 的待配货列表中持续可见
- 【重点】"配货中"单据在非操作人 PDA 的待配货列表中不可见
- 【重点】"配货中"单据在 PC 端全局可见，且操作人账号回显锁定不可修改

## 3. PDA 打包模块 (PDA-PK)
### 3.1 自动打印触发机制
- 首次点击创建箱子自动调用打印机打印箱码
- 点击新增箱子按钮时同步自动打印新箱码
### 3.2 并发锁定与流转
- 【重点】首个用户扫描装箱第一个商品：触发单据责任人绑定，状态变更为“打包中”
- 【重点】“打包中”单据的 PDA 视图隔离（同配货逻辑验证）
### 3.3 完结提示与页面流转
- 最后一个商品装箱完成后的语音提示与弹窗提示触发
- 确认装箱完结后自动跳转回"打包详情页"的页面路由逻辑
