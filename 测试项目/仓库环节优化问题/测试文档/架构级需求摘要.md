# 架构级需求摘要 (仓库 PDA 优化)

## 1. 业务痛点与优化背景
当前仓库 PDA 在操作过程（正品录入、配货、打包）中存在多项体验与流程问题：
- 异常提示不明确，造成操作误解。
- 缺乏新任务消息触达（语音、视觉气泡），易导致任务遗漏。
- 操作路径冗余，打印箱码、页面跳转等操作繁琐，浪费时间。
- 核心漏洞：配货、打包环节允许多人并发操作同一单据，导致数据错乱、责任无法追溯。

## 2. 核心功能全景
1. **正品录入**：优化捆绑商品的语音提示。
2. **配货单消息**：新增语音提示、气泡角标计数、未读订单列表红色高亮标重。
3. **打印功能**：实现创建或新增箱子时的自动/同步触发打印箱码，减少点击。
4. **装箱反馈**：装箱完结后增加语音与弹窗双重提醒。
5. **流程跳转**：打包/装箱完毕后不再退回列表，直接停留/跳转回打包详情页。
6. **防并发与责任认领（核心变更）**：
   - 引入“配货中”、“打包中”状态。
   - 强绑定首个操作人：首个点击配货、或首个装箱的人强制认领该单。
   - 视图隔离：PDA 端仅向认领人展示该“进行中”的单据，其他人不可见，电脑端全局可见。
   - 账号固化：操作人字段系统默认填充，前端屏蔽修改能力。
7. **补充增强**：正品录入详情增加“贴纸及FBA信息查看”功能。
