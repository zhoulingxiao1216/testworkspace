## 四、重点说明

| 重点 | 说明 |
|:--|:--|
| 数据准备复杂 | 需要多商品、多店铺、多状态、金额确认、数量公式、购入数空值等组合数据 |
| 条件需求范围 | 采购差价负数拦截、店铺返现二次确认、购入数排序需先确认是否上线 |
| 金额链路风险 | 采购差价和店铺返现需同时验证 UI、接口和状态不误更新 |
| 分页排序风险 | 购入数排序必须验证全量分页，不可只看第一页 |
| Agent2 造数建议 | 优先业务 API，其次 UI；DB Mock Seed 仅限测试环境且必须遵守审计规则 |
