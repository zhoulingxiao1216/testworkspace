## 一、通用气泡规则（BUB）

#### TC-BUB-001 【正向】一级、二级分类气泡展示 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 一级与二级分类标题右侧均展示气泡 |
| **优先级** | P0 |
| **前置条件** | 用户已登录，存在一级、二级分类待办数据 |
| **操作步骤** | 进入包含一级、二级分类的模块 |
| **预期结果** | 一级分类标题右侧展示汇总气泡，二级分类标题右侧展示对应待办气泡 |

#### TC-BUB-002 【正向】折叠状态气泡持续展示 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 折叠后提醒入口不丢失 |
| **优先级** | P0 |
| **前置条件** | 一级分类下存在待办气泡 |
| **操作步骤** | 折叠一级分类 |
| **预期结果** | 一级和二级相关提醒不因折叠而丢失，分类标题右侧仍可见提醒气泡 |

#### TC-BUB-003 【正向】一级气泡汇总规则 [SmokeTest]
