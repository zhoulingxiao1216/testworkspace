## 二、业务目标

| 目标 | 说明 |
|:--|:--|
| 模块提醒可见 | 有新订单、新发货单、新客户待匹配、重要待办等事项时，在对应模块标题右侧展示气泡 |
| 数量准确 | 一级分类气泡等于已加载二级分类待办数总和，二级分类气泡等于目标待办数量 |
| 状态及时 | 新增、审核完成、客户经理匹配、页面切换、刷新、重新登录后，提醒数量按需求 SLA 更新 |
| 异常可恢复 | 子模块加载失败、状态未同步、多语言遮挡、网络延迟时，有明确降级和恢复机制 |
| 通知可配置 | 用户注册成功后可向配置的相关人员发送短信提醒，支持多人 |
| 全局导航增强 | 右侧导航展示消息、待办、订单数量 |

## 三、需求范围

| 范围 | 具体内容 |
|:--|:--|
| 通用气泡 | 一级/二级标题右侧展示；折叠/展开均展示；`<=99` 展示实际数，`>99` 展示 `99+` |
| 管理系统客户管理 | 客户管理一级汇总；客户信息二级统计待匹配业务采购客户经理的客户数量 |
| B2B 订单管理 | 订单管理一级汇总报价单、代购订单待审核数量；二级分别展示待审核数量 |
| B2B 发货配送 | 发货配送一级汇总；发货单列表二级展示待审核发货单数量 |
| 气泡交互 | 点击一级气泡展开二级；点击二级气泡跳转待办列表；点击重要待办气泡展开模块 |
| 重要待办 | 汇总“问题确认”“测量 / 报告”“系统通知”三个子模块待办数量 |
| 短信提醒 | 用户注册成功后提醒相关人员，支持配置和多人通知 |
| 右侧导航 | 消息展示未读消息条数；待办展示未处理全部条数；订单展示全部订单条数 |

## 四、核心规则

| 规则编号 | 规则 | 验收口径 |
|:--|:--|:--|
| BR-001 | 一级气泡汇总 | 一级气泡 = 已加载二级气泡数量总和 |
| BR-002 | 二级气泡计数 | 二级气泡 = 该分类目标待办数量 |
| BR-003 | 数字上限 | `<=99` 显示实际数，`>99` 显示 `99+` |
| BR-004 | 折叠可见 | 折叠/展开状态均不能丢失气泡 |
| BR-005 | 加载失败不计入 | 未加载成功的子分类或子模块暂不计入汇总 |
| BR-006 | 数据补全 | 子分类或子模块加载完成后自动补全汇总 |
| BR-007 | 客户匹配消失 | 客户匹配客户经理后 1 秒内气泡消失 |
| BR-008 | 客户异常轮询 | 气泡未消失时每 5 秒校验，连续 3 次仍异常后刷新 |
| BR-009 | 审核增减 | 待审核新增加 1，审核完成递减，归零隐藏 |
| BR-010 | 页面切换同步 | 切换页面后 2 秒内拉取并渲染目标模块气泡 |
| BR-011 | 重要待办汇总 | 重要待办 = 三个已加载子模块待办数之和 |
| BR-012 | 重要待办加载 | 刷新或重新登录后 1 秒内渲染重要待办气泡 |
| BR-013 | 重要待办异常提示 | 子模块加载失败时展示已加载总和和 `?` 提示 |
| BR-014 | 多语言避让 | 长标题、语言切换后气泡不遮挡、不错位 |
| BR-015 | 短信多人通知 | 用户注册成功后按配置通知一个或多个相关人员 |
| BR-016 | 权限隔离 | 无权限模块不泄露提醒数量，统计范围按用户可见范围 |

## 五、暂缓与待确认

| 类型 | 内容 | 影响 |
|:--|:--|:--|
| 待确认 | “角标或者站内信提醒”最终实现方式 | 影响站内信相关用例是否进入执行范围 |
| 待确认 | 负数修正为 0 后展示 0 还是隐藏 | 影响异常用例预期结果 |
| 待确认 | B2B “实时”是否有明确 SLA | 影响实时更新用例判定 |
| 待确认 | 客户待匹配统计范围 | 影响客户管理计数数据准备 |
| 待确认 | 短信“相关人员”角色范围和配置维度 | 影响短信通知用例数据准备 |
| 待确认 | 重要待办三个子模块的待办定义和完成条件 | 影响重要待办汇总与递减用例 |
| 待确认 | 右侧导航订单、待办、消息统计范围 | 影响导航数量用例判定 |
| 暂缓 | 短信失败重试、频控、退订、模板内容 | PRD 未给规则，不作为本轮阻断验收 |

## 六、测试策略摘要

| 策略 | 内容 |
|:--|:--|
| P0 主链路 | 气泡展示、汇总、`99+`、新增递增、审核递减、归零隐藏、客户匹配消失、重要待办汇总、短信触发、右侧导航基础数量 |
| P1 异常链路 | 加载失败、轮询恢复、页面切换、多语言重定位、点击交互、多人短信、权限范围 |

| Agent2 执行前置 | 需要测试环境 URL、账号权限、造数方式、短信验证通道、接口或 DB mock 造数许可 |
