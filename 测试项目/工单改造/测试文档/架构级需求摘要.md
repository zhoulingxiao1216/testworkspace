## 范围定义

| 范围 | 模块 | 说明 |
| --- | --- | --- |
| 范围内 | 订单商品行工单入口 | 商品无工单显示创建，有工单显示处理、状态和数量角标。 |
| 范围内 | 创建工单 | 单处理人、中文模板回填、问题内容、实物图/链接图、历史工单。 |
| 范围内 | 工单详情 | 当前商品工单列表、当前处理区、历史记录、状态机动作。 |
| 范围内 | 我的待办 / 全部工单 | 本人相关待办与权限范围全部工单模式。 |
| 范围内 | 工单模板 | 多语言模板维护，创建只用中文，对客发送再用客户语言。 |
| 范围内 | 客户确认回传 | 接收客户选择、客户原文、业务翻译、同步内部。 |
| 范围内 | 历史工单 | 按规格跨订单召回，点击新开 Tab，不覆盖当前弹窗。 |
| 范围外 | 客户确认页重做 | PRD 说明现有页面承接，本期只约束内部回传和同步。 |

## 关键对象

| 对象 | 关键字段 | 测试关注 |
| --- | --- | --- |
| 工单主表 | 内部ID、展示序号、订单号、商品行ID、商品快照、发起人、当前处理人、状态、版本号 | 序号与内部ID分离、状态版本防并发覆盖。 |
| 工单附件 | 工单ID、附件类型、排序、预览地址、原始文件、去重标识 | 实物图/链接图分组、上传失败恢复、预览删除。 |
| 工单记录 | 记录类型、内容、处理人、目标人、创建时间、唯一记录ID | 历史分类、客户沟通去重、倒序展示。 |
| 待办 | 工单ID、待办人、状态、来源动作、是否已处理 | 当前处理人唯一、同步待办去重。 |
| 模板 | 模板名、中文内容、多语言内容、启用状态、内容快照 | 创建回填中文、停用删除不影响历史。 |
| 历史规格Key | 商品名、颜色、尺码、属性标准化 | 同规格不同商品ID召回、无权限订单过滤。 |

## 高风险链路

| 链路 | 风险 |
| --- | --- |
| 质检创建工单 → 采购提交意见 → 业务发送客户 → 客户回复 → 业务同步 → 发起人完结 | 角色动作多、状态跳转多，最容易出现越权或漏同步。 |
| 订单详情入口与我的待办同时处理同一工单 | 并发覆盖、重复提交、状态过期。 |
| 业务发送客户确认 | 非业务误发、客户语言模板缺失、图片来源混淆。 |
| 历史工单召回 | 规格匹配过宽或权限过滤失效。 |
| 全部工单模式 | 普通员工越权查看全部订单工单。 |
| 模板停用/删除 | 历史工单内容丢失或对客发送空内容。 |

## Agent1 测试策略

- P0 冒烟：订单商品行入口、创建工单、待处理提交意见、业务发送客户、客户回复同步、发起人完结、我的待办入口。
- P0 安全：业务角色、发起人、当前处理人、全部工单数据权限、历史工单权限过滤。
- P1 回归：筛选查询、模板维护、多语言模板、附件上传方式、历史记录分类。
- 专项：状态版本并发、同规格历史召回、附件去重、旧状态“已关闭”兼容为“已完结”。
