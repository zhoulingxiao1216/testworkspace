# 工单改造测试点大纲

## 测试前置条件

| 维度 | 最小准备 | 用途 |
| --- | --- | --- |
| 订单 | 覆盖 Korea/Japan 等国家的代购订单，包含多个商品行 | 订单详情入口、客户语言、业务人员。 |
| 商品行 | 无工单、有未完结工单、多工单、全完结工单、同规格不同商品ID | 角标、状态摘要、历史工单。 |
| 角色 | 质检发起人、采购处理人、订单业务、仓库、普通员工、全量工单权限员工 | 权限、待办、全部工单。 |
| 模板 | 自定义、色差、尺寸、停用模板、缺语言模板 | 创建回填、对客发送、历史快照。 |
| 附件 | JPG/PNG/WebP、超限文件、重复粘贴图片、上传失败模拟 | 上传、预览、删除、分组。 |
| 客户回复 | 可接受、不接受、退货、空选择、多轮回复 | 客户回传、业务同步。 |

## 测试点树

- 工单改造测试点
  - 订单详情入口
    - 无工单显示创建工单
    - 有未完结工单显示工单处理、红色数量角标、最新状态摘要
    - 多工单按最新未完结工单摘要
    - 完结后角标剔除
    - 无权限入口置灰且后端拒绝
  - 创建工单
    - 商品快照字段展示与缺失兜底
    - 处理人单选且质控角色过滤
    - 模板选择只回填中文
    - 问题内容必填并保留换行
    - 实物图和链接图分组上传
    - 点击、拖拽、粘贴上传与失败恢复
    - 同规格历史工单召回、筛选、新开 Tab
  - 工单详情
    - 当前商品全部工单列表与选中态
    - 左侧切换同步当前处理区和历史记录
    - 非业务处理人提交意见
    - 业务发送客户确认
    - 待客户确认不可转交
    - 客户已回复后翻译并确认同步
    - 发起人确认完结
    - 非发起人不可完结
    - 关闭工单必须填写处理意见
    - 已完结只读
  - 历史记录
    - 全部不包含流转记录
    - 工单内容、内部处理、客户沟通、流转记录分类
    - 客户沟通记录去重
    - 右侧查看详情分类定位高亮
    - 旧“已关闭”展示为“已完结”
  - 我的待办
    - 工作台和我的待办气泡只统计待我处理
    - 我的待办 / 全部工单模式切换
    - 两种模式 Tab 顺序与数量
    - 客户ID、订单/工单、创建时间、状态、处理人筛选
    - 下一步打开同一工单详情弹窗
    - 订单编号跳转订单详情
    - 全部工单按权限过滤
  - 工单模板
    - 新增、编辑、复制、停用、删除
    - 中文内容必填
    - 7 种语言内容维护
    - 停用模板不出现在创建下拉
    - 删除/停用不影响历史工单快照
    - 对客发送目标语言缺失提示补充
  - 客户确认承接
    - 发送客户确认生成唯一确认链接或确认ID
    - 客户选择结果为空不进入客户已回复
    - 客户原文回传后业务翻译必填
    - 确认同步后进入客户已确认，不直接完结
    - 继续回复客户形成多轮沟通
  - 权限与安全
    - 非业务不可发送客户确认
    - 非当前处理人不可提交/转交
    - 非发起人不可确认完结
    - 普通用户不可查看无权限历史工单和全部工单
    - 后端接口不信任前端隐藏状态
  - 并发与一致性
    - 两入口同时提交同一工单状态版本冲突
    - 转交后旧处理人待办消失
    - 完结后所有待办关闭
    - 创建成功后订单商品行实时刷新
