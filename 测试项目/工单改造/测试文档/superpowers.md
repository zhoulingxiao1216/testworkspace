# 工单改造 Superpowers

## 适用范围

- 代购订单详情商品行工单入口。
- 创建工单弹窗。
- 工单详情弹窗。
- 我的待办 / 全部工单。
- 工单模板。
- 客户确认回传与客户沟通同步。
- 历史工单查询、历史记录、附件、权限、状态流转。

## 核心测试原则

| 原则 | 规约 |
| --- | --- |
| 状态机优先 | 所有处理动作必须围绕待处理、待客户确认、客户已回复、客户已确认、已完结验证，禁止只看按钮是否存在。 |
| 权限后端兜底 | 前端隐藏按钮不算通过，关键动作必须验证后端权限：业务发送客户、发起人完结、当前处理人处理/转交、数据权限查看全部工单。 |
| 商品行绑定 | 工单必须绑定订单商品行和商品快照；商品删除、拆分、合并后历史仍可追溯。 |
| 单处理人闭环 | 创建、转交、待办归属只允许一个当前处理人，协同同步对象不得变成并行处理人。 |
| 附件分组不可混 | 实物图和链接图必须分组上传、存储、展示、发送，不允许合并成无来源附件池。 |
| 客户沟通不越权 | 只有业务可发送客户确认和同步客户回复；客户回复不能直接结束工单。 |
| 历史记录可读 | 全部、工单内容、内部处理、客户沟通、流转记录分类清晰；全部不混入流转记录。 |
| 历史工单按规格 | 同规格不同商品ID也应召回历史工单，但必须做订单/组织权限过滤。 |
| 模板内容快照 | 模板停用、删除或多语言修改不得影响已创建工单的历史内容。 |
| 并发防覆盖 | 订单详情和待办两个入口同时处理同一工单时，后端必须校验状态版本。 |

## 状态与动作矩阵

| 状态 | 允许动作 | 禁止动作 | 重点断言 |
| --- | --- | --- | --- |
| 待处理-非业务 | 保存草稿、提交意见、转交、关闭、发起人确认完结 | 发送客户确认 | 提交意见后同步给业务；非发起人不可完结。 |
| 待处理-业务 | 保存草稿、发送客户确认、转交、关闭、发起人确认完结 | 非业务直接对客 | 发送内容文字必填；图片按勾选发送。 |
| 待客户确认 | 查看、关闭、发起人确认完结 | 转交、再次提交内部意见 | 业务发出后等待客户；不可打断客户沟通链路。 |
| 客户已回复 | 继续回复客户、确认同步、转交内部处理、关闭、发起人确认完结 | 不翻译直接同步 | 客户内容翻译必填；确认同步后变客户已确认，不直接完结。 |
| 客户已确认 | 关闭、发起人确认完结 | 非发起人完结 | 同步对象收到待办；发起人最终确认。 |
| 已完结 | 查看历史 | 所有编辑动作 | 所有处理按钮隐藏；旧“已关闭”展示为已完结。 |

## 关键数据准备

| 数据 | 最小准备 | 用途 |
| --- | --- | --- |
| 订单商品 | 无工单商品 1 个、有 1 条未完结工单商品 1 个、有多条工单商品 1 个、已完结工单商品 1 个 | 商品行入口、角标、状态摘要。 |
| 用户角色 | 质检发起人、采购处理人、订单业务、仓库、普通无权限用户、全量工单权限用户 | 权限与待办范围。 |
| 工单状态 | 覆盖待处理、待客户确认、客户已回复、客户已确认、已完结 | 状态机和 Tab。 |
| 附件 | 实物图、链接图、上传失败图、大图预览图、重复粘贴图 | 附件分组、上传、预览、删除。 |
| 模板 | 启用模板、停用模板、缺少目标语言模板、已被历史工单引用模板 | 模板回填、对客发送、删除停用影响。 |
| 历史工单 | 同商品ID历史、同规格不同商品ID历史、无权限订单历史 | 规格召回与权限过滤。 |
| 客户确认 | 客户选择结果、客户原文、空选择结果、多轮客户沟通 | 客户回传和同步。 |

## 必测风险

- `SKR7182` 之类跨项目客户口径不适用于本项目；本项目以订单/商品/角色权限为主。
- 我的待办和全部工单是两套查询范围，不能只复用前端筛选。
- 创建工单模板只回填中文，对客发送才读取客户语言。
- 工单编号展示序号不是内部唯一 ID，接口不能使用序号做主键。
- 查询无权限历史工单时，不得通过同规格召回绕过订单权限。
