## 发现的测试风险

| 风险 | 说明 | 处理 |
| --- | --- | --- |
| 客户确认页不在本期重做 | 但客户回复直接影响内部状态机 | 用例覆盖回传和同步，不覆盖客户页 UI 重做。 |
| 历史工单匹配需要后端规则 | 原型无法证明规格Key准确性 | 待确认问题 Q-006，执行时需造同规格不同ID数据。 |
| 全部工单权限依赖真实权限体系 | 静态原型无法验证越权 | 用例要求普通账号和全量账号对照。 |
| 并发状态版本依赖接口 | 页面原型无法验证 | 用例要求双入口并发或接口模拟。 |
| 附件上传失败依赖环境 | 静态原型无法模拟失败 | 交接清单要求上传失败测试图或 mock。 |
