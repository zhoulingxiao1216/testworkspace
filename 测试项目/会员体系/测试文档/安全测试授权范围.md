## 4. 数据修改授权

允许修改 lying 测试环境中的测试数据，包括但不限于：

- 会员等级；
- 国家一般会员开关；
- 会员价格、原价、期限套餐；
- 全球服务定价；

- 测试订单；

- 测试账号会员到期时间；
- 测试完成后尽量还原环境。

禁止修改生产配置、真实财务数据、真实用户订单、真实支付记录和非测试账号数据。

## 5. 安全/API 类用例授权

允许执行安全/API 类用例，但仅限 lying 测试环境、测试账号、低频请求，目标是验证系统是否正确返回 401/403/业务拦截。

允许动作：

- API 越权参数篡改验证，例如修改 `country`、`level_id`；
- 退出登录后旧 Token 复用验证；
- 绕过前端直接调用下单/结算接口验证服务端硬拦截；
- LocalStorage / SessionStorage 残留检查；
- 超长字符、特殊字符、XSS 字符串输入拦截验证；
- 记录请求 URL、方法、状态码、关键响应字段。

禁止动作：

- 扫描器扫描；
- 密码爆破；
- 目录爆破；
- 高并发压测；
- 漏洞利用链构造；
- 持久化攻击；
- 外联回连；
- 访问非测试账号或生产数据。

## 6. 停止条件

出现以下任一情况，立即停止相关测试：

1. 请求命中生产环境；
2. 出现真实扣款、真实入账、真实财务流水风险；
3. 出现大量 5xx 错误；
4. 出现账号被锁、IP 被封、WAF 拦截；
5. 出现非测试用户数据；
6. 后台配置被破坏且无法自动还原；
7. 安全策略提示需要人工进一步授权。

## 7. 证据与脱敏要求

测试执行需要保留：

- 页面截图；
- 请求 URL；
- 请求方法；
- 响应状态码；
- 关键响应字段；
- 操作账号；
- 操作时间；
- 关联用例编号；
- 是否产生订单/流水/配置变更；
- 缺陷复现步骤。

报告中 Token、Cookie、密码必须脱敏，不输出完整 Authorization Header。
