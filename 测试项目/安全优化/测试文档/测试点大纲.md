# 安全优化测试点大纲

> 基于 `终版整理安全问题需求及解决方案.md` 整理。本文只描述“测什么”，具体执行步骤见 `安全优化测试用例.md`。安全验证默认仅在测试环境、Mock 环境或明确授权环境执行。

## 测试前置条件

### 测试账号准备

| 维度 | 参数 | 需要的账号类型 |
|:--|:--|:--|
| 普通用户 | 用户 A / 用户 B | 各 1 个，用于跨用户越权、地址、报价、资金链路 |
| 支付密码 | 未设支付密码 / 已设支付密码 | 各 1 个，用于提现密码绕过验证 |
| 管理端 | 超级管理员 / 普通管理员 / 无权限管理员 | 各 1 个，用于 admin_index、余额调整、售后退款、代客登录 |
| IM | 客服/管理员 / 用户 / 非房间成员 | 至少 3 个，用于房间成员校验和 WebSocket 身份绑定 |
| Chrome 扩展 | 测试扩展包 | 1 套，用于 host_permissions、sender、URL 白名单验证 |

### 管理端/环境配置前置

- 准备独立安全测试环境，禁止在生产环境直接执行破坏性资金、安全攻击或内网探测。
- 准备万里汇沙箱回调样例：合法签名、缺签、错签、金额/币种不匹配、重复回调。
- 准备可回滚资金样本：待支付报价单、已支付订单、可退订单、提现账户、余额调整账户、售后退款订单。
- 准备跨用户资源样本：用户 A/B 地址、进口商地址、quote_no、聊天房间、消息 unique_value。
- 准备 XSS/注入 payload 样本：`<img onerror>`、SVG、`javascript:`、危险 `data:`、Excel `= + - @` 前缀文本。
- 准备敏感文件路径样本：`.pem`、`.key`、`.env`、证书目录、验证码邮件、email_log、verify_code_log。

### 特殊模式说明

> **受控安全验证**：涉及资金、退款、提现、密钥、内网 URL、恶意脚本、凭证撞库的场景，Agent2 必须先确认环境和授权；未授权时只做代码审计或标记 Blocked/Conditional。

> **上线结论约束**：P0 任一场景未通过即不可写“测试通过”；Critical/High 未关闭安全缺陷必须判定“暂缓上线”。

## 测试核心原则（必读）

**原则1：拒绝路径必须证明无副作用**
- 401/403 不够，还要核对订单、余额、地址、消息、token、日志、状态未被修改。

**原则2：服务端可信优先于前端入参**
- 金额、sender、group、room、quote_no、address_id、jump URL、imageUrl 等关键值不得直接信任客户端。

**原则3：合法路径必须回归**
- 安全修复不能只让攻击路径失败，也要保证合法管理员、本人资源、合法签名、合法消息、合法导出仍可用。

**原则4：敏感信息不可公开、不可明文长期留存**
- 私钥、验证码、token、secret、邮件正文、DeepL key 等需要验证公开访问、响应、日志、存储四个面。

**原则5：XSS 与注入要覆盖历史和双端路径**
- 新发送、新渲染、历史加载、用户端、管理端、扩展端、导出端都要覆盖。

- 安全优化测试点
  - 资金与支付安全
    - **【重点】** 越权退款匿名/普通用户拒绝与管理员合法退款回归
    - **【重点】** 退款金额服务端计算、拒收前端 amount、重复退款幂等
    - **【重点】** 万里汇回调缺签、错签、金额/币种不匹配、重复回调拒绝
    - 万里汇合法签名回调建单回归
    - **【重点】** 未设支付密码提现拒绝、错误支付密码拒绝
    - 提现金额 0/负值/超额边界校验
    - **【重点】** 余额调整和售后退款经办 admin_id、金额上限、双人审批
    - 充值金额以服务端/渠道实付为准
  - 鉴权与访问控制
    - **【重点】** admin_index 写接口匿名拒绝、合法管理员可用、无权限管理员拒绝
    - **【重点】** api_tb refreshToken 无鉴权拒绝、授权刷新审计、不返回 token 明文
    - **【重点】** SSO 非白名单回跳拒绝、token 不进 URL、state/nonce 防会话固定
    - 凭证签发接口错误 secret 失败频控和统一失败文案
    - 邮箱注册/发码接口不可枚举，checkEmail 无鉴权前副作用
  - 资源归属与 IDOR
    - **【重点】** 收货地址跨用户 update/delete/updateDefault/updateIncludeDeliveryNote 拒绝
    - 进口商地址跨用户写操作拒绝
    - **【重点】** 报价回退 quote_no 归属校验
    - 报价回退循环内远程调用与 DB 写入批量化，去硬编码 ID
    - 跨用户拒绝请求无副作用审计
  - IM 与消息安全
    - **【重点】** WebSocket 握手无 token/错 token 拒绝
    - **【重点】** WebSocket 伪造 send_user_id、group_uuid_arr、receive_user_id 拒绝
    - **【重点】** 聊天 room_uuid、unique_value 跨房间读写拒绝
    - 本房间合法读写、置顶、删除、标记回归
    - 用户端与管理端聊天存储型 XSS 双端净化
    - 历史聊天消息加载路径同样净化
  - XSS 与注入防护
    - **【重点】** 报价、订单、EMS 导出 Excel 公式注入拦截
    - 远程商品描述 v-html 净化
    - 官网公告、协议、design-fjx CMS HTML 净化
    - Chrome 扩展商品搜索结果 title/image/offerId/location DOM XSS 拦截
    - Chrome 扩展移除 inline onclick 和危险 innerHTML
  - 密钥与敏感数据
    - **【重点】** public 目录无 WorldTrade 私钥，`.pem/.key/.env` 公开访问被拒
    - WorldTrade 密钥轮换后签名与回调链路正常
    - 邮件日志不存活验证码完整正文
    - 验证码改 TTL/hash/清理任务，过期不可复用
    - 响应、URL、日志不泄漏 token/secret/key
  - Chrome 扩展与本地组件
    - **【重点】** host_permissions/content matches 缩小到业务域

    - imageUrl fetch 拒绝 loopback、link-local、内网 IP、非 https、非白名单域名
    - 上传前来源域确认和审计留痕
    - Lodop 本地打印 WebSocket 不 eval 不可信数据
  - 审计与纵深防御
    - **【重点】** 代客登录签发与验证均写持久审计
    - 余额调整、售后退款、token 刷新记录经办人/IP/目标对象
    - 安全失败日志可追踪但不记录敏感明文
