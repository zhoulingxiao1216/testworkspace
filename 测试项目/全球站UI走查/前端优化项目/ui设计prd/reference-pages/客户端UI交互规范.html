1. 通用交互原则

本章只定义全站交互的底线原则和章节归属规则，不再承载按钮、表单、下拉、表格、弹窗等具体控件规范。具体控件、业务场景和验收细则应落到对应章节，避免同一规则在多个章节重复或互相覆盖。
