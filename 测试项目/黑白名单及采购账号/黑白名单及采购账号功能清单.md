# 黑白名单及采购账号功能清单

## 1. 功能概述

本项目包含核心两大功能模块：
1. **IP黑白名单管理**：用于管理系统IP访问权限，通过设置白名单和黑名单，实现对系统登录IP的控制，保障系统访问安全。
2. **采购账号授权管理**：提供1688及淘宝采购账号的配置、授权绑定与状态管理，支持订单“一键采购”操作，并具备授权状态的实时检测与异常告警功能。

## 3. 后端功能清单

### 3.1 黑白名单及IP管控核心

### 3.3 一键采购及授权预警器 (重点)

| 功能名称 | 描述 | 异常处理 |
|----------|------|----------|
| 一键采购前置检查 | 在生成代采订单前，拦截检查其绑定的采购账号是否有效及授权 | 如失败阻断交易流，抛出引导授权的异常指令 |
| 订单维度一键采购 | 在订单详情页面支持1688和淘宝的一键采购操作 | 订单状态非进行中时按钮置灰，未配置采购账号时提示错误 |

| 定时授权到期巡检 | Cron定时任务：每日定期盘点1688及淘宝授权Token到期日 | 距离到期一定天数时写入预警状态，驱动前端气泡展示 |

## 4. 权限控制

| 角色 | 权限 |
|------|------|
| 管理员 | 可管理黑白名单及所有采购账号的CRUD和授权 |

## 5. 业务流程

- **5.1 IP管控流程**：登录 -> 中间件查库 -> 白名单放行/黑名单受阻/中间灰度拦截页 -> 豁免特权跳过。
- **5.2 1688管理流程**：添加主账号及信息 -> 通过API刷新出关联的子账号 -> 建立系统账号到采购子账的映射绑定。
- **5.3 淘宝授权流程**：后台录入店铺ID及手机 -> 点击授权跳转淘宝OAuth页面 -> 确认授权回调换取Token并落库。
- **5.4 一键采购前置流程**：用户触发代采 -> 核心检查器鉴定绑定是否正常及Token是否过期 -> 异常则阻断提示 -> 正常则携带采购账密自动下单。
- **5.5 异常到期预警机制**：后端守护进程轮询Token有效期 -> 离过期<N天触发警告标记 -> 前台标题携带气泡 -> 过期阻断业务。

## 6. 异常处理

| 故障类型 | 处理方式 |
|---------|----------|
| IP规则交叉失效 | 校验中间件逻辑；避免同一IP配置互斥记录。 |
| 1688接口Token过期 | 发出强提醒，并立刻阻断关联的一键采购流程。 |
| 淘宝授权回调失败 | 提供原始回调Error日志并引导清除浏览器缓存重新授权。 |
| 用户无可用采购账号 | 弹出定制化异常交互页面，附带前往配置管理模块的快捷锚点。 |

## 8. 技术与安全实现要点

1. **OAuth安全性防线**：淘宝回调的 `state` 防护CSRF；对于生成的 `access_token` 需进行库内脱敏或对称加密防护。
2. **高速IP网关匹配**：基于路由中间件拦截，建议考虑 Redis 缓存提速。
3. **隔离事务阻断**：采购预检操作必须是在开启相关DB事务的第一线执行，保证一旦授权失效不会造就半切单据。
