0. 最高优先级全局价格口径：会员价与商品单价统一使用 promotionPrice

全局硬规则：前台所有“会员价 / Hubbuyer 价格 / 商品单价”，以及后台所有携带“单价”的页面、明细、表单下载、导出和打印文件，统一取 1688 词搜、图片搜索和商品详情返回的营销价 promotionPrice。覆盖订单、报价单、全商品、发货订单、采购处理、入库/仓库发货、清算弹窗等链路，不再使用此前旧商品单价。
需求编号 规则对象 规则定义 影响页面 / 模块
REQ-016 会员价取值 会员价 = 1688 接口返回的营销价 promotionPrice。来源包括 1688 词搜、图片搜索，以及对应商品详情中的营销价字段。 商品列表、商品详情、购物车、确认订单、报价单列表、报价单详情、订单详情。
REQ-016 后台所有携带单价字段 后台所有页面只要展示、录入、计算或导出商品单价，均使用 promotionPrice；订单、报价单、全商品、发货订单、采购处理、入库/仓库发货、清算弹窗不得再使用旧单价。 后台代购订单详情、订单、报价单、全商品、发货订单、采购处理、入库/仓库发货、订单清算弹窗及其明细。
REQ-016 表单下载 / 导出单价 所有表单下载、导出、打印、明细文件中只要包含商品单价字段，单价必须等于 promotionPrice，即 1688 优惠价格 / 营销价。 订单下载、报价单下载、发货订单下载、全商品导出、采购/仓库/清算相关表单下载与打印。
REQ-008 订单详情节省公式 人工交涉节省 = 采购差价；商品金额节省 = 1688 原价对应的金额 - 会员价对应的金额，其中会员价对应的金额按 promotionPrice × 数量 汇总。 前台订单详情页、费用明细抽屉、店铺清算详情展示。

来源说明：用户补充需求指定 1688 开放平台字段，会员价参考 1688 product.search.keywordQuery 接口文档；预估国内运费参考 1688 product.freight.estimate 接口文档。本文档不发明额外接口名，只定义字段取值和页面/后端使用口径。

1. 项目背景与目标

1.1 项目背景

当前页面素材显示，前台已在商品列表、详情、购物车、确认订单、报价单、订单详情中展示 Hubbuyer 价格/会员价、报价单支付金额、会员免代采手续费、实际清算金额、订单差额、HUBBUYER 为您节省等信息；后台已在代购订单详情和订单清算弹窗中补充采购、质检、退换、返现、退款、实际支出等字段。本次补充要求将所有会员价和商品单价统一为 1688 返回的营销价 promotionPrice，收费体系调整需要把这些页面串成统一的价格、收费和清算规则。

1.2 优化目标

目标编号 目标 业务价值 验收口径
OBJ-001 建立报价单支付金额、实际结算金额、采购差额、订单差额的统一口径。 减少前后台金额口径不一致，降低清算争议。 前台订单详情、后台清算弹窗和资金处理文案对同一订单给出一致方向。
OBJ-002 在现有清算字段基础上优化返现、退款、人工降价等金额的展示和校验提示。 避免同一来源金额在页面展示、弹窗录入、资金处理说明中被重复理解。 不新增清算公式，不引入额外费用分类规则。
OBJ-003 让客户在下单前、支付前、订单清算后都能看到费用构成。 提升收费透明度，支撑“Hubbuyer 不收取商品差价”的前台表达。 确认订单、报价单详情、订单详情均有费用一览和关键说明。
OBJ-004 统一会员价和后台所有携带单价字段的数据来源。 避免词搜、图搜、商品详情、报价单、订单、仓库发货各自使用不同单价。 所有涉及商品单价的前后台页面、明细、表单下载、导出、打印均使用 promotionPrice，订单详情节省金额按本文档明确公式展示。

1.3 范围与非范围

类型 内容 说明
范围内 前台商品列表、商品详情、购物车、确认订单、报价单列表、报价单详情、订单详情。 以用户提供的页面目录为准，按页面节点写明字段、交互、金额展示和异常。
范围内 后台代购订单详情页、订单清算弹窗页。 覆盖订单清算入口、店铺清算明细、报价单金额、实际结算金额、重新计算、确定清算。
范围内 收费/清算字段口径、订单清算弹窗现有公式、前后台展示同步、单价来源与下载/导出口径。 基于现有页面字段和后台订单清算弹窗公式做优化；当前版本不改清算主逻辑。
非范围 真实支付通道接入、银行汇款到账、第三方支付平台交易回调、资金账户入账实现。 本文档只定义页面展示、金额含义、清算能力和接口能力，不发明具体接口名称。
非范围 经营利润报表、业绩差额报表、汇率收益报表。 旧逻辑中的收益口径应移到经营报表，不作为客户清算公式。

1.4 角色与权限

角色 权限范围 关键限制 审计要求
前台客户 / 企业会员 查看商品价格、购物车费用、报价单支付金额、订单清算金额、订单差额和资金处理提示。 不得修改后台清算字段；对未清算订单只看报价和进行中状态。 支付、取消、再提交、下载报价单/订单需要记录用户、时间、订单编号。
采购 维护实际支出、国内运费、到付运费、退换货运费、没货退款、店铺返现等采购相关字段。 关键金额一旦采购确认或订单清算后不得无审计修改。 金额修改前后值、修改原因、操作人、时间必须可追溯。
业务 / 客户经理 查看订单、联系客户、解释补差价或退款原因。 不能直接改清算公式；仅可发起问题处理或备注。 联系客户、修改负责人、处理备注需留痕。
财务 / 管理员 执行重新计算、确定清算、确认客户补差价/退款处理。 确定清算属于高风险操作，需二次确认和权限校验。 清算版本、公式版本、输入金额、输出金额、客户处理动作需写入清算记录。

3. 【前台】页面需求

3.1 商品列表页：宫格商品卡统一样式、普通商品卡片与 Hubbuyer 价格卡片

核心业务逻辑：当前图中只有搜索页做了新版商品列表样式，但该样式不是搜索页专属。所有会以宫格形式展示商品列表的页面都需要统一优化为该商品卡样式，包括首页、首页模块中的二级页面、搜索页、图搜、商品详情中的店铺内页、足迹等入口。商品列表页只解释商品卡价格展示差异，不产生费用汇总，也不计算运费、代采手续费或清算金额。

需求编号 卡片类型 展示样式与字段 业务规则与异常边界处理
REQ-001 适用页面范围 所有宫格商品列表入口统一使用新版商品卡样式：搜索页、图搜、首页商品列表、首页模块二级页面、商品详情中的店铺内页、足迹等。只要页面以宫格方式展示商品卡，就纳入本样式优化范围。 不得只改搜索页。后续新增宫格商品列表页面时，也必须复用同一商品卡样式、价格展示规则和 Hubbuyer 价格空态规则。
普通商品卡片 展示商品图、标题、1688 原价、CNY/USD 折算；Hubbuyer 价格区展示“无”或等价空态，不展示会员节省强调样式。 普通商品无会员价时不得使用旧单价补齐 Hubbuyer 价格；点击仍可进入商品详情，但后续报价需在详情页确认是否有有效 promotionPrice。
有 Hubbuyer 价格卡片 在 1688 原价旁并列展示 Hubbuyer 价格，Hubbuyer 价格取 promotionPrice，视觉上应比普通价更突出；同时展示对应 USD 折算，方便用户直接感知会员价优势。 当 promotionPrice 存在且大于 0 时才展示 Hubbuyer 价格；若接口返回异常、为 0 或格式不合法，卡片回到普通商品空态，不得回退旧商品单价。

交互与跳转说明：商品列表仅承担商品发现和价格提示，点击商品卡进入商品详情页；筛选、排序、搜索不改变会员价取值来源。

3.2 商品详情页：Hubbuyer 价格模块与预估国内运费

核心业务逻辑：商品详情页新增 Hubbuyer 价格模块，并在用户选择商品规格和数量后刷新预估国内运费。商品金额按选中 SKU 的 promotionPrice × 数量 计算。

需求编号 字段/控件名称 功能展现描述 业务规则与异常边界处理
REQ-002 Hubbuyer 价格模块 在价格区域展示“Hubbuyer 价格”标题、会员价格梯度、CNY/USD 折算、1688 原价对比和最小起订量。Hubbuyer 价格视觉层级高于 1688 原价，1688 原价使用弱化或划线/次级样式。 Hubbuyer 价格必须取 1688 词搜、图片搜索或商品详情返回的营销价 promotionPrice；页面上的“会员价”“Hubbuyer 价格”“商品单价”口径一致。
SKU、库存、数量 按规格展示 SKU 价格、库存、数量步进器和已选汇总；用户调整数量后，商品金额和预估国内运费同步刷新。 未选 SKU、低于最小起订量、库存不足时禁止加入购物车；错误需要在当前操作区域内给出可见反馈。
预估国内运费 在详情页底部或价格汇总区展示“预估国内运费”，并根据当前选中的 SKU、数量和收货相关参数刷新。 预估国内运费接口取 1688 product.freight.estimate；本文档以用户提供的官方链接为接口依据。接口失败、超时或参数不足时展示“待确认”并禁止把异常值计入报价金额。
加购按钮 校验 SKU、起订量、库存、会员价和预估运费状态后加入购物车。 加入购物车时需要保存商品单价快照、1688 原价、Hubbuyer 价格、预估国内运费、规格和数量，后续页面沿用该报价阶段快照。

交互与跳转说明：选择 SKU 和数量后，详情页先刷新商品金额与预估国内运费，再允许加购；商品详情不触发资金冻结或清算。

3.3 购物车页面：会员价商品样式、会员已省、预估国内运费

核心业务逻辑：购物车负责汇总可报价商品，并清楚区分“有 Hubbuyer 价格的商品”和“普通商品”。底部导航需新增会员已省和预估国内运费汇总。

5. 业务规则与风险控制

5.1 订单清算公式

规则编号 规则 说明 风险控制
RULE-001 报价单支付金额 = 客户已支付金额。 支付完成后的报价单支付金额作为订单差额公式中的对比金额。 未支付、支付失败、部分支付、逾期取消不得进入清算。
RULE-002 实际结算金额 = 客户价 + 附加项费用 + 质检费用 + 订单其他费用 + 代采手续费。 该公式取自后台订单清算弹窗页的“计算公式”表。 客户价、附加项费用、质检费用、订单其他费用、代采手续费必须与弹窗字段一致；弹窗字段“手续费”按代采手续费理解。
RULE-003 订单差额 = 实际结算金额 - 报价单支付金额 - 采购差额。 该公式取自后台订单清算弹窗页，字段名称必须沿用系统已有“订单差额”。 前台订单详情页若仍展示“报价单支付金额 - 实际清算金额”，必须同步修正为后台公式或明确差异来源。
RULE-008 会员价 / 商品单价 = promotionPrice。 1688 词搜、图片搜索和商品详情返回的营销价 promotionPrice 是前台会员价和后台所有携带单价字段的唯一价格基准。 promotionPrice 缺失或异常时不得回退旧单价；订单、报价单、全商品、发货订单、采购、仓库发货、清算、表单下载、导出和打印均需读取同一价格快照。
