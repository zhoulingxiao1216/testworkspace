3. 操作清单

操作编号 功能编号 操作 权限 前置条件 结果 产品需求章节
ACT-001FUN-002加入购物车客户SKU 已选、数量满足起订量、库存有效，预估国内运费已返回或状态可报价。商品进入购物车并参与购物车金额汇总。3.2
ACT-002FUN-003购物车下一步客户购物车商品有效且会员已省、预估国内运费、商品金额刷新完成。进入确认订单页面。3.3
ACT-003FUN-004确认订单下一步客户同意利用规约，报价单支付金额已计算。生成或进入报价单。3.4
ACT-004FUN-005打开支付弹窗客户报价单状态为待入金/待支付。展示支付金额、汇率、支付方式和平台服务费；平台服务费不计入报价单金额。3.5
ACT-005FUN-006立即支付客户报价单未过期，支付方式可用。支付成功后生成订单，报价单支付金额作为订单差额公式中的对比金额。3.6
ACT-006FUN-009维护采购金额采购订单未最终清算或有重算权限。更新实际支出、运费、返现、退款等清算输入。4.1
ACT-007FUN-010重新计算财务 / 管理员清算弹窗打开，输入字段通过基础校验。刷新实际结算金额、订单差额和客户处理。4.2
ACT-008FUN-012确定清算财务 / 管理员公式口径确认，清算试算无阻断异常。生成清算记录；客户需补款时自动扣除客户余额，余额不足时扣成不足金。4.2
ACT-009FUN-016冻结商品价格快照系统商品进入报价/订单链路时 promotionPrice 已返回且有效。订单、报价单、全商品、发货订单、采购处理、仓库发货、清算弹窗、表单下载、导出和打印使用同一 promotionPrice 单价。0 / 5.2
ACT-010FUN-017配置前台新增文案键系统 / 前端页面可见新增字段、提示、按钮、状态、表头、抽屉文案和鼠标移入提示已按页面梳理。前台新增固定文案从多语言配置读取，语言切换时同步更新；动态业务数据保持原值。5.4

4. 规则映射

规则编号 功能编号 规则摘要 风险等级 产品需求章节
RULE-001FUN-004报价单支付金额在支付后作为订单差额公式中的对比金额。高5.1
RULE-002FUN-011实际结算金额 = 客户价 + 附加项费用 + 质检费用 + 订单其他费用 + 代采手续费。高5.1
RULE-003FUN-011订单差额 = 实际结算金额 - 报价单支付金额 - 采购差额；字段名称沿用系统已有“订单差额”。高5.1
RULE-004FUN-014同一来源金额不能在采购差额、店铺返现、退款等现有字段中被人工重复录入或重复说明。高5.2
RULE-005FUN-012确定清算需二次确认并写入审计。高5.3
RULE-006FUN-015手续费统一解释为代采手续费；平台服务费为第三方支付平台收取，不由 Hubbuyer 收取，也不计入报价单金额。高5.2
RULE-008FUN-016会员价和后台所有携带单价的字段必须取 promotionPrice；订单、报价单、全商品、发货订单及所有表单下载/导出/打印不得回退旧单价。高0 / 5.2
RULE-009FUN-017前台页面可见新增固定字段、按钮、提示、表头、状态、抽屉文案和鼠标移入提示必须走多语言配置；金额、订单号、商品名、店铺名等业务数据不作为固定文案翻译。高5.4
