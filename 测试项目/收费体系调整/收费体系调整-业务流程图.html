1. 主业务流程图

按“前台报价、支付成单、后台清算、补退分支、闭环回显”拆成泳道。绿色粗线是正常主路径，紫色虚线是价格基准和多语言配置，红色虚线是阻断类风险。

主路径 补退分支 阻断风险 价格基准 多语言配置
主路径摘要 promotionPrice 先形成商品金额，再进入报价单支付金额。

FLOW-017 到 FLOW-006 解决会员价、预估国内运费、会员已省和前台支付链路，支付完成后直接进入 FLOW-008 后台清算数据维护。

关键风险 同一来源金额不能重复录入。

FLOW-011 只做现有字段的来源核对和提示，返现、采购差额、退款、人工降价不在本版本重新拆分费用分类。

同步点 订单差额公式以后台清算弹窗为准。

FLOW-012 的计算口径为实际结算金额 - 报价单支付金额 - 采购差额，前台订单详情需同步显示。

价格基准 后台所有单价都读取 promotionPrice 快照。

订单、报价单、全商品、发货订单、采购处理、仓库发货、清算弹窗、表单下载、导出和打印不能再读取旧单价。

多语言配置 前台新增固定文案都从多语言配置读取。

FLOW-018 覆盖商品列表、商品详情、购物车、确认订单、报价单列表、报价单详情和订单详情；金额、订单号、商品名、店铺名等动态数据保持原值。

2. 核心公式图

公式以订单清算弹窗页为准，先确认报价单支付金额和采购差额，再计算后台实际结算金额，最后判断客户补款、退款或无需处理；客户需补款时自动扣除客户余额，余额不足时扣成不足金。

支付金额 商品金额 = promotionPrice × 数量；报价单支付金额 = 客户已支付金额

支付金额池

对应 FLOW-004 / FLOW-005 / FLOW-006，是后续清算比较基准。

→
实际结算 实际结算金额 = 客户价 + 附加项费用 + 质检费用 + 订单其他费用 + 代采手续费

实际结算口径

对应 FLOW-010 / FUN-011，取自订单清算弹窗页计算公式。

→
订单差额 订单差额 = 实际结算金额 - 报价单支付金额 - 采购差额

差额方向

对应 FLOW-012；前台订单详情需同步后台公式。

4. 异常流程

异常流以卡片展示，不使用表格；每个异常都指向具体流程节点和功能项，方便评审时定位责任页面。

EX-001

商品无 Hubbuyer 价格时，所有宫格商品列表入口均展示普通卡片空态；SKU 未选、库存不足或低于起订量时，FLOW-002 阻断加购。

关联功能：FUN-001 / FUN-002

EX-009

1688 预估国内运费接口失败、超时或参数不足时，FLOW-002 / FLOW-003 / FLOW-004 / FLOW-006 展示待确认并阻断异常值计入报价。

关联功能：FUN-002 / FUN-003 / FUN-004 / FUN-006

EX-002

报价单待入金超过 72 小时或支付期限过期时，FLOW-005 / FLOW-006 禁用支付。

关联功能：FUN-005 / FUN-006

EX-003

支付失败时，FLOW-005 不生成订单，不产生可用于订单差额公式的报价单支付金额。

关联功能：FUN-005

EX-004

后台清算输入缺少必填金额或字段方向不明时，FLOW-009 / FLOW-010 阻断确定清算。

关联功能：FUN-010 / FUN-011

EX-005

店铺返现、采购差额、退款、人工降价重复计入时，FLOW-011 阻断提交。

关联功能：FUN-014

EX-006

确定清算后客户需补款但余额不足时，FLOW-013 按现有逻辑扣成不足金。

关联功能：FUN-012

EX-007

平台服务费被计入报价单金额时，FLOW-016 提示修正为第三方支付平台收取且不计入报价单金额。

关联功能：FUN-015

EX-008

1688 返回的 promotionPrice 缺失、为 0 或格式异常时，FLOW-017 阻断报价；后台页面、下载、导出和打印不得回退旧商品单价。

关联功能：FUN-016

EX-010

前台页面可见新增字段、提示、按钮、状态、抽屉文案或鼠标移入提示未接入多语言配置时，FLOW-018 阻断上线；金额、订单号、商品名、店铺名等动态数据不得被误翻译。

关联功能：FUN-017
