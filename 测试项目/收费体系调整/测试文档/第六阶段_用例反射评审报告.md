## 3. 旧版设计问题闭环

| 旧版问题 | 本次处理 |
| :-- | :-- |
| 旧版用例数量不足、粒度偏粗 | 扩展为 48 条，按模块拆分到可执行检查点。 |
| 对 `promotionPrice` 异常和禁止回退覆盖不足 | 新增缺失、为 0、非法格式、接口异常、后台/导出回退拦截。 |
| 报价单快照覆盖不足 | 新增价格变更、运费变更、支付成功继承、下载打印一致性。 |
| 清算公式和资金闭环覆盖不完整 | 新增平台服务费隔离、采购差额重复抵扣、正/负/零差额、并发清算。 |
| 权限和导出缺少明确用例 | 新增无权限维护、接口越权、敏感字段导出拦截。 |
| 多语言只做泛化说明 | 新增前台商品和打印模板专项检查。 |

## 4. 审计结论

本次测试点和测试用例已按 Agent1 规范重新设计，覆盖收费体系调整的核心业务风险。后续执行时必须优先完成 15 条 SmokeTest 和全部 Critical 用例；若出现价格源回退、快照污染、清算公式错误、资金流水重复或权限绕过，应直接判定为阻塞上线风险。
