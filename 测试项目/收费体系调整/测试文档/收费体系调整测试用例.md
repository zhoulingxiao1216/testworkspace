# 收费体系调整 测试用例

> 设计依据：`superpowers.md`、PRD、功能清单、业务流程图、页面原型及 Agent1 测试用例编写规范。  
> 覆盖范围：前台商品、购物车与确认订单、报价单与支付、后台订单管理、订单清算、全局导出规则。  
> 用例总数：59 条，其中 Critical 37 条、High 20 条、Medium 2 条。

## 1. 前台商品 C-GOODS

### 1.1 商品价格、运费与多语言

#### TC-C-GOODS-001 【正向】商品卡展示 Hubbuyer 价格
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 商品卡价格源：有 `promotionPrice` 时展示 Hubbuyer 价格，并与 1688 原价形成明确层级。 |
| **优先级** | Critical |
| **前置条件** | 1. 使用 Account-VIP 登录前台。<br>2. Item-A 存在有效 1688 原价、`promotionPrice`、SKU 和库存。 |
| **操作步骤** | 1. 进入首页商品宫格列表。<br>2. 进入词搜列表和店铺内商品列表。<br>3. 查看 Item-A 商品卡。 |
| **预期结果** | 1. 三个入口商品卡均展示 Hubbuyer 价格，数值等于 `promotionPrice`。<br>2. 1688 原价以弱化或划线样式展示。<br>3. 商品卡不展示旧单价或其他价格源。 |
| **财务精度** | CNY/JPY 展示小数位与页面现有规范一致，换算后不出现 0.01 以上误差。 |

#### TC-C-GOODS-002 【异常】promotionPrice 缺失时不得回退旧单价
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 价格异常降级：`promotionPrice` 缺失时，不得展示旧单价或错误会员价。 |
| **优先级** | Critical |
| **前置条件** | 1. 使用 Account-VIP 登录前台。<br>2. Item-B 的 `promotionPrice` 返回 null 或字段缺失。 |
| **操作步骤** | 1. 进入包含 Item-B 的商品列表。<br>2. 查看商品卡和商品详情页价格区域。 |
| **预期结果** | 1. 商品卡不展示 Hubbuyer 价格。<br>2. 详情页价格区域展示空态、待确认或不可报价提示。<br>3. 页面不得回退展示历史旧单价。 |

#### TC-C-GOODS-003 【异常】promotionPrice 为 0 或非法格式时阻断报价
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 价格异常降级：`promotionPrice` 为 0、负数、字符串或非法小数时阻断报价。 |
| **优先级** | Critical |
| **前置条件** | 1. 1688 Mock 分别返回 `promotionPrice=0`、负数、非数字字符串。<br>2. 前台可访问对应商品。 |
| **操作步骤** | 1. 分别打开异常商品详情页。<br>2. 选择 SKU 和数量。<br>3. 尝试加入购物车。 |
| **预期结果** | 1. 页面展示价格不可用或待确认提示。<br>2. 加入购物车按钮被禁用，或提交时明确阻断。<br>3. 购物车中不生成异常价格商品行。 |

#### TC-C-GOODS-004 【正向】商品详情 Hubbuyer 价格与商品卡一致
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 商品详情页展示的 Hubbuyer 价格必须与列表商品卡同一价格源一致。 |
| **优先级** | High |
| **前置条件** | 1. Item-A 在列表页和详情页均可访问。<br>2. `promotionPrice` 返回有效值。 |
| **操作步骤** | 1. 在列表页记录 Item-A 商品卡 Hubbuyer 价格。<br>2. 点击进入详情页。<br>3. 对比价格模块展示值。 |
| **预期结果** | 1. 详情页 Hubbuyer 价格等于列表商品卡价格。<br>2. SKU 未切换时不出现价格跳变。<br>3. 页面未展示旧价格字段。 |
| **财务精度** | 商品卡与详情页金额完全一致，含币种和小数位。 |

#### TC-C-GOODS-005 【正向】SKU 和数量变更联动商品金额
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 详情页数量变更后，商品金额基于当前 SKU 的 `promotionPrice` 实时重算。 |
| **优先级** | High |
| **前置条件** | 1. Item-A 至少存在 2 个 SKU。<br>2. 各 SKU 返回有效 `promotionPrice`。 |
| **操作步骤** | 1. 打开 Item-A 详情页。<br>2. 选择 SKU-A，输入数量 1、3、10。<br>3. 切换 SKU-B，重复调整数量。 |
| **预期结果** | 1. 商品金额 = 当前 SKU `promotionPrice` × 数量。<br>2. 切换 SKU 后价格和金额同步刷新。<br>3. 低于起订量或超过库存时出现阻断提示。 |
| **财务精度** | 每次重算保留到页面规定小数位，边界值不多扣或少扣。 |

| **操作步骤** | 1. 打开 Item-A 详情页。<br>2. 选择 SKU 并输入有效数量。<br>3. 观察预估国内运费展示。<br>4. 修改数量后再次观察。 |
| **预期结果** | 1. 系统按当前 SKU 和数量请求预估国内运费。<br>2. 运费字段展示接口返回值。<br>3. 修改数量后运费重新刷新。<br>4. 商品单价不因运费刷新而变化。 |
| **财务精度** | 运费金额不与商品金额混算，单独按金额字段精度展示。 |

#### TC-C-GOODS-007 【异常】预估国内运费失败时阻断异常值入链路
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 运费接口失败、超时或参数不足时展示待确认，不允许异常运费进入购物车和报价。 |
| **优先级** | Critical |

| **预期结果** | 1. 页面展示预估国内运费待确认或加载失败提示。<br>2. 异常运费不得作为 0 或随机值写入。<br>3. 如规则要求运费有效才可报价，则加购被阻断并定位提示。 |

#### TC-C-GOODS-008 【正向】前台商品新增文案走多语言配置
| 字段 | 内容 |
| :-- | :-- |

| **优先级** | Medium |
| **前置条件** | 1. 前台支持中文、日文、英文切换。<br>2. 多语言配置已包含本需求新增 key。 |
| **操作步骤** | 1. 分别切换中文、日文、英文。<br>2. 查看商品卡、详情页 Hubbuyer 价格、预估国内运费和加购提示。 |
| **预期结果** | 1. 固定文案随语言切换。<br>2. 商品名、店铺名、金额、SKU 等动态数据保持原值。<br>3. 缺失 key 不直接暴露技术字段。 |

## 2. 购物车与确认订单 C-CART

### 2.1 购物车快照与确认订单金额

#### TC-C-CART-001 【正向】购物车商品行单价沿用加购快照
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 购物车商品行单价必须沿用加购时的 `promotionPrice` 快照。 |
| **优先级** | Critical |
| **前置条件** | 1. Item-A 以有效 `promotionPrice` 成功加入购物车。<br>2. 记录加购时 SKU、数量、单价。 |
| **操作步骤** | 1. 进入购物车。<br>2. 查看 Item-A 商品行单价、小计和商品总金额。 |
| **预期结果** | 1. 商品行单价等于加购时 `promotionPrice`。<br>2. 小计 = 单价 × 数量。<br>3. 购物车未重新读取旧单价。 |
| **财务精度** | 商品行小计和底部商品总金额对账一致。 |

#### TC-C-CART-002 【正向】购物车数量变更后金额实时重算
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 数量增减后，购物车行金额、商品总金额、会员已省和预估国内运费同步刷新。 |
| **优先级** | High |
| **前置条件** | 1. 购物车中存在 Item-A。<br>2. 运费接口可按数量返回。 |
| **操作步骤** | 1. 将数量从 1 改为 3。<br>2. 再改为起订量边界和库存上限。<br>3. 查看底部汇总。 |
| **预期结果** | 1. 小计、商品总金额、会员已省按数量实时刷新。<br>2. 运费按最新数量刷新或进入待确认状态。<br>3. 超库存或低于起订量时阻断下一步。 |
| **财务精度** | 每个金额字段按独立公式重算，不因页面刷新重复累加。 |

#### TC-C-CART-003 【正向】会员已省只做展示不参与支付扣减
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 会员已省 = 1688 原价金额 - Hubbuyer 会员价金额，仅用于权益感知。 |
| **优先级** | Critical |
| **前置条件** | 1. Account-VIP 购物车内存在 Item-A 和 Item-C。<br>2. Item-A 有原价和 `promotionPrice`，Item-C 无会员价。 |
| **操作步骤** | 1. 勾选 Item-A 和 Item-C。<br>2. 查看会员已省和商品总金额。<br>3. 进入确认订单页。 |
| **预期结果** | 1. 会员已省只统计 Item-A 的价格差。<br>2. Item-C 不参与会员已省。<br>3. 报价单支付金额未再次扣减会员已省。 |
| **财务精度** | 商品总金额不因会员已省字段二次减少。 |

#### TC-C-CART-004 【正向】多店铺购物车预估国内运费分店汇总
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 多店铺、多商品、多 SKU 场景下，预估国内运费按规则汇总且不污染商品金额。 |
| **优先级** | High |
| **前置条件** | 1. 购物车中存在至少 2 个店铺商品。<br>2. 各商品运费接口可返回不同金额。 |
| **操作步骤** | 1. 勾选全部商品。<br>2. 分别取消某店铺商品。<br>3. 查看预估国内运费和商品总金额变化。 |
| **预期结果** | 1. 运费随勾选范围变化。<br>2. 商品总金额只受商品行勾选影响。<br>3. 店铺维度运费与底部汇总可对账。 |
| **财务精度** | 店铺运费合计等于底部预估国内运费。 |

#### TC-C-CART-005 【异常】购物车价格或运费异常时阻断下一步
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 价格失效、运费待确认、商品下架、库存不足时阻断进入确认订单。 |
| **优先级** | Critical |
| **前置条件** | 1. 购物车存在价格异常商品或运费异常商品。<br>2. 商品行处于勾选状态。 |
| **操作步骤** | 1. 点击购物车“下一步”。 |
| **预期结果** | 1. 系统阻断跳转。<br>2. 明确提示异常原因并定位到商品行。<br>3. 不生成确认订单临时数据。 |

#### TC-C-CART-006 【正向】确认订单费用一览分项准确
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 确认订单页费用一览准确展示商品金额、预估国内运费、选项费用、代采手续费和报价单支付金额。 |
| **优先级** | Critical |
| **前置条件** | 1. 购物车选择 Item-A 并进入确认订单。<br>2. 存在选项费用和有效预估国内运费。 |
| **操作步骤** | 1. 查看确认订单费用一览。<br>2. 对比购物车勾选商品行、运费、选项费用和手续费。 |
| **预期结果** | 1. 商品金额等于勾选商品小计之和。<br>2. 预估国内运费、选项费用、代采手续费单列。<br>3. 报价单支付金额按规则合计。 |
| **财务精度** | 报价单支付金额 = 商品金额 + 预估国内运费 + 选项费用 + 代采手续费，按页面规则保留小数。 |

#### TC-C-CART-007 【正向】普通账号和会员账号代采手续费差异
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 普通账号正常收取代采手续费，会员账号按权益免除或减免。 |
| **优先级** | Critical |
| **前置条件** | 1. Account-Normal 和 Account-VIP 均可下同一组商品。<br>2. 代采手续费规则已配置。 |
| **操作步骤** | 1. 使用 Account-Normal 进入确认订单。<br>2. 使用 Account-VIP 进入确认订单。<br>3. 对比代采手续费展示和报价单支付金额。 |
| **预期结果** | 1. 普通账号显示并计入代采手续费。<br>2. 会员账号按权益显示免除/减免说明。<br>3. 会员减免不影响商品单价快照。 |
| **财务精度** | 两个账号报价单支付金额差异仅来自代采手续费规则差异。 |

#### TC-C-CART-008 【异常】平台服务费不得计入确认订单报价单金额
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 平台服务费属于第三方支付费用，不计入确认订单报价单支付金额。 |
| **优先级** | Critical |
| **前置条件** | 1. 支付平台服务费规则已配置。<br>2. 确认订单页可生成报价单。 |
| **操作步骤** | 1. 进入确认订单页。<br>2. 查看费用一览和报价单支付金额。<br>3. 点击下一步生成报价单。 |
| **预期结果** | 1. 确认订单页不把平台服务费混入报价单金额。<br>2. 平台服务费仅在支付弹窗或支付相关模块单列。<br>3. 生成的报价单金额不包含平台服务费。 |
| **财务精度** | 报价单支付金额与费用一览合计一致，且不含平台服务费。 |

## 3. 报价单与支付 C-QUOTE

### 3.1 报价单快照、支付与订单回显

#### TC-C-QUOTE-001 【正向】生成报价单时固化价格和费用快照
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 生成报价单瞬间固化 `promotionPrice`、预估国内运费、代采手续费和报价单支付金额。 |
| **优先级** | Critical |
| **前置条件** | 1. 确认订单页金额已计算完成。<br>2. Item-A 价格和运费有效。 |
| **操作步骤** | 1. 点击确认订单“下一步”。<br>2. 进入报价单列表或详情。<br>3. 对比确认订单金额与报价单金额。 |
| **预期结果** | 1. 报价单商品单价、商品金额、预估国内运费、代采手续费与确认订单一致。<br>2. 报价单支付金额被固化。<br>3. 后续列表查询不重新计算实时价。 |
| **财务精度** | 报价单支付金额与确认订单计算结果完全一致。 |

#### TC-C-QUOTE-002 【正向】1688 价格变更不影响待支付报价单
| 字段 | 内容 |
| :-- | :-- |

| **预期结果** | 1. 报价单页面单价和金额保持生成时快照。<br>2. 下载文件金额与页面一致。<br>3. 不出现实时价格覆盖快照。 |
| **财务精度** | 修改前后报价单支付金额不变。 |

#### TC-C-QUOTE-003 【正向】预估运费变更不影响待支付报价单
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 报价单快照隔离：生成后预估国内运费变化不得影响报价单。 |

| **操作步骤** | 1. 修改同一商品的预估国内运费返回值。<br>2. 刷新报价单详情页。<br>3. 打开支付弹窗。 |
| **预期结果** | 1. 报价单详情预估国内运费保持快照值。<br>2. 支付弹窗报价单金额保持快照值。<br>3. 新生成报价单才使用新的运费值。 |
| **财务精度** | Quote-A 的预估国内运费和报价单支付金额不变。 |

#### TC-C-QUOTE-004 【正向】报价单列表会员已省展示准确
| 字段 | 内容 |
| :-- | :-- |
| **测试点** | 报价单列表新增会员已省字段按报价单快照计算展示。 |
| **优先级** | High |
