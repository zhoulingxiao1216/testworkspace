## 三、 【表单下载】管理端与用户端核心流程时序图

针对管理端和用户端的表单下载功能，为确保数据准确性和完整性的核心安全逻辑：

```mermaid
sequenceDiagram
    participant User as 用户/管理员
    participant Frontend as 前端页面
    participant API as 后端API
    participant DB as 数据库
    
    User->>Frontend: 进入对应页面（发货单详情/个人中心）
    User->>Frontend: 点击下载按钮
    Frontend->>User: 显示表单类型选择
    User->>Frontend: 选择表单类型（如：商业发票）
    alt 选择商业发票合并
        User->>Frontend: 确认合并选项
    end
    Frontend->>API: 调用表单数据获取接口
    API->>DB: 查询表单所需数据
    DB-->>API: 返回数据
    alt 选择商业发票合并
        API->>API: 执行商品合并逻辑
    end
    API->>API: 生成Excel文件
    API-->>Frontend: 返回文件下载链接
    Frontend-->>User: 触发文件下载
```

## 四、 【修改品名/材质】核心交互流程

针对修改品名/材质功能的核心业务流程，展示从触发到保存的完整链路：

```mermaid
flowchart LR
    Start["用户：点击修改品名/材质按钮"] --> Popup["系统：弹出修改弹窗"]
    Popup --> Fetch["系统：自动获取英文品名和材质"]
    Fetch --> Display["展示商品列表（图片、品名、材质）"]
    Display --> Select["用户：选择需要修改的商品"]
    Select --> Modify["用户：修改中文品名/材质/英文品名/英文材质"]
    Modify --> Save["用户：点击保存按钮"]
    Save --> Validate["系统：验证数据"]
    Validate --> Update["系统：更新商品信息"]
    Update --> Success["显示保存成功提示"]
```

## 六、 【EMS面单】特殊处理流程

针对EMS面单打印需要显示备注弹窗的特殊处理流程：

```mermaid
sequenceDiagram
    participant User as 管理员
    participant Frontend as 前端页面
    participant API as 后端API
    
    User->>Frontend: 进入发货单详情
    User->>Frontend: 选择EMS面单
    Frontend->>User: 显示备注弹窗
    User->>Frontend: 填写备注信息
    User->>Frontend: 点击确认打印

    API->>API: 生成EMS面单
    API-->>Frontend: 返回面单文件
    Frontend-->>User: 触发面单打印
```
