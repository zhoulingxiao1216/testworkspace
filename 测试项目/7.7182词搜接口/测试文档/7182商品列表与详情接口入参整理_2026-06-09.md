# 7182商品列表与详情接口入参整理

整理时间：2026-06-09  
接口域名：`https://main-api.hubbuyer.com`  
适用范围：7182 词搜接口功能联调、接口测试、验收测试

## 通用请求头

| 参数 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- |
| `Authorization` | 是 | `Bearer <access_token>` | 业务接口必须携带 Bearer Token；Token 由 `/open_api/v1/auth/token` 获取。 |
| `Content-Type` | 是 | `application/json; charset=utf-8` | 请求体固定按 JSON 提交。 |
| `X-Request-Id` | 否 | `qa-7182-20260609-001` | 外部请求追踪 ID；不传时由服务端生成。 |

说明：`Authorization` 只适用于商品列表、商品详情等业务接口；用户换取 Token 接口不需要携带 `Authorization`。

## 用户换取 Token 接口

接口地址：

```text
POST https://main-api.hubbuyer.com/open_api/v1/auth/token
```

### 请求头

| 参数 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- |
| `Content-Type` | 是 | `application/json; charset=utf-8` | 建议按 JSON 提交；如兼容樱花站口径，可同时验证 form-data。 |
| `Authorization` | 否 | - | Token 获取接口不需要认证头。 |

### Body 入参

| 参数 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| `client_key` | string | 是 | `hubbuyer-JPN62` | 当前测试使用的 7182 开放接口客户标识，由开发提供。 |
| `client_secret` | string | 是 | `<client_secret>` | 客户密钥，只在换取 Token 时提交；测试文档和日志不得明文记录。 |

### 请求示例

```json
{
  "client_key": "hubbuyer-JPN62",
  "client_secret": "<client_secret>"
}
```

### 开发提供联调样例

记录来源：开发提供 PHP cURL 示例  
记录时间：2026-06-09  
安全处理：原始 `client_secret` 不落盘，以下使用 `<client_secret>` 占位。  
注意：当前测试使用 `client_key=hubbuyer-JPN62`；早期 PRD/测试文档曾出现 `SKR7182` 口径，需在验收时确认最终上线客户标识。

```php
<?php

$curl = curl_init();

curl_setopt_array($curl, array(
  CURLOPT_URL => 'https://main-api.hubbuyer.com/open_api/v1/auth/token',
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_ENCODING => '',
  CURLOPT_MAXREDIRS => 10,
  CURLOPT_TIMEOUT => 0,
  CURLOPT_FOLLOWLOCATION => true,
  CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
  CURLOPT_CUSTOMREQUEST => 'POST',
  CURLOPT_POSTFIELDS => 'client_key=hubbuyer-JPN62&client_secret=<client_secret>',
  CURLOPT_HTTPHEADER => array(
    'Content-Type: application/x-www-form-urlencoded'
  ),
));

$response = curl_exec($curl);

curl_close($curl);
echo $response;
```

该样例覆盖的入参组合：

| 参数 | 样例值 | 说明 |
| --- | --- | --- |
| `client_key` | `hubbuyer-JPN62` | 开发提供的联调客户标识。 |
| `client_secret` | `06b2***bfa3` | 开发提供的联调密钥，记录时必须脱敏。 |
| `Content-Type` | `application/x-www-form-urlencoded` | 该样例使用 form-urlencoded，而非 JSON。 |

### 成功响应关注字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | 成功应为 `200`。 |
| `msg` | string | 成功通常为 `success`。 |
| `data.access_token` / `access_token` | string | 后续业务接口使用的 Bearer Token。 |
| `data.token_type` / `token_type` | string | 固定应为 `Bearer`。 |
| `data.expires_in` / `expires_in` | string/int | Token 有效期或过期时间。 |

### 错误场景

| 场景 | 触发条件 | 预期 |
| --- | --- | --- |
| 缺少凭据 | `client_key` 或 `client_secret` 为空 | 返回参数错误，不生成 Token。 |
| 凭据错误 | `client_key/client_secret` 不匹配 | 返回认证失败，不生成 Token。 |
| 客户禁用 | `hubbuyer-JPN62` 被禁用 | 返回客户禁用错误。 |
| 日志脱敏 | 任意成功或失败请求 | 日志不得记录 `client_secret` 或完整 Token。 |

## 商品列表查询接口

接口地址：

```text
POST https://main-api.hubbuyer.com/open_api/v1/product/search
```

### Body 入参

| 参数 | 类型 | 必填 | 默认值 | 取值/限制 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `keyword` | string | 是 | - | 去除首尾空格后长度 1-100 | 日文搜索关键词；不能为空。 |
| `keyword_language` | string | 否 | `ja` | 仅支持 `ja` | 关键词语言；传其他语言应返回参数错误。 |
| `response_language` | string | 否 | `ja` | 仅支持 `ja` | 返回语言；商品可见信息固定日文优先。 |
| `page` | int | 否 | `1` | 从 1 开始 | 页码。 |
| `page_size` | int | 否 | `20` | 最大 50；`include_detail=true` 时最大 20 | 每页条数。 |
| `include_detail` | boolean | 否 | `false` | `true` / `false` | 是否补充当前页商品核心详情。 |
| `price_min` | number | 否 | - | `>= 0`，不得大于 `price_max` | 最低价格，单位人民币元。 |
| `price_max` | number | 否 | - | `>= 0`，不得小于 `price_min` | 最高价格，单位人民币元。 |
| `month_sold_min` | int | 否 | - | `>= 0` | 最低月销量。 |
| `category_id` | string | 否 | - | 1688 类目 ID | 类目筛选。 |
| `ship_time` | string | 否 | - | `24h`、`48h` | 发货时效筛选。 |
| `certified_factory` | boolean | 否 | - | `true` / `false` | 是否筛选认证工厂。 |
| `one_piece_dropship` | boolean | 否 | - | `true` / `false` | 是否筛选一件代发。 |
| `new_arrival_7d` | boolean | 否 | - | `true` / `false` | 是否筛选 7 天上新。 |
| `selection_1688` | boolean | 否 | - | `true` / `false` | 是否筛选 1688 严选或同等级标签商品。 |
| `min_order_quantity_max` | int | 否 | - | `>= 1` | 最大起订量，筛选起订量小于等于该值的商品。 |
| `repurchase_rate_min` | number | 否 | - | 0-100 | 最低复购率。 |
| `trade_score_min` | number | 否 | - | 0-5 | 最低店铺评分。 |
| `sort` | string | 否 | `relevance` | 见下方排序枚举 | 排序方式。 |

### sort 枚举

| sort | 说明 |
| --- | --- |
| `relevance` | 综合相关性。 |
| `sales_desc` | 月销量从高到低。 |
| `price_asc` | 价格从低到高。 |
| `price_desc` | 价格从高到低。 |
| `repurchase_desc` | 复购率从高到低。 |
| `score_desc` | 店铺评分从高到低。 |
| `newest_desc` | 新品优先。 |

## 商品详情查询接口

接口地址：

```text
POST https://main-api.hubbuyer.com/open_api/v1/product/detail
```

### Body 入参

| 参数 | 类型 | 必填 | 默认值 | 取值/限制 | 说明 |
| --- | --- | --- | --- | --- | --- |
| `offer_id` | string | 是 | - | 1688 商品 ID | 来自商品列表接口响应 `data.items[].offer_id`。 |
| `response_language` | string | 否 | `ja` | 仅支持 `ja` | 返回语言；商品信息固定日文优先。 |
| `include_html_detail` | boolean | 否 | `false` | `true` / `false` | 是否返回完整 HTML 详情；本期默认不返回。 |
| `include_sku` | boolean | 否 | `true` | `true` / `false` | 是否返回 SKU 信息。 |

### 请求示例

```json
{
  "offer_id": "604016892818",
  "response_language": "ja",
  "include_sku": true,
  "include_html_detail": false
}
```

## 测试关注点

| 接口 | 参数场景 | 预期 |
| --- | --- | --- |
| 商品列表查询 | `keyword` 为空、超长、非日文语言 | 返回参数错误，不进入上游搜索。 |
| 商品列表查询 | `keyword_language` 或 `response_language` 非 `ja` | 返回参数错误。 |
| 商品列表查询 | `page < 1`、`page_size` 超上限 | 返回参数错误。 |
| 商品列表查询 | `include_detail=true` 且 `page_size > 20` | 返回参数错误或要求降低分页大小。 |
| 商品列表查询 | `price_min > price_max` | 返回参数错误。 |
| 商品列表查询 | `sort` 不在枚举内 | 返回参数错误。 |
| 商品详情查询 | `offer_id` 为空或非法 | 返回参数错误。 |
| 商品详情查询 | `offer_id` 不存在、下架或无权限 | 返回商品不存在类错误。 |
| 两个接口 | 未带 `Authorization` | 返回未认证错误。 |
| 两个接口 | Token 无效、过期、客户禁用 | 返回鉴权失败或客户禁用错误。 |
