## 二、业务范围

| 范围 | 模块 | 结论 |
|:--|:--|:--|
| 范围内 | 统一认证 | 7182 使用 `client_key/client_secret` 获取 JWT Bearer Token，词搜、商详、商品状态查询共用同一套凭据。 |
| 范围内 | 词搜列表接口 | `POST /open_api/v1/product/search`，只接受日文关键词，返回日文商品列表与 `offer_id`。 |
| 范围内 | 商品详情接口 | `POST /open_api/v1/product/detail`，按单个 `offer_id` 查询日文详情、SKU、价格、图片、供应商等字段。 |
| 范围内 | 商品状态查询服务 | `GET /open_api/v1/product/status_v2`，独立一级服务节点，使用全球站订单与全商品状态。 |
| 范围内 | 前台商品数据查询页面 | 独立前台日文页面，Client Key / Secret 认证后只读查询商品状态。 |
| 范围内 | 后台 API维护 | 仅 API客户授权、调用日志记录两个页面。 |
| 非范围 | 客户侧搜索页与商详页 | 本期不开发搜索列表页、商品详情展示页。 |
| 非范围 | 订单、购物车、报价写入 | 本期只查询商品数据和商品状态，不创建业务单据。 |
| 非范围 | 1688 上游密钥后台页 | 1688 密钥仅服务端或高权限运维配置，不做普通后台页面。 |

## 三、核心验收口径

| 主题 | 验收口径 |
|:--|:--|
| 鉴权 | 正确凭据返回 Bearer Token；错误凭据、禁用客户、Token 缺失、Token 过期均返回日文错误且不进入业务查询。 |
| 日文限定 | 搜索输入语言仅 `ja`，未传默认 `ja`，非日文语言返回 400；商品标题、标签、属性、错误消息优先日文。 |
| 1688 适配 | 对外字段稳定，上游字段名在 Adapter 内适配；AppKey、AppSecret、access_token、签名不返回给 7182。 |
| 筛选排序 | 价格、销量、类目、发货时效、认证工厂、一件代发、起订量、复购率、评分、排序均走白名单；未知字段返回 400。 |
| include_detail | `include_detail=true` 只补充当前页详情，最多 20 个商品；部分详情失败时整体搜索仍可返回。 |
| 状态查询 | 商品状态以全球站 `b2b_order.status` 与 `b2b_order_detail.order_mark` 为准，对外只展示 6 个日文状态。 |
| 前台页面 | 未认证前筛选区和列表不可操作；认证后点击「検索」才展示统计和商品一覧；页面只读。 |
| 后台授权 | 客户ID 默认 `SKR7182`；列表和添加客户弹窗不展示用户ID；生成 Token、禁用、限流修改保留操作日志。 |
| 调用日志 | 记录请求参数摘要、响应码、耗时、错误分类、trace_id；Secret、Token、1688 密钥、签名必须脱敏。 |

## 四、模板字段矩阵

| 模板字段 | 业务含义 | 关联测试关注 |
|:--|:--|:--|
| `url` | 1688 商品链接 | 商品状态查询链路、商品编号展示、导入记录关联。 |
| `name` | 商品名称或商品编码 | 商品名称展示与空值兜底。 |
| `SKU` | 7182 SKU 编码 | SKUコード 查询、组合筛选、日志参数摘要。 |
| `size` / `color` | 规格属性 | 属性1、属性2 展示与日文/中文来源兜底。 |
| `price` | 商品价格 | 导入记录参考，不作为本期财务计算核心。 |
| `JANCODE` | JAN 码 | JANコード 查询字段和索引来源待开发确认。 |
| `user_order_no` | 消费者订单号 | 消費者注文番号 查询、管理番号兜底。 |
| `num` | 下单数量 | 下単数、数量字段展示。 |
| `spec_id` / `sku_id` | 1688 规格标识 | 状态链路与详情 SKU 对齐。 |
| `ItemURL` / `SkuURL` | 客户侧商品/图片链接 | 前台展示不应泄露内部敏感说明。 |

## 五、主要风险与待确认项

| 风险 | 影响 | 建议 |
|:--|:--|:--|
| 1688 上游字段名和筛选能力以控制台为准 | 搜索和详情字段可能与 PRD 推断字段不一致 | 联调阶段建立字段映射样例，并覆盖缺失字段兜底。 |
| JAN 来源字段为推断 | JAN 查询可能无法稳定命中 | 开发明确 JAN 来源表、索引和匹配规则。 |
| 6 个日文状态的代码级映射未固化 | 状态查询可能出现边界状态归类争议 | 开发提供 `b2b_order.status` 与 `order_mark` 到 6 状态的映射表。 |
| Token 刷新旧 Token 失效时机需落地 | 外部客户切换窗口可能产生中断 | 明确生成新 Token 后旧 Token 是否立即失效及是否支持并行宽限期。 |
| PDF 为截图型资料 | 无法自动抽取字段 | 以 PRD、原型和 Excel 模板作为可执行测试字段来源。 |
