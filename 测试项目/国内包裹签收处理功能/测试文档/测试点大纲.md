# 国内包裹签收处理功能 测试点大纲

> 基于《国内包裹签收处理功能立项文档.docx》及墨刀原型整理，审计问题（Q1-Q5）已获产品确认。
> Q6（关联订单展示上限）、Q7（淘宝订单纳入范围）暂定，按保守假设设计。

## 测试前置条件

### 测试账号准备

| 角色 | 数量 | 用途 |
|:---|:---|:---|
| 后台管理员 | ×1 | 仓库管理模块全权限访问 |
| 业务员 | ×2 | 验证业务员下拉筛选及关联展示 |
| 采购员 | ×2 | 验证采购员下拉筛选及关联展示 |
| 质检/初检岗位 | ×1 | 验证组别字段和接手操作 |

### 环境配置前置

- 后台系统组别配置至少 2 个组（用于组别字段验证）
- 物流公司列表至少包含 3 家国内物流公司
- 扫码枪/PDA 设备已与系统完成对接
- 存在至少 1 笔 1688 采购订单已发货（用于关联订单匹配验证）
- 准备周一至周日不同时间签收的测试包裹数据

## 测试核心原则（必读）

**原则1：超时判定差异化**
- 超时计算根据签收日不同采用不同阈值：工作日24h / 周六48h / 周日跳过从周一计算
- 所有超时相关测试必须覆盖三种日期类型

**原则2：私人包裹隔离**
- 私人包裹仅记录签收数据，不参与处理/超时/处理时长任何统计维度
- 私人包裹判定标准：扫码后无法匹配订单/业务员/用户ID

**原则3：数据统计全量一致**
- 6维度统计必须覆盖筛选结果的全量数据（含翻页），不仅限当前页
- 筛选条件变更后统计数据必须实时联动刷新

**原则4：多对多关联映射**
- 快递号与订单号为多对多关系，搜索时可能出现多条结果
- 展示时关联订单一行一个

**原则5：默认展示规则**
- 页面打开默认展示当天数据 + 超时未处理包裹置顶
- 默认数据也需参与统计

- 国内包裹签收处理功能测试点
  - 筛选与搜索 (FT)
    - 时间段筛选
      - 发货时间筛选：验证时间段选择组件的起止范围选择及筛选结果准确性
      - 签收时间筛选：验证签收时间段筛选的数据过滤正确性
      - 接手时间筛选：验证接手时间段筛选的数据过滤正确性
      - 时间筛选边界值：验证仅选起始/仅选结束/起止相同等边界场景
    - 文本模糊匹配筛选
      - 快递单号模糊搜索：验证输入部分单号的模糊匹配能力
      - 关联订单模糊搜索：验证输入部分订单号的模糊匹配能力
      - 用户ID模糊搜索：验证用户ID输入的模糊匹配能力
    - 下拉选择筛选
      - 是否超时筛选：验证全部/是/否三选项的筛选结果准确性
      - 业务员下拉筛选：验证下拉列表包含全部+系统业务员名单，选择后筛选正确
      - 采购员下拉筛选：验证下拉列表包含全部+采购人员列表，选择后筛选正确
      - 物流公司下拉筛选：验证下拉列表包含全部+国内物流公司清单，选择后筛选正确
      - 是否处理下拉筛选：验证全部/是/否三选项的筛选结果准确性
    - 按钮功能
      - 搜索按钮：验证点击搜索后根据已选筛选条件返回正确结果
      - 重置按钮：验证点击重置后所有筛选条件恢复初始状态
    - 组合筛选
      - **【重点】** 多条件组合筛选：验证多个筛选条件同时生效时的结果准确性
      - 无结果场景：验证所有条件组合后无数据时的空状态展示
  - 数据统计 (ST)
    - 统计维度展示
      - **【重点】** 6维度统计正确性：验证已发货/已签收/未签收/已处理/未处理/已超时的计数准确
    - 统计联动
      - **【重点】** 筛选后统计联动：验证筛选条件变更后6维度统计数据实时更新
      - 全量统计含翻页数据：验证统计结果涵盖所有翻页数据，非仅当前页
    - 统计隔离
      - **【重点】** 私人包裹不计入特定统计：验证私人包裹数据不统计到超时、处理时长等维度
  - 数据列表展示 (DT)
    - 基础字段展示
      - 发货时间展示：验证从1688/淘宝接口获取的发货时间正确展示，无数据时为空
      - 签收时间展示：验证扫码枪扫码时间正确记录和展示
      - 快递单号展示：验证扫码签收后快递单号正确同步展示
      - 物流公司展示：验证扫码签收时物流公司名称正确同步展示
      - 关联订单展示：验证关联订单号一行一个展示，支持多订单关联
      - 业务员/采购员/用户ID展示：验证关联订单对应的人员信息正确展示
      - 接手时间展示：验证初检扫码时间正确记录为接手时间
      - 组别展示：验证初检扫码人员对应的组别正确展示
    - 状态字段展示
      - 是否处理状态展示：验证已签收无接手=未处理、有接手=已处理的状态判定
      - 是否超时状态展示：验证超时状态根据签收时间和处理时间正确计算
      - 处理时长展示：验证从签收到接手的时长按小时取整展示
    - 排序与默认展示
      - **【重点】** 默认展示当天数据：验证页面打开时仅展示当天签收和处理数据
      - **【重点】** 超时未处理包裹置顶：验证超时未处理包裹排序最高
      - 签收时间升序排列：验证普通包裹按签收时间从早到晚排列
  - 手工录入 (MI)
    - 弹窗交互
      - 手工录入按钮打开弹窗：验证点击手工录入按钮后弹窗正确弹出
      - 运单号输入与自动匹配：验证填写运单号后系统自动匹配对应订单并展示
    - 校验与边界
      - **【重点】** 运单号格式校验：验证非法格式运单号的前端校验拦截
      - 空运单号提交拦截：验证未填写运单号时的提交拦截
    - 匹配结果处理
      - 匹配成功展示：验证匹配到订单后筛选项中正确展示相关内容
      - **【重点】** 匹配失败按私人包裹：验证无法匹配订单时按私人包裹处理
  - 超时判定 (TO)
    - 工作日超时
      - **【重点】** 工作日24h超时判定：验证周一至周五签收后超过24h未处理标记为超时
      - 工作日24h内处理不超时：验证24h内完成处理不标记超时
      - 工作日24h边界值：验证恰好24h的边界判定
    - 周六超时
      - **【重点】** 周六48h超时判定：验证周六签收后超过48h未处理标记为超时
    - 周日特殊规则
      - **【重点】** 周日签收跳过计算：验证周日签收的包裹跳过周日，从周一开始计算24h超时
    - 处理时长
      - 处理时长小时取整：验证处理时长从签收到接手按小时取整计算
  - 私人包裹 (PP)
    - 判定规则
      - **【重点】** 私人包裹判定：验证扫码后无法匹配订单/业务员/用户ID时判定为私人包裹
    - 数据隔离
      - 私人包裹仅记录签收数据：验证私人包裹只记录签收数据（快递单号/签收时间/物流公司）
      - **【重点】** 私人包裹不计入超时统计：验证私人包裹不参与超时、处理时长统计
  - 翻页分页 (PG)
    - 基础翻页
      - 默认30条/页：验证初始加载默认每页展示30条数据
      - 条数切换：验证10/20/30/50每页的切换功能
    - 导航功能
      - 翻页导航：验证上一页/下一页按钮功能及总页数展示
      - 跳页功能：验证输入页码直接跳转到对应页面
