## 一、业务背景与目标

| 维度 | 内容 |
|:--|:--|
| **目标用户** | 给大客户提供服务的业务员 |
| **需求背景** | 大客户表格下单，业务员需要有地方导入表格，给大客户批量选品同时产生对应的吊牌和贴纸 |
| **使用场景** | 当大客户需要大批量的下单，同时又不去网站下单，只提供了相关的 Excel 表格时 |
| **业务目标** | 通过批量导入下单功能，快速实现用户的选品能尽快转换为订单，减少用户等待时间，提升满意度，同时降低业务人员操作繁琐程度 |

## 二、功能全景概览

### 2.1 核心入口

- **路径**：全球站后台 → B2B系统 → 客户管理 → 客户信息 → 批量导入（新增）
- **触发方式**：在客户详情页（管理系统和B2B系统两个模块）新增功能入口，点击后切换到批量导入窗口
- **关键约束**：在用户面板导入数据时，数据归属对应用户，商品选品信息同步到该用户的购物车

### 2.2 模版体系（4 个模版，3 个客户）

| 客户代号 | 模版文件名 | 模版类型 | 核心用途 | 是否生成吊牌/贴纸 |
|:--|:--|:--|:--|:--|
| **7182** | `20260416発注書_1637.xlsx` | 选品导入 | 自动选品到购物车，默认附加项：全量详检 | ❌ 无需 |
| **8160** | `816026042052　816026042053(1).xlsx` | 吊牌/贴纸参数补充 | 从前台下载已有订单 → 补充吊牌/贴纸参数 → 重新导入生成 | ✅ 需要（贴纸+吊牌） |
| **7561-自社** | `0422発注書_自社倉庫.xlsx` | 选品导入 | 选品到购物车 | ❌ 无需 |
| **7561-ZOZO** | `0422発注書_zozo.xlsx` | 选品+吊牌 | 选品到购物车 + 附加项选择吊牌 → 转代购订单时生成吊牌 | ✅ 需要（仅吊牌，转订单时生成） |

### 2.3 7182 模版业务流程

1. 业务员在客户面板上传 7182 模版 Excel
2. 系统解析表头字段，按商品链接自动选品到购物车
3. **SKU/颜色/尺寸二次校验**：与 1688 链接上的字段核对，不匹配则报错
4. **价格比价**：将 price（单价）与 1688 报价比对，展示表单价、链接价、差价，支持一键复制
5. 导入以下扩展字段：
   - `num` → 购物车数量
   - `else_remark`（最小正品数） → 展示在订单详情的商品属性中
   - `JANCODE + SKU` → 合并到订单详情商品信息的 mysku 字段，逗号分隔，支持一键复制
   - `ItemURL + SkuURL` → 写入订单备注（报价单也需要）
   - `user_order_no`（用户注文番号） → 写入商品信息 + 后台筛选条件 + 前台多处筛选

### 2.4 8160 模版业务流程

1. **前台下载流程**：用户在前台 B2B代行管理 → 注文履歴 页面
   - 注1：展开订单商品列表，逐一勾选商品
   - 注2：订单列表复选功能，批量勾选（订单级，含所有单品）
   - 注3：批量导入模版下载按钮（未勾选置灰，勾选后变蓝）
   - **上限 1000 条**：超过时弹窗提醒，自动勾选前 1000 个商品
   - 勾选状态在页面刷新/关闭/跳转时保持不变，导出后清零
   - 已有吊牌/贴纸时弹窗提醒是否继续下载 → 继续则带出已有参数
2. **导入流程**：用户填写红色表头（品牌名、SKU、销售价格、颜色、尺寸、管理编码、是否需要贴纸、是否需要吊牌）→ 导入系统
3. **冲突检测**：若用户修改了订单自带信息，弹窗提醒是否覆盖
4. **费用联动**：覆盖模版后判断是否产生其他费用，如有则自动添加附加项并关联费用

### 2.5 7561 模版业务流程

#### 自用仓库版

- 根据表单信息将商品选品到购物车：商品链接 → size / color / price / NUM / SKU(Mysku)

#### ZOZO 仓库版

1. 系统通过表单名判定仓库类型（名称含 `zozo` 不区分大小写 → ZOZO仓库）
2. 导入后仅选品到购物车 + 附加项选择"吊牌" → 报价包含吊牌费用
3. 见积书阶段不生成吊牌
4. **转代购订单时**同步生成吊牌，数据读取订单信息
5. 吊牌模版表头 ABCDEF 对应吊牌字段

### 2.6 前台筛选扩展（用户注文番号）

新增筛选条件覆盖以下页面：

| 页面路径 | 筛选字段 |
|:--|:--|
| 前台 → B2B代行管理 → 見積書一览 → 搜索栏 | 用户注文 |
| 前台 → B2B代行管理 → 注文历史 → 筛选栏 | 用户注文 |
| 前台 → B2B代行管理 → 全商品 → 筛选项 | 用户注文 |
| 前台 → 配送管理 → My仓库 → 筛选项 | 用户注文 |
| 前台 → 配送管理 → 国际配送 → 筛选项 | 用户注文 |

**匹配规则**：支持精确匹配，字数和文字不做限制。

### 2.7 吊牌/贴纸制作

- **贴纸**：固定模版，仅需 SKU + 商品编码
- **吊牌**：参数包含品牌名、SKU、销售价格、颜色、尺寸、管理编码（均非必填，未填字段在吊牌中删除，系统优化排版）
- **数量同步**：根据订单正品数量同步贴纸/吊牌数量
- **费用关联**：自动产生关联服务费用并添加到附加项
