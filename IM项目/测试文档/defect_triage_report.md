# 全球站 IM 一期测试缺陷分流报告 (Defect Triage Report)

经对《协润进出口_缺陷_20260413150403》文档进行梳理，第一轮测试共计产生 **17 个有效反馈**（其中 12 个确认为功能 BUG，5 个为交互与视觉优化建议）。
为了更高效地进行后续修复与回归测试，我将其与我们的 [测试点大纲] 及需求文档（PRD）进行了映射与分类评估。

## 🔴 高优阻断与核心逻辑缺陷 (High Priority & Logic Bugs)

这类问题大多直接违背了 PRD 当中着重强调的“强制同步”和“拦截”要求，建议优先指派开发进行修复：

1. **退出登录未同步失效（严重安全漏洞）**
   - **Bug ID**: 1001361（用户退出登录后仍能发消息且消息会丢失）
   - **违背要求**: `1.2 登录态同步与恢复` 中明确要求“B2B商城执行退出登录后，IM立即同步失效，发送/接收操作均被拦截”。当前状态极易导致数据不同步和错乱。
2. **等级、人员等系统信息不同步**
   - **Bug ID**: 1001373（修改会员等级后IM不更新） —— 违背 `1.6 用户等级展示` 中的“实时同步更新”原则。
   - **Bug ID**: 1001364（修改客户采购员后，原采购员仍在群内） —— 违背人员变更时的最终一致性逻辑，导致信息泄露。
   - **Bug ID**: 1001369（新分配人员未落入群聊，需重新确认）。
3. **消息已读未读与排序异常**
   - **Bug ID**: 1001297（已读回复后次日仍提示未读） —— 状态持久化失败。
   - **Bug ID**: 1001358（消息未按时间倒序展示而是按注册时间） —— 严重影响基础对话体验。

## 🟠 性能指标缺陷 (Performance Issues)

不符合 PRD 对 `IM-PERF` 模块定下的客观时间基准：

1. **Bug ID**: 1001367（聊天记录加载时间超 20s 且偶发报错）。
2. **Bug ID**: 1001356（客服登录后加载消息响应大于 10s）。
   - **违背要求**: PRD 明确规定“IM页面首次加载耗时 ≤ 2s”以及“API响应时间 ≤ 500ms”。此类超长延迟通常为后端慢查询、缺少索引或大列表全量返回导致。

## 🟡 一般功能缺陷 (General Functional Bugs)

1. **Bug ID**: 1001376（历史记录查询未生效）。
2. **Bug ID**: 1001362（群名称命名 `客户ID/用户级别/人数` 格式不符）。
3. **Bug ID**: 1001359（引用图片回复时尺寸溢出超出聊天框）。
4. **Bug ID**: 1001377（图片历史记录仅单张单独展示，多图展示异常）。
5. **Bug ID**: 1001371（客服对群聊成员只有添加无法删除）。
   - *【注】这里需二次核对*：PRD指明**仅群主**有权限删除群成员。若该测试的“客服”并非群主，则不可删除为【正确表现】。若该“客服”是群主但仍无法删除，才是真实缺陷。

## 🟢 体验优化建议 (Optimization / UI Suggestions)

这类反馈并非系统运行阻断，而是测试人员从交互侧提出的合理化建议：

1. **1001284**: 缺失最主要的回车键发送消息功能（建议务必加上，提升使用效率）。
2. **1001378**: 群成员列表打开后遮挡聊天内容。
3. **1001375**: 在标准笔记本宽高比下字体偏小。
4. **1001374**: 聊天框连续发生多张图片不能形成合集，点击无法前后翻页预览。
