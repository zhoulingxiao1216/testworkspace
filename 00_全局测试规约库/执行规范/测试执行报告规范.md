# 测试执行报告编写规范

> **适用范围**：所有项目的测试执行结果记录，由测试执行 Agent（Test Runner）自动生成。
> **配套文档**：与《缺陷报告编写规范》配合使用。

---

## 一、文件命名与存放

| 规则 | 说明 |
|------|------|
| 文件名格式 | `执行报告_YYYY-MM-DD.md` |
| 存放路径 | `{项目}/测试文档/执行报告/` |
| 截图存放 | `{项目}/测试文档/执行报告/screenshots/` |
| 录屏存放 | `{项目}/测试文档/执行报告/recordings/` |
| 同日多次执行 | 追加后缀 `_R2`、`_R3`（如 `执行报告_2026-04-23_R2.md`） |

---

## 二、文档结构

```markdown
# {项目名称} 测试执行报告

> 执行日期：YYYY-MM-DD
> 执行环境：{URL}
> 执行轮次：第 N 轮
> 用例来源：{测试用例集文件名}

## 执行概览

| 指标 | 数值 |
|------|------|
| 总用例数 | N |
| 已执行 | N |
| ✅ Pass | N (xx%) |
| ❌ Fail | N (xx%) |
| ⚠️ Blocked | N |
| ⏭️ Skip | N |
| SmokeTest 通过率 | N/M (xx%) |

## SmokeTest 结果（优先展示）

| 用例编号 | 标题 | 结果 | 耗时 | 备注 |
|---------|------|------|------|------|

## 全量执行日志

### TC-XX-001 {标题}
- **结果**：✅ Pass
- **步骤记录**：
  1. {操作} → {实际响应}
  2. ...
- **截图**：![step1](screenshots/TC-XX-001_step1.webp)
- **耗时**：Xs

### TC-XX-002 {标题}
- **结果**：❌ Fail
- **步骤记录**：
  1. {操作} → {实际响应}（步骤 1-2 正常）
  3. {操作} → ⚠️ 实际响应与预期不符
- **偏差说明**：预期 {XX}，实际 {YY}
- **关联缺陷**：BUG-XX-001
- **截图**：![fail](screenshots/TC-XX-002_fail.webp)
```

---

## 三、执行状态枚举

| 状态 | 符号 | 判定条件 |
|------|------|---------|
| Pass | ✅ | 所有步骤的实际结果与预期结果完全匹配 |
| Fail | ❌ | 任一步骤的实际结果与预期不符 |
| Blocked | ⚠️ | 前置条件不满足、环境异常、依赖用例未通过 |
| Skip | ⏭️ | 人工指定跳过或当前轮次不执行 |

## 四、截图命名规范

| 场景 | 命名格式 | 示例 |
|------|---------|------|
| 步骤截图 | `{用例编号}_step{N}.webp` | `TC-MG-001_step3.webp` |
| 失败截图 | `{用例编号}_fail.webp` | `TC-MG-005_fail.webp` |
| 缺陷截图 | `BUG-{模块}-{序号}.webp` | `BUG-MG-001.webp` |
| 环境截图 | `env_{描述}.webp` | `env_login_page.webp` |

---

## 五、执行记录书写规范

### 5.1 步骤记录

- 使用数字序号，与用例「操作步骤」一一对应
- 每步格式：`{N}. {操作摘要} → {实际响应}`
- 正常步骤简写，异常步骤详写

### 5.2 偏差说明

Fail 用例**必须**包含偏差说明，格式：
```
- **偏差说明**：预期 {预期结果关键内容}，实际 {实际观察到的结果}
```

### 5.3 禁止写法

| ❌ 错误 | ✅ 正确 | 原因 |
|---------|--------|------|
| "测试通过" | 列出关键步骤实际响应 | 无法回溯验证 |
| 不附截图 | 关键步骤 + Fail 必须截图 | 无法复现取证 |
| 只写"失败" | 写明预期 vs 实际偏差 | 无法判定缺陷严重度 |

## 六、一致性自检清单

- [ ] 文件名符合 `执行报告_YYYY-MM-DD.md` 格式
- [ ] 执行概览表数据与全量日志逐条核对一致
- [ ] 所有 Fail 用例均有偏差说明 + 关联缺陷编号
- [ ] 所有 Fail 用例均有截图附件
- [ ] SmokeTest 结果表完整（所有 `[SmokeTest]` 标签用例均已列出）
- [ ] Blocked 用例注明阻塞原因
- [ ] 截图文件存放在 `screenshots/` 目录下且命名规范
