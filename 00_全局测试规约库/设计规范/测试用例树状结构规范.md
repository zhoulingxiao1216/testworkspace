# 测试用例树状结构规范

> 适用范围：所有项目的测试用例文档，与《测试用例编写规范》和《测试点大纲编写规范》配套使用。

---

## 一、树状结构层级

树状图共 **5 层**，层级定义如下：

```
项目名称 (用例总数)
├── 端（管理端 / 客户端 / 其他）
│   ├── 模块 [TC前缀]
│   │   ├── 测试点
│   │   │   ├── TC-XXXX-NNN  用例名称（≤20字）
│   │   │   └── TC-XXXX-NNN  用例名称（≤20字）
│   │   └── 测试点
│   │       └── TC-XXXX-NNN  用例名称（≤20字）
│   └── 模块 [TC前缀]
│       └── ...
└── 端
    └── ...
```

| 层级 | 说明 | 示例 |
|:--|:--|:--|
| L1 项目 | 项目名称 + 总用例数 | `会员体系优化 (143条用例)` |
| L2 端 | 系统入口分类 | `管理端` / `客户端` |
| L3 模块 | 功能模块 + TC前缀标记 | `全球会员定价 [TC-PR]` |
| L4 测试点 | 模块内的具体测试维度 | `B2B/B2C模式切换` |
| L5 用例 | TC编号 + 简短用例名 | `TC-PR-001  开启B2C新用户获下单权限` |

---

## 二、TC 编号命名规则

格式：`TC-{模块缩写}-{序号}{变体后缀}`

```
TC - MG  - 002  A
│    │      │    └── 变体后缀（可选）：A/B/C 或 -S2/-S3
│    │      └────── 序号：3位数字，001起步，模块内连续
│    └───────────── 模块缩写：2~4位大写英文
└────────────────── 固定前缀
```

### 各端业务模块缩写声明机制（解耦架构）

> **⚠️ 强约束通告**：
> 作为全局维度的“树状语法约束基座”，本文档**彻底禁止硬编码**收录任何具体业务线的模块对照表（如约定 `MG`、`FI`、`IM-AUTH` 等短前缀含义）。
> **配置下放**：所有具体工程的模块缩写字典，必须下放至各业务级目录内维护（如存放于 `业务项目/测试文档/superpowers.md` 的字典章节，或独立的 `config.json`）。在解析与渲染该分支结构的树状图时，应优先加载所属业务域的局部上下文进行反演。

## 三、用例名称书写规则

1. **长度上限**：≤ 20 个中文字符（含标点），严禁折行
2. **禁止前缀**：不加【正向】【异常】等括号标签（标签保留在 `测试用例.md` 详情中）
3. **动宾结构**：优先使用"主语+动作+结果"或"条件+行为"格式
4. **关键词前置**：将最能区分用例的词放在最前面

```
✅ 正确：余额充足直接扣减身份生效
✅ 正确：跨日审核锁定提交当日汇率
❌ 错误：【重点·Critical】跨日审核：审批时汇率锁定为提交当日，不随次日更新
```

---

## 四、树状图构建步骤

1. **确定项目名称与总用例数** → 填写 L1 根节点
2. **按端分类** → 填写 L2（管理端 / 客户端）
3. **参照测试点大纲分模块** → 填写 L3，括号内标注 TC 前缀
4. **将测试点大纲二级条目作为 L4 测试点**
5. **每条测试用例** → 填写 L5，格式为 `TC-XXX-NNN  ≤20字名称`
6. **变体用例**（同一测试点下多场景）→ 使用后缀区分，如 `TC-FI-014` 和 `TC-FI-014-S3`

---

## 五、ASCII 树形符号规范

| 符号 | 含义 |
|:--|:--|
| `├──` | 非最后一项子节点 |
| `└──` | 最后一项子节点 |
| `│` | 纵向连接线（父节点有后续兄弟时使用） |
| 空格缩进 | 每层缩进 **4 个空格**（含符号宽度） |

> ⚠️ 所有符号必须使用**半角字符**，不可混用全角竖线 `｜`。

## 六、配套文档关系

```
测试点大纲 (.md)          测试用例 (.md)           树状结构图
──────────────           ──────────────────       ────────────────
L1 模块                → L3 模块 [TC-XX]       → 同步更新
  L2 测试点            → L4 测试点              → 同步更新
    L3 验证项          → L5 TC-XX-NNN 用例详情 → 同步新增编号
```

每次新增测试模块或测试用例时，**三份文档需同步维护**。

## 七、完整示例（节选）

```
电商结算系统 (38条用例)
├── 管理端
│   └── 价格配置 [TC-PC]
│       ├── 普通定价模式
│       │   ├── TC-PC-001  成本价加客户价保存成功
│       │   └── TC-PC-002  客户价低于成本价拦截
│       └── 阶梯定价模式
│           ├── TC-PC-003  阶梯区间合法保存成功
│           └── TC-PC-004  阶梯区间倒挂保存拦截
└── 客户端
    └── 结算台 [TC-CK]
        └── 汇率结算
            ├── TC-CK-001  结算取最新已生效汇率
            └── TC-CK-002  历史订单汇率快照不跳变
```
