# 用户行为规律库

> 记录各角色用户在使用系统时的行为预期与操作习惯，用于指导测试设计时补充「用户行为符合性」测试点。
> 原始用户反馈数据统一归档于 `_原始反馈/` 目录，不再按项目拆分。

---

## 目录结构

```
用户行为规律库/
├── README.md                     # 本文件
├── _原始反馈/                    # 用户线上反馈原始数据（按月归档）
│   ├── _TAPD导出/                # TAPD 原始导出文件（.rtf/.xlsx）
│   └── YYYY-MM_反馈汇总.md       # 统一月度汇总，按反馈角色分类
├── Role_客服人员.md              # 已有 3 条行为规律
├── Role_业务员.md
├── Role_采购员.md
├── Role_仓库管理员.md
└── Role_B端外部客户.md           # 预留
```

---

## 工作流程

```
① 收到 TAPD 导出文件
        ↓
② 存入 _原始反馈/_TAPD导出/
        ↓
③ 整理至当月 YYYY-MM_反馈汇总.md（按角色分类，不按项目）
        ↓
④ 月底复盘：识别可提炼的行为规律条目
        ↓
⑤ 将新条目录入对应 Role_*.md 文件
```

---

## 使用方法

1. **测试设计阶段**：根据被测功能的目标用户角色，打开对应 `Role_*.md`
2. **检索相关条目**：找到与当前功能场景匹配的行为规律条目
3. **补充测试点**：将命中的行为规律转化为额外测试点，标注 `[行为符合性]`
4. **录入新条目**：有新反馈/观察时随时补充，月底统一整理
