## 1. 用户换取 Token 接口

接口地址：

```text
POST https://main-api.hubbuyer.com/open_api/v1/auth/token
```

请求类型：

```text
application/x-www-form-urlencoded
```

PHP cURL 示例：

```php
<?php

$curl = curl_init();

curl_setopt_array($curl, array(
  CURLOPT_URL => 'https://main-api.hubbuyer.com/open_api/v1/auth/token',
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_ENCODING => '',
  CURLOPT_MAXREDIRS => 10,
  CURLOPT_TIMEOUT => 0,
  CURLOPT_FOLLOWLOCATION => true,
  CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
  CURLOPT_CUSTOMREQUEST => 'POST',
  CURLOPT_POSTFIELDS => 'client_key=hubbuyer-JPN62&client_secret=06b203e7-4c71-41a4-982e-b9ec4b86bfa3',
  CURLOPT_HTTPHEADER => array(
    'Content-Type: application/x-www-form-urlencoded'
  ),
));

$response = curl_exec($curl);

curl_close($curl);
echo $response;
```

## 2. 商品列表查询接口

接口地址：

```text
POST https://main-api.hubbuyer.com/open_api/v1/product/search
```

请求类型：

```text
application/json
```

PHP cURL 示例：

```php
<?php

$curl = curl_init();

  CURLOPT_ENCODING => '',
  CURLOPT_MAXREDIRS => 10,
  CURLOPT_TIMEOUT => 0,
  CURLOPT_FOLLOWLOCATION => true,
  CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
  CURLOPT_CUSTOMREQUEST => 'POST',
  CURLOPT_POSTFIELDS =>'{

    "keyword_language": "ja",
    "page": 1,
    "page_size": 20,
    "price_min": 10,
    "price_max": 100,
    "ship_time": "48h",
    "sort": "sales_desc",
    "include_detail": false,
    "certified_factory": false,
    "one_piece_dropship": false,
    "new_arrival_7d": false,
    "selection_1688": false,
```

## 3. 商品详情查询接口

接口地址：

```text
POST https://main-api.hubbuyer.com/open_api/v1/product/detail
```

请求类型：

```text
application/json; charset=utf-8
```

PHP cURL 示例：

```php
<?php

$curl = curl_init();

curl_setopt_array($curl, array(
  CURLOPT_URL => 'https://main-api.hubbuyer.com/open_api/v1/product/detail',
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_ENCODING => '',
  CURLOPT_MAXREDIRS => 10,
  CURLOPT_TIMEOUT => 0,
  CURLOPT_FOLLOWLOCATION => true,
  CURLOPT_HTTP_VERSION => CURL_HTTP_VERSION_1_1,
  CURLOPT_CUSTOMREQUEST => 'POST',
  CURLOPT_POSTFIELDS =>'{
    "offer_id": "604016892818",
    "response_language": "ja",
    "include_sku": true,
    "include_html_detail": false
  }',
  CURLOPT_HTTPHEADER => array(
    'Authorization: Bearer <access_token>',
    'Content-Type: application/json; charset=utf-8'
  ),
));

$response = curl_exec($curl);

curl_close($curl);
echo $response;
```

说明：`offer_id` 应优先使用商品列表查询接口返回的 `data.items[].offer_id`。
