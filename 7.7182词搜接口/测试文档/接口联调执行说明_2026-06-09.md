# 7182词搜接口联调执行说明

本说明用于功能接口测试，不用于压力测试。

## 接口范围

| 模块 | 方法 | 地址 |
| --- | --- | --- |
| Token 获取 | POST | `https://main-api.hubbuyer.com/open_api/v1/auth/token` |
| 商品列表查询 | POST | `https://main-api.hubbuyer.com/open_api/v1/product/search` |
| 商品详情查询 | POST | `https://main-api.hubbuyer.com/open_api/v1/product/detail` |

## 执行脚本

脚本：`测试文档/7182_open_api_smoke_test.py`

该脚本覆盖：

- 正确凭据获取 Bearer Token。
- 使用日文关键词调用商品列表查询，并校验 `data.items[].offer_id`。
- 使用搜索返回的 `offer_id` 调用商品详情查询。
- 缺少 Bearer Token 调用业务接口的鉴权拦截。
- 空关键词参数错误拦截。

## 执行方式

使用 Client Secret 自动获取 Token：

```powershell
$env:OPEN_API_BASE_URL="https://main-api.hubbuyer.com"
$env:OPEN_API_CLIENT_KEY="hubbuyer-JPN62"
$env:OPEN_API_CLIENT_SECRET="<从安全凭据处获取>"
$env:OPEN_API_AUTH_BODY_TYPE="form"
$env:OPEN_API_KEYWORD="クリスマス"
python "D:\test_workspace\7.7182词搜接口\测试文档\7182_open_api_smoke_test.py"
```

说明：开发提供的 Token 获取样例使用 `application/x-www-form-urlencoded`，脚本默认 `OPEN_API_AUTH_BODY_TYPE=form`；若后端确认支持 JSON，可设置为 `json`。

已有 Bearer Token 时直接复用：

```powershell
$env:OPEN_API_BASE_URL="https://main-api.hubbuyer.com"
$env:OPEN_API_ACCESS_TOKEN="<Bearer Token 或纯 token>"
$env:OPEN_API_KEYWORD="クリスマス"
python "D:\test_workspace\7.7182词搜接口\测试文档\7182_open_api_smoke_test.py"
```

仅执行未授权/参数错误冒烟：

```powershell
python "D:\test_workspace\7.7182词搜接口\测试文档\7182_open_api_smoke_test.py" --negative-only
```

## 输出

执行结果会写入：

```text
D:\test_workspace\7.7182词搜接口\测试文档\接口执行结果\7182_open_api_smoke_YYYYMMDD_HHMMSS.json
```

结果文件会脱敏 `client_secret` 和 `access_token`，但仍应按测试证据管理，不上传公开仓库。
