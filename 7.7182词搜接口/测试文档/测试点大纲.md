## 测试前置条件

### 测试账号与数据

| 维度 | 最小准备 | 用途 |
|:--|:--|:--|
| API 客户 | `SKR7182` 启用客户 1 个、禁用客户 1 个、错误凭据 1 组 | 鉴权、禁用、错误凭据、限流验证 |

### 环境配置前置

- 开放接口域名或临时代域名可访问，HTTPS 配置完成。
- 1688 搜索和商详接口权限已开通，并完成服务端 AppKey、AppSecret、access_token 安全配置。
- 开放接口日志表、客户配置表、商品状态查询链路表具备测试环境数据。
- 调用日志记录页面能查询词搜、商详、状态查询三类路径。
- 前台商品状态查询页面能独立访问，不依赖后台左侧导航。

## 测试核心原则

**原则1：认证真相统一**

- 词搜、商详、商品状态查询必须共用同一套 `client_key/client_secret/Bearer Token`。
- 后台客户禁用、生成 Token、限流调整必须实时反映到开放接口行为。

**原则2：日文边界优先**

- 输入语言仅允许日文，未传语言默认日文。
- 对外错误消息、商品可见字段、前台页面文案优先日文。

**原则3：对外契约稳定，上游差异封装**

- 1688 字段名和筛选能力差异必须封装在 Adapter 内。
- 对外响应字段、状态码、错误消息、分页和 trace_id 保持稳定。

**原则4：日志可追踪但不泄密**

- 每次请求需要可通过 trace_id 追踪。
- Secret、Token、1688 access_token、AppSecret、签名、完整上游 URL 不得明文出现在日志和错误响应中。

**原则5：状态查询只读且以全球站状态为准**

- 前台商品状态查询不能修改订单、购物车或商品状态。
- 对外只展示 6 个日文商品状态，不暴露内部 `b2b_order.status` 或 `order_mark`。

## 测试点树

- 7182词搜接口测试点
  - 统一认证 AUTH
    - Token 获取接口
      - 正确凭据获取 Token 与过期时间
      - 缺少凭据、错误凭据、禁用客户的日文错误
      - Token 获取接口同时兼容 JSON 与樱花站 form-data 口径
    - Bearer Token 使用
      - 业务接口必须携带标准 Authorization 头
      - Token 缺失、无效、过期、禁用客户历史 Token 的拦截
      - Token 不允许出现在 query、日志和异常消息中
    - 客户级限流
      - 客户默认 60 次/分钟限流
      - 限流按 client_id 生效并写入日志
  - 词搜列表 SRCH
    - 日文关键词搜索
      - 日文关键词返回日文商品列表和 `offer_id`
      - 未传 `keyword_language` 默认 `ja`
      - 非日文语言或明显中文关键词返回 400
      - 搜索无结果返回 200 且 `items=[]`
    - 筛选与排序
      - 价格、销量、类目、发货时效、认证工厂、一件代发、7天上新、严选组合筛选
      - 起订量、复购率、店铺评分候选集过滤与 `filter_notes`
      - 排序白名单与非法排序拦截
      - 未知筛选字段返回 400
    - 详情补充与缓存
      - `include_detail=false` 只返回列表
      - `include_detail=true` 当前页最多 20 个商品
      - 部分商品详情失败时整体搜索仍返回
      - 不同筛选、排序、语言缓存 key 不串用
  - 商品详情 DET
    - 单品详情
      - 使用搜索返回的 `offer_id` 查询日文详情
      - `offer_id` 缺失、非法、商品不存在或下架的错误处理
      - SKU、图片、价格、属性、供应商、服务标签缺失时字段兜底
      - `include_html_detail` 默认不开放完整 HTML
    - 上游适配
      - 1688 鉴权失败、超时、限流的稳定错误
      - 详情缓存命中与未命中
      - 上游密钥和签名不向外暴露
  - 商品状态查询 STAT
    - 查询接口
      - 同一 Bearer Token 调用 `/product/status_v2`
      - 按消费者订单号查询该订单全部商品
      - 按 SKU、JAN、状态、时间范围组合查询
      - 无筛选条件分页返回最近数据
      - `page/limit/sort/status` 非法参数拦截
    - 状态口径
      - 6 个对外日文状态筛选和返回
      - 内部全球站订单状态和全商品状态不暴露
      - 导入记录、cart_id、订单、全商品链路缺失的兜底
      - 查询为空返回 200 且 `items=[]`
    - 响应字段
      - 商品番号、商品名称、状態、管理番号、SKU、JAN、属性、数量、運単番号、注文日時完整性
      - 注文日時显示到分钟
  - API客户授权 ADM
    - 客户列表与筛选
      - 客户ID 默认 `SKR7182`
      - 页面不展示、不录入用户ID
      - Secret、Token 展示和复制的脱敏与审计
    - 客户操作
      - 添加客户自动生成 Secret 和初始 Token
      - 生成 Token 后更新摘要与更新时间
      - 禁用客户后 Token 获取和业务接口被阻断
      - 行内调整限流实时生效
  - 调用日志记录 LOG
    - 统计与筛选
      - 点击搜索后展示今日请求、成功、失败、限流、平均响应
      - 按客户ID、状态、时间范围查询日志
      - 重置后恢复初始筛选
    - 脱敏与追踪
      - 日志列表路径、参数摘要、响应码、耗时、错误分类可追踪
      - Secret、Token、1688 密钥和签名不明文展示
  - 前台商品数据查询 UI
    - 认证态
      - 初始未认证状态下筛选区、搜索、分页、列表不可操作
      - Client Key / Secret 认证成功后启用查询区
      - 认证失败和解除认证恢复不可操作状态
    - 查询与展示
      - 点击「検索」后展示统计和商品一覧
      - 点击「リセット」清空筛选并收起统计结果
      - 商品一覧固定 20 个字段、单行展示、超出省略号
      - Sakura 照会ページ新窗口跳转
      - 页面全日文，不展示内部状态口径和数据库字段
