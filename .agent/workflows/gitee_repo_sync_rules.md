# 远端 Gitee 仓库操作规范与权限控制

执行前先读取 `.agent/dependencies.yaml`，路径引用以 `deps.<alias>` 为准。

在执行任何与 Gitee 相关的代码操作（如克隆、拉取、查询、提交、推送）时，系统必须严格遵守以下对两个核心仓库的操作权限规则：

### 1. 仓库：`义乌市协润进出口有限公司/global-test`
* **管理者角色**：本人维护的核心工作仓库。
* **操作权限**：**读写权限（Read & Write）**
* **允许行为**：
  - 可以获取与拉取代码（`git fetch` / `git pull`）
  - 可以修改内容并执行本地提交（`git commit`）
  - **可以**并且被允许将更新内容**推送**到远端仓库（`git push`）
* **对应本地路径**：`deps.test_workspace_root`

### 2. 仓库：`义乌市协润进出口有限公司/global-workspace`
* **管理者角色**：由项目经理（PM）维护的需求与文档仓库。
* **操作权限**：**只读权限（Read-Only）**
* **允许行为**：
  - 只能获取、拉取、对比或抓取该仓库的内容，用于同步最新的 PRD 或产品更新。
  - 本地需求文档入口参考 `deps.pm_docs_root`。
  - **严格禁止**执行任何修改推送到此远端仓库的操作。无论是自动执行还是执行 `git push` 命令，在此仓库中均被明确禁止。
