# Reflections

Store task-level reflections here when a task produces reusable lessons.

Recommended file name:

```text
YYYY-MM-DD_{project}_{task}.md
```

Recommended structure:

```markdown
# Reflection

| Field | Value |
|---|---|
| Date | YYYY-MM-DD |
| Project | project-id |
| Role | Agent 1 / Agent 2 |
| Task | short task name |

## What Changed

## Reusable Lessons

## One-Off Observations

## Memory Updates

## Promotion Candidates
```
