## 三、 【防篡改溯源墙】汇款金额强制锁定核销流程

针对 3.1.1 `会员支付.html` 等汇款入金模块，为防御前端金额篡改攻击，保障资金汇率精确转接的核心安全逻辑：

```mermaid
sequenceDiagram
    participant Frontend as 用户端-会员支付表单
    participant Node as 前端控制器-表单构建
    participant API as 后端微服务-资金核销API
    participant DB as DB-2.2.1 会员大盘库
    
    Frontend->>Frontend: 选择指定国家下的特定身份卡包
    Frontend->>Node: 传递跳转参：{国家ID, 拟购等级ID}
    Node-->>Frontend: 渲染：仅展示只读格式化金额 (无法使用Input编辑)
    Frontend->>API: 填妥单据，发起资金汇款台账登记
    
    Note over API: 警告：后端此节点全面废弃并拒收<br/>由前端传来的预估充值金额(amount)
    
    API->>DB: 携带 {国家ID, 当前用户等级ID} 查询全球主配表
    DB-->>API: 严格返回【官方唯一外币基准定价】
    API->>API: 根据官方定价和安全基数生成充值待核销台账单
    API-->>Frontend: 下发成功回调：单据已生成，款项待财务到账清算
```
