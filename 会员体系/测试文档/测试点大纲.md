## 测试核心原则（必读）

本次会员体系优化测试需始终围绕以下4个核心原则展开：

**原则1：不同国家拥有独立的会员体系**
- 每个国家单独配置开通哪些会员等级、对应的价格
- 测试时必须区分国家维度，A国配置不得影响B国展示

**原则2：区分注册用户与付费会员的下单权限**
- 已开通一般会员的国家：注册即可下单
- 未开通一般会员的国家：注册为普通用户，需购买付费会员方可下单
- 拦截点在下单提交页（非购物车）

**原则3：不同会员等级对应不同的附加项价格**
- 同一国家下，不同等级会员看到的附加项价格不同（等级越高价格越优惠）
- 前台展示必须精准取当前登录用户所属等级的对应价格，不允许跨等级串价

**原则4：大客专属价格优先于会员体系价格**
- 管理端为特定用户配置了专属定价后，该用户前台始终展示专属价
- 专属价同时展示原公盘价（带删除线）作为对比
- 无论会员等级如何变化，专属价均保持最高优先级

**原则5：进行中的订单价格不受会员变更影响**
- 订单生成后，即使用户会员升/降级，或后台调整了价格配置，该订单的计费金额维持下单时的历史快照价格不变
- 此规则适用于报价单、结算单等所有已生成的单据

- 会员体系优化测试点
  - 管理端
    - 会员等级基础库
      - 新增/编辑会员等级名称，多语种填写保存
      - 会员介绍文字（多语种）填写后，前台介绍中心对应等级的权益说明正确展示对应语言
      - 成为条件设为"邀请制"后，全球会员定价页该级别的所有金额输入框隐藏
        - 验证点：切换至邀请制Tab（如VIP），"会员定价"区域（会员期限/会员费/原价/添加按钮）整体消失
        - 验证点：邀请制Tab仍保留代采手续费阶梯配置和上架设置字段
      - 会员等级排序数值影响前台展示顺序
      - VIP 授权管理
        - 管理端手动为指定用户添加 VIP 等级，可设置起止期限
        - VIP 授权成功后，该用户前台会员身份实时刷新为 VIP（缓存清除验证）
        - VIP 到期后自动降回原等级（已开通一般会员的国家→一般会员，未开通的国家→普通用户）
        - 管理端可提前撤销 VIP，撤销后前台即时失效
    - 全球会员定价（按国家配置）
      - 开通一般会员的国家
        - 开启一般会员后，该国所有注册用户立即具备下单权限
        - **【重点】** 存量普通用户（未开通一般会员期间已注册的账号）开通一般会员后，无需重新注册，自动获得下单权限（含缓存清除验证）
        - **【重点】** 关闭一般会员后，该国注册用户立即被拦截无法下单（含缓存及时失效验证）
      - 未开通一般会员的国家
        - **【重点】** 新注册用户为普通用户，下单页被拦截，引导购买付费会员
      - 全球会员定价列表国家状态
        - 某国状态置为"已禁用"，前台该国会员购买页对应等级不再展示
        - 启用/禁用实时生效（验证缓存清除）
      - 会员定价期限配置上限：每个等级最多添加5个期限套餐，添加第6个时按钮置灰/无效
      - 代采手续费阶梯配置
        - 最多添加5级，添加第6级按钮置灰/无效
        - **【重点】** 阶梯区间倒挂（如100以上后配50以上），保存时报错拦截
        - 阶梯区间重叠（两行设置相同起始值），保存时报错拦截
      - 原价与会员费关系校验
        - **【重点】** 原价 < 会员费时，保存拦截（定价倒挂）
        - 原价 = 0 时，保存拦截
      - 上架设置
        - 选择"现在上架"：确定后该卡立即在前台充值大厅可见
        - 选择"指定时间"：显示时间选择器，到达指定时间前前台不可见，到达后自动上架
        - 指定时间早于当前时间，保存时报错拦截
      - 多等级Tab独立性
        - 切换"一般会员/EC/VIP"各Tab，每个等级独立保存，修改一个不影响其他
      - 会员费防损校验
        - 实际收取会员费 ≤ 0，输入框报错拦截
    - 全球服务定价（按国家×会员等级）
      - 会员身份矩阵动态裂变
        - 该国启用N个会员等级，附加项价格配置右侧生成N套独立输入框
        - 不同等级的价格互相隔离，不串用
      - 六大计费模式切换（开封相关内容不测）
        - **【重点】** 切"普通"：显示成本价+客户价，客户价<成本价时保存拦截
        - 切"阶梯"：可动态添加阶梯行，各阶区间不得倒挂重叠
        - 切"起订量"：显示最低起订数量字段，前台不足起订量按最低量计费
        - 切"按套"：显示包含件数字段，前台用件数/套数向上取整计费
        - 切"按时"：显示时价，单位继承自基础库不可修改
        - 切"相谈"：所有金额输入框隐藏，前台展示"面议"
        - 面议附加项不在下单时计费，由后台在清算单阶段手动填写实际金额后再结算
      - 基础库联动验证
        - 附加项基础库中将某项"禁用"后，全球服务定价配置该项应自动不可用
        - 商品附加项 / 发货附加项 两类在服务定价中独立显示，互不混用
        - 质检方式"按件"/"按时"计费类型，在服务定价切换对应模式后单位正确继承（不可手改）
      - 国家配置状态（启用中/已禁用）
        - 全球服务定价列表中，某国状态置为"已禁用"后，前台该国的附加项价格不再展示
        - 启用/禁用操作需实时生效（验证缓存及时清除）
    - 客户详情（大客专属定价）
      - 附加项设置按会员等级列（EC/EC&OEM/VIP）×附加项行展示开关
        - 每个附加项对每个会员等级有独立开关，关闭后该等级用户不可使用该附加项
        - 切换开关后验证前台该用户对应等级的附加项可用性实时变化
      - 自定义价格（大客专属覆写）
        - 每行附加项可按阶梯数量（1~5件/6~30件/31~∞）独立覆写单价
        - 覆写后价格字体显示为红色（区别于公盘价黑色），页面底部"以下附件对该客专用(自定义)的价格"区汇总展示
        - **【重点】** 修改后价不得低于成本底价，否则拦截
        - 恢复默认：该附加项全阶梯价格回归公盘价，红色消失从汇总区移除
      - **【重点】** 大客专属价优先级最高（Priority Override）：即使专属价配置得比当前会员价**更高**，或管理端关闭了该等级的附加项开关，任何情况下均强行以专属价计费，严禁底层作弊或因便宜而绕道。
    - 入金审核（充值会员费通道）
      - 四步弹窗流程：汇款记录 → 复核信息 → 传输凭证确认 → （驳回时）填写驳回原因
      - **【重点】** 汇率每日更新一次，审批页汇率字段只读，锁定用户**提交当日**的日汇率
      - **【重点】** 跨日审核验证：用户23:59提交，次日00:01审核，审批页显示仍为提交当日汇率，不随当日汇率更新
      - 凭证图片：管理端可查看用户上传凭证，且凭证图片可放大/下载
      - 初步确认 → 最终确认（复核），两步完整后资金才入账
      - 最终确认后不可撤销/驳回
      - 驳回：必须填写驳回原因，驳回原因发送至用户站内信/通知
      - 驳回原因文本框为必填项，空提交时前端拦截
      - **【重点】** 充值金额进入会员费账户，与可提现余额（B2B余额）严格隔离
      - **【重点】** 审批通过后，用户会员身份实时更新（缓存清理验证）

    - 介绍中心-服务/费用
      - 未登录状态：展示默认公盘价（最低等级价），登录后按会员等级实时刷新
      - 邀请制会员等级（如VIP）：展示对应等级的服务价格，但购买/升级入口不对非受邀用户开放
      - **【重点】** 切换国家，会员等级展示和附加项价格完全重新拉取对应国家数据
      - 会员卡超过3张时，界面触发横向滚动，不出现排版错位
      - 阶梯价附加项显示价格区间（最低值~最高值），而非固定单价
      - hover [?] 图标，弹出阶梯价分档明细
      - 多期限选项（MO月/1Y年/5Y五年）
        - 各期限价格独立展示，选择不同期限后购买金额对应变更
        - 续费后有效期 = 当前到期时间 + 所选期限（秒级精确累加）
      - 各等级权益对比表

        - 红字标注的价格字段（阶梯价）正确显示价格区间格式
    - 购物车
      - **【重点】** 购物车中附加项价格按当前登录用户的会员等级显示
      - 等级升级后重新进入购物车，价格即时刷新为新等级价格
      - **【重点】** 会员到期后重新进入购物车：附加项价格自动降为到期后等级（一般会员/普通用户）对应的价格
      - 有大客专属价的用户：购物车展示专属价+原价删除线对比
      - 购物车本身无会员准入拦截，拦截发生在提交下单时
    - 【Rule 5 底量架构】底层币种对账与转换
      - **【重点】** 购物车至附加项的所有中间计算必须严格使用 **CNY（人民币）** 作为基准计费底座进行求和 `*[V2变更]*`
      - **【重点】** 下单瞬间（前端结算台显示前），验证引擎调用外部接入的"当日带安全点数汇率" 将 CNY 转换为 Client 国别所在币种（JPY/USD/KRW） `*[V2变更]*下单时刻锚定`
      - USD换算后严格保留2位小数入库，而JPY向下/向上取整无小数，防止溢出或账目黑洞
    - 会员支付
      - 余额支付通道
        - 余额充足时，直接扣减购买会员，身份实时生效
        - 余额不足时，提示余额不足，不允许提交
        - 不支持余额+充值组合支付
        - 升级补差价为0时，正常完成升级
        - **【重点】** 升级溢转：残值>新卡费，差额1:1转入B2B余额钱包，不吞没
      - 入金（充值）通道
        - 汇款金额三步流程：①确认金额（只读） → ②选择银行账号并复制汇款信息 → ③填写汇款人信息+上传凭证
        - 银行账号支持多个（如JP Morgan/Citibank），用户任选其一
        - "复制信息"按钮：点击后银行信息一键复制至剪贴板，验证内容完整无截断
        - 汇款金额页面锁死只读，取后台配置价格，不可手动输入
        - 凭证上传支持图片格式，上传后显示缩略图，可删除重传
        - 提交申请后生成历史记录，状态显示"审核中"
        - 历史记录三种状态：审核中 / 已到账 / 拒绝（驳回原因展示在对应行）
        - 审核驳回时，驳回原因展示在记录列表对应行
      - **【重点】** 通道互斥
        - 两种通道各自独立，不能部分余额+部分充值
    - 附加项-番号管理
      - 页面分为两个区域：オプション本詳（服务附加项）和 相関荷物配備（发货附加项），各自独立展示价格
      - 阶梯价服务项展示价格区间（最低~最高），非固定价
      - 有大客专属价的用户：展示红色高亮的专属价+带删除线的原价对比
      - 无大客专属价的用户：展示对应会员等级的公盘价
      - **【重点】** 实际下单计费验证：提交后后端计费取专属价，历史订单专属价被修改后仍保持下单时金额
    - 下单页（会员准入拦截） `*[V2变更]*`
      - 已开通一般会员的国家注册用户：无拦截，正常下单
      - **【重点】** 未开通一般会员的国家普通用户：拦截，弹出引导购买付费会员 `*[V2新增]*强核通过防线`
      - 未开通一般会员的国家付费会员（有效期内）：正常下单
      - **【重点】** 未开通一般会员的国家付费会员（已过期）：拦截 `*[V2新增]*强核通过防线`
    - 【Rule 6 防串血框架】越级与缓存清洗
      - **【重点】** API鉴权层隔离：利用工具强篡改接口中的 `country` 字段至他国，后端鉴权层检测到绑定国家不一致，抛出异常熔断拦截，不返回任何混杂信息
      - **【重点】** Client缓存彻底销毁：同设备中退出日本账号切换登录美国账号时，严格检查上一段的 Session / LocalStorage（含遗留大客专属价、日本站独特附加项）必须被彻底抹除清空不生效
  - 会员生命周期（跨端验证）
    - 同级续费（支持MO月/1Y年/5Y五年多期限）
      - **【重点】** 续费后到期时间 = 原到期时间戳 + 所选期限对应秒数（精确到秒）
      - 多次续费天数正确累加，期限不同时各自正确折算
    - 升级购买
      - 期限天数换算：MO=30天，1Y=365天，5Y=1825天
      - **【重点】** 残值 = 剩余天数/总天数 × 历史实付会员费（取历史价格快照，非当前配置价）
      - 应付差价 = 新卡费 - 残值
      - 差价>0：正常付款，升级成功，天数重置
      - 差价=0：免费升级成功
      - **【重点】** 差价<0（溢转）：升级成功，多余金额1:1转入B2B余额，不吞没不抹零
    - 会员降级
      - 前端购买页低级别卡置灰，不可点击
      - 高级卡未过期时无法切换低级卡
      - 已开通一般会员的国家付费会员到期 → 自动降回一般会员（仍可下单）
      - **【重点】** 未开通一般会员的国家付费会员到期 → 自动降回普通用户（下单被拦截）
    - 历史价格快照（进行中订单价格锁定） `*[V2新增]*快照固化隔离`
      - **【重点】** 已生成的报价单/结算单，后台调价后，历史单据金额不变 `*[V2新增]*`
      - **【重点】** 用户会员升级后，之前进行中的订单仍按下单时的等级价格计算，不切换为新等级价格
      - **【重点】** 用户会员降级/过期后，之前进行中的订单价格不变
      - **【重点】** 大客专属价被管理端修改或重置后，已生成的历史单据不受影响 `*[V2新增]*`
