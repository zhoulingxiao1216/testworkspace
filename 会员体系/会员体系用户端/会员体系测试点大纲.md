## 测试核心原则（必读）

本次会员体系优化测试需始终围绕以下4个核心原则展开：

**原则1：不同国家拥有独立的会员体系**
- 每个国家单独配置开通哪些会员等级、对应的价格
- 测试时必须区分国家维度，A国配置不得影响B国展示

**原则2：区分注册用户与付费会员的下单权限**
- B2C国家（开通一般会员）：注册即可下单
- B2B国家（未开通一般会员）：注册为普通用户，需购买付费会员方可下单
- 拦截点在下单提交页（非购物车）

**原则3：不同会员等级对应不同的附加项价格**
- 同一国家下，不同等级会员看到的附加项价格不同（等级越高价格越优惠）
- 前台展示必须精准取当前登录用户所属等级的对应价格，不允许跨等级串价

**原则4：大客专属价格优先于会员体系价格**
- 管理端为特定用户配置了专属定价后，该用户前台始终展示专属价
- 专属价同时展示原公盘价（带删除线）作为对比
- 无论会员等级如何变化，专属价均保持最高优先级

**原则5：进行中的订单价格不受会员变更影响**
- 订单生成后，即使用户会员升/降级，或后台调整了价格配置，该订单的计费金额维持下单时的历史快照价格不变
- 此规则适用于报价单、结算单等所有已生成的单据

- 会员体系优化测试点
  - 管理端
    - 会员等级基础库
      - 新增/编辑会员等级名称，多语种填写保存
      - 成为条件设为"邀请制"后，全球会员定价页该级别的所有金额输入框隐藏
      - 会员等级排序数值影响前台展示顺序
    - 全球会员定价（按国家配置）
      - B2C模式：该国开通"一般会员"
        - 开启一般会员后，该国所有注册用户立即具备下单权限
        - 关闭一般会员后，该国注册用户立即被拦截无法下单（含缓存及时失效验证）
      - B2B模式：该国未开通"一般会员"
        - 新注册用户为普通用户，下单页被拦截，引导购买付费会员
      - 会员卡应用状态切换（应用中/未应用）
        - 置为"未应用"后，前台充值大厅该卡立即下架
      - 代采手续费阶梯配置
        - 最多添加5级，添加第6级按钮置灰/无效
        - 阶梯区间倒挂（如100以上后配50以上），保存时报错拦截
        - 阶梯区间重叠（两行设置相同起始值），保存时报错拦截
      - 会员费防损校验
        - 实际收取会员费 ≤ 0，输入框报错拦截
    - 全球服务定价（按国家×会员等级）
      - 会员身份矩阵动态裂变
        - 该国启用N个会员等级，附加项价格配置右侧生成N套独立输入框
        - 不同等级的价格互相隔离，不串用
      - 六大计费模式切换（开封相关内容不测）
        - 切"普通"：显示成本价+客户价，客户价<成本价时保存拦截
        - 切"阶梯"：可动态添加阶梯行，各阶区间不得倒挂重叠
        - 切"起订量"：显示最低起订数量字段，前台不足起订量按最低量计费
        - 切"按套"：显示包含件数字段，前台用件数/套数向上取整计费
        - 切"按时"：显示时价，单位继承自基础库不可修改
        - 切"相谈"：所有金额输入框隐藏，前台展示"面议"
    - 客户详情（大客专属定价）
      - 未开启自定义：附加项价格面板锁定只读，取公盘价
      - 开启自定义后：
        - 可修改附加项单价
        - 修改后价不得低于成本底价，否则拦截
        - 被修改的价格字体红色高亮显示
      - 恢复默认：价格重置为公盘价，红色高亮消失
      - 大客专属价优先级高于会员体系价格（同时存在时取专属价）
    - 入金审核（充值会员费通道）
      - 审批页汇率字段只读，锁定用户提交时刻的汇率快照
      - 汇率快照锁定验证：提交后汇率变动，审批页金额不变
      - 初步确认 → 最终确认，两步审批流程完整
      - 最终确认后不可撤销/驳回
      - 驳回必须填写原因，原因发送至用户站内信
      - 充值金额进入会员费账户，与可提现余额（B2B余额）严格隔离
      - 审批通过后，用户会员身份实时更新（缓存清理验证）
  - 客户端
    - 介绍中心-服务/费用
      - 切换国家，会员等级展示和附加项价格完全重新拉取对应国家数据
      - 会员卡超过3张时，界面触发横向滚动，不出现排版错位
      - 阶梯价附加项显示价格区间（最低值~最高值），而非固定单价
      - hover [?] 图标，弹出阶梯价分档明细
    - 会员支付
      - 余额支付通道
        - 余额充足时，直接扣减购买会员，身份实时生效
        - 余额不足时，提示余额不足，不允许提交
        - 不支持余额+充值组合支付
        - 升级补差价为0时，正常完成升级
        - 升级溢转：残值>新卡费，差额1:1转入B2B余额钱包，不吞没
      - 入金（充值）通道
        - 汇款金额页面锁死只读，取后台配置价格，不可手动输入
        - 提交申请后生成历史记录，审核状态实时显示
        - 审核驳回时，驳回原因展示在记录列表
      - 通道互斥
        - 两种通道各自独立，不能部分余额+部分充值
    - 附加项-番号管理
      - 阶梯价服务项展示价格区间（最低~最高），非固定价
      - 有大客专属价的用户：展示红色高亮的专属价+带删除线的原价对比
      - 无大客专属价的用户：展示对应会员等级的公盘价
    - 下单页（会员准入拦截）
      - B2C国家注册用户：无拦截，正常下单
      - B2B国家普通用户：拦截，弹出引导购买付费会员
      - B2B国家付费会员（有效期内）：正常下单
      - B2B国家付费会员（已过期）：拦截
  - 会员生命周期（跨端验证）
    - 同级续费
      - 续费后到期时间 = 原到期时间戳 + 30×24×3600秒（精确到秒）
      - 多次续费天数正确累加
    - 升级购买
      - 残值 = 剩余天数/总天数 × 历史实付会员费（取历史价格快照，非当前配置价）
      - 应付差价 = 新卡费 - 残值
      - 差价>0：正常付款，升级成功，天数重置
      - 差价=0：免费升级成功
      - 差价<0（溢转）：升级成功，多余金额1:1转入B2B余额，不吞没不抹零
    - 会员降级
      - 前端购买页低级别卡置灰，不可点击
      - 高级卡未过期时无法切换低级卡
      - B2C国家付费会员到期 → 自动降回一般会员（仍可下单）
      - B2B国家付费会员到期 → 自动降回普通用户（下单被拦截）
    - 历史价格快照（进行中订单价格锁定）
      - 已生成的报价单/结算单，后台调价后，历史单据金额不变
      - 用户会员升级后，之前进行中的订单仍按下单时的等级价格计算，不切换为新等级价格
      - 用户会员降级/过期后，之前进行中的订单价格不变
      - 大客专属价被管理端修改或重置后，已生成的历史单据不受影响
