# SEO优化测试点大纲

> 基于 `SEO优化.txt` 整理。当前需求仅明确 B2B 首页、产品分类页、产品页的 SEO 优化方向；URL 生成规则、多语言范围、Schema 字段来源等执行口径见 `审计待确认问题单.md`。

## 测试前置条件

### 测试账号准备

| 维度 | 参数 | 需要的账号类型 |
|:--|:--|:--|
| B2B 前台 | 首页、分类页、产品页 | 无登录访问账号 × 1，用于游客态爬虫验证 |
| B2B 后台 | SEO 配置、分类、产品资料 | 运营/管理员账号 × 1，用于配置 title、description、slug |
| 技术验证 | 接口/HTML/日志 | 测试执行账号 × 1，用于 curl、抓包、日志核对 |

### 管理端/环境配置前置

- 准备至少 3 个产品分类，覆盖英文别名、拼音别名、长别名。
- 准备至少 6 个产品，覆盖正常资料、缺描述、缺图、下架、长标题、特殊字符标题。
- 准备旧 URL 样本，包括参数 ID 链接、带后缀链接、大小写变体、尾斜杠变体。
- 明确多语言范围、默认语言、SEO 字段后台配置优先级和缓存生效 SLA。
- 准备 robots.txt、sitemap.xml 或对应生成接口的访问方式。

### 特殊模式说明

> **代码可读模式**：所有 SEO 核心字段必须通过初始 HTML、查看源代码或服务端渲染结果读取，不能只依赖浏览器执行 JS 后的 DOM。

> **条件执行模式**：多语言语言集合、Schema 字段完整度、旧链接 301 策略若未确认，Agent2 执行时标记 Conditional，不直接判缺陷。

## 测试核心原则（必读）

**原则1：SEO 字段先验可读**
- title、description、canonical、Schema 等核心字段必须在页面初始 HTML 中稳定可读。
- 禁用 JS 或使用爬虫请求时，不能丢失关键 SEO 信息。

**原则2：URL 规范优先于页面可访问**
- 新 URL 不仅要能访问，还必须符合伪静态、英文/拼音、无后缀、无参数、无纯数字 ID 的规范。
- 同内容只允许一个规范可收录 URL，避免重复收录。

**原则3：页面类型与结构化数据一致**
- 首页、分类页、产品页分别输出适配自身页面类型的 Schema。
- JSON-LD 字段必须来自当前页面数据，不允许串分类、串产品、串语言。

**原则4：多语言 SEO 不串文案**
- HTML lang、hreflang、title、description、Schema 文案必须与当前语言一致。
- 多语言互链必须指向真实存在的等价内容页。

**原则5：SEO 配置变更可回滚可追踪**
- 后台保存 title、description、slug 后，前台在约定 SLA 内生效。
- 修改 URL 时旧链接跳转、canonical、sitemap 同步更新，不破坏历史访问。

- SEO优化测试点
  - 元信息可爬取
    - 首页 SEO 元信息初始 HTML 可读取
      - 验证点：title 唯一且主题匹配
      - 验证点：description 存在且非空
      - 验证点：禁用 JS 或 curl 仍能读取
    - 产品分类页 SEO 元信息初始 HTML 可读取
    - 产品详情页 SEO 元信息初始 HTML 可读取
    - **【重点】** SEO 后台配置保存后的前台缓存生效
      - 验证点：title/description 更新生效
      - 验证点：不同页面和语言不互相污染
    - 空 SEO 字段和超长 SEO 字段兜底策略
    - title、description 特殊字符转义与页面布局安全
  - URL 伪静态
    - **【重点】** 产品分类页 URL 结构符合 `域名/分类别名`
    - **【重点】** 产品详情页 URL 结构符合 `域名/分类别名/产品别名`
    - 普通页面 URL 结构符合 `域名/页面别名`
    - URL 禁止中文、纯数字 ID、后缀和查询参数
    - 分类别名和产品别名唯一性冲突处理
    - 旧 URL 到新 URL 的跳转兼容
    - canonical 指向规范 URL，防止重复收录
    - 404、禁用分类、下架产品 URL 处理
  - 产品分类页 SEO
    - 分类页 title、description 与分类主题一致
    - 分类页商品列表与分类归属一致
    - 分类页 BreadcrumbList 输出正确
    - 分类页 ItemList 与当前列表商品一致
    - **【重点】** 分类页分页、筛选、排序 canonical/noindex 策略
    - 分类缺图、缺描述、空商品列表兜底
  - 产品详情页 SEO
    - 产品页 title、description 与当前商品一致
    - 产品详情内容、图片、价格、币种在 SEO 字段中来源正确
    - Product Schema 必填字段合法
    - Product Schema 价格、库存、图片字段空值兜底
    - **【重点】** 产品下架、禁用、404 状态下的 SEO 处理
    - 商品名称特殊字符、长文本、多规格信息安全展示
  - 多语言与 Schema.org
    - HTML lang 与页面语言一致
    - **【重点】** hreflang 多语言互链完整且状态正常
    - x-default 默认入口指向正确
    - 不同语言 title、description、Schema 文案隔离
    - 首页 Organization/WebSite JSON-LD 合法
    - 分类页 ItemList/BreadcrumbList JSON-LD 合法
    - 产品页 Product/BreadcrumbList JSON-LD 合法
  - 安全回归与爬虫入口
    - robots.txt 不误屏蔽首页、分类页、产品页
    - sitemap.xml 仅包含规范 URL 且覆盖新增分类/产品页
    - SEO 字段、slug、Schema JSON 字段防 XSS 和 JSON 注入
    - SEO 优化不影响页面核心功能、登录态、商品浏览和跳转
    - 页面响应状态、重定向链路和性能可接受
