# SEO优化架构级需求摘要

> Agent1 基于 `SEO优化.txt` 与首页 `https://b2b.hubbuyer.com/` 的轻量可访问性确认整理。本摘要仅作为测试设计输入，不替代 Agent2 的正式执行结果。

## 一、信源档案

| 信源 | 类型 | 处理结果 | 摘要 |
|:--|:--|:--|:--|
| `SEO优化.txt` | 需求文本 | 已读取 | B2B 平台首页、产品分类页、产品页需要代码可读 SEO 信息、URL 伪静态、多语言和 Schema.org 结构化数据优化。 |
| `https://b2b.hubbuyer.com/` | 线上首页 | 已轻量访问 | HTTP 200；HTML title 可读取为 `Hubbuyer | B2B Sourcing Platform`；description、canonical、hreflang、JSON-LD 需在正式测试中继续验证。 |

## 二、业务范围

| 范围 | 页面类型 | 验收重点 |
|:--|:--|:--|
| 范围内 | 首页 | 服务端可读取 `<title>`、description、语言标识、canonical、Schema.org 基础结构化数据。 |
| 范围内 | 产品分类页 | URL 形态为 `域名/分类别名`，不含中文、ID、查询参数或文件后缀；具备分类维度 title、description、ItemList 或 BreadcrumbList 数据。 |
| 范围内 | 产品详情页 | URL 形态为 `域名/分类别名/产品别名`；具备产品详情 title、description、Product Schema、canonical 与面包屑。 |
| 范围内 | 多语言 SEO | 不同语言页面输出对应语言的 title、description、canonical/hreflang，避免语言串文案。 |
| 范围内 | 爬虫可读性 | SEO 关键信息出现在初始 HTML 或服务端渲染结果中，禁止仅依赖客户端 JS 后填充。 |
| 非范围 | 排名效果保证 | 搜索引擎收录排名、自然流量提升属于上线后观测指标，不作为本轮功能测试通过条件。 |
| 非范围 | 内容运营质量评分 | 商品标题和描述是否达到营销最佳写法由运营/产品确认，测试仅校验字段完整、来源正确、格式可读。 |

## 三、核心验收口径

| 主题 | 验收口径 |
|:--|:--|
| 元信息可读取 | 首页、分类页、产品页的初始 HTML 中可读取唯一有效 `<title>` 和 `meta name="description"`；内容与页面主题匹配。 |
| URL 伪静态 | 分类页形如 `/Menswear` 或 `/shuma`；产品页形如 `/Menswear/product-slug`；不出现 `.html`、`.php`、`?id=`、中文、纯数字 ID。 |
| 旧链接兼容 | 旧 ID/参数链接若仍对外存在，应 301 到新规范 URL，canonical 指向新 URL。 |
| 多语言 | 页面语言、title、description、canonical/hreflang 组合一致；同一内容的多语言版本可互相声明。 |
| Schema.org | 首页、分类页、产品页分别输出合理 JSON-LD；Product、ItemList、BreadcrumbList、Organization/WebSite 等结构字段合法。 |
| 安全与回归 | URL 别名和 SEO 字段需要防 XSS、重复别名冲突、空值兜底、缓存更新一致。 |

## 四、主要风险与待确认项

| 风险 | 影响 | 建议 |
|:--|:--|:--|
| URL 别名来源未明确 | 会影响分类/产品 slug 生成、重复冲突和历史链接迁移口径 | 开发或产品提供分类别名、产品别名生成规则和唯一性策略。 |
| 多语言范围未明确 | hreflang 和多语言元信息用例无法确定完整覆盖语言 | 明确本次至少支持的语言集合、默认语言和 x-default 规则。 |
| Schema 字段来源未明确 | Product 价格、库存、图片、品牌、评分等字段可能无法稳定断言 | 提供字段映射表，标注必填、可选和不可用字段。 |
| 旧链接迁移策略未明确 | 301/302、canonical、sitemap 更新无法最终判定 | 明确旧 URL 是否保留入口、跳转状态码、跳转有效期和日志监控。 |
| 缓存与 CDN 刷新策略未明确 | SEO 修改后线上页面可能长期展示旧内容 | 明确后台保存到前台 HTML 生效 SLA 和强刷方式。 |
