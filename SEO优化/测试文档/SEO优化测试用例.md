# SEO优化测试用例

生成日期：2026-06-12  
需求来源：`SEO优化.txt`  
说明：本用例集用于 B2B 平台首页、产品分类页、产品详情页 SEO 优化验收。多语言范围、Schema 字段来源、旧链接跳转策略等待确认项已在 `审计待确认问题单.md` 标记，执行时可按确认结果 Execute 或 Conditional。

## 2. URL 伪静态

### 2.1 分类和产品规范 URL

#### TC-SEO-URL-001 【重点·正向】产品分类页 URL 符合域名加分类别名 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 产品分类页 URL 结构符合 `域名/分类别名` |
| **优先级** | Critical |
| **前置条件** | 已配置分类别名，例如 `Menswear` 或 `shuma` |
| **操作步骤** | 1. 访问产品分类页入口 <br> 2. 点击或直接打开分类页 <br> 3. 观察浏览器地址栏和页面 HTTP 状态 |
| **预期结果** | 1. 分类页 URL 形如 `https://b2b.hubbuyer.com/Menswear` 或约定小写形式 <br> 2. URL 不包含中文、纯数字 ID、查询参数、`.html`、`.php` <br> 3. 页面 HTTP 状态为 200 且内容为对应分类 |

#### TC-SEO-URL-002 【重点·正向】产品详情页 URL 符合分类别名加产品别名 [SmokeTest]

| 字段 | 内容 |
|:--|:--|
| **测试点** | 产品详情页 URL 结构符合 `域名/分类别名/产品别名` |
| **优先级** | Critical |
| **前置条件** | 已配置产品所属分类别名和产品别名 |
| **操作步骤** | 1. 从分类页点击任一产品进入详情页 <br> 2. 观察地址栏 URL <br> 3. 直接访问该详情页 URL |
| **预期结果** | 1. 产品页 URL 形如 `https://b2b.hubbuyer.com/Menswear/product-slug` <br> 2. URL 不包含中文、纯数字 ID、查询参数、`.html`、`.php` <br> 3. 直接访问返回当前产品详情，不跳错分类或商品 |

| **预期结果** | 1. 页面 URL 使用英文或拼音别名 <br> 2. 不出现中文、ID、参数和文件后缀 <br> 3. 刷新和直接访问均正常 |

| 字段 | 内容 |
|:--|:--|
| **测试点** | URL 禁止中文、纯数字 ID、后缀和查询参数 |
| **优先级** | High |

| **预期结果** | 1. 不规范 URL 不作为 canonical 主地址 <br> 2. 若旧链接需要兼容，应跳转到规范 URL 或按规则 noindex <br> 3. 不出现同一内容多种可收录 URL |
