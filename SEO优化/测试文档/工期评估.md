## 四、重点说明

| 重点 | 说明 |
|:--|:--|
| 样本准备依赖高 | 需要分类、产品、旧链接、多语言、缺图、缺描述、下架等样本，否则部分用例只能 Conditional。 |
| SEO 不能只看 DOM | 必须使用查看源代码、curl 或服务端渲染 HTML 验证，避免 JS 后填充误判。 |
| URL 改造风险高 | URL 规则会影响旧链接、canonical、sitemap、搜索引擎重复收录和历史外链。 |
| Schema 字段需确认 | Product 价格、库存、图片、品牌、评分字段是否输出需以开发字段映射为准。 |
| 上线后观测不纳入本工期 | 搜索引擎收录、排名和流量变化属于上线后运营观测，不作为本轮功能验收工期。 |
